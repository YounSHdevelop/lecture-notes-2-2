④ 비동기 ★동 · 마 · 매

⑤ React ★setter 대신 dispatch

  • useReducer 반환 : [state, dispatch]
  • [ ] Effect : Mount 시 1번

빈칸 채우기 눌러서 정답 확인

Timer API에서 반복 타이머를 멈추는 함수는 clearInterval이다. Promise의 후속 처리 중 성공 여부와 관계없이 무조건 실행되는 것은 finally()다. fetch 결과로 받는 것은 데이터가 아니라 Response 객체다. JSX는 빌드 때 React.createElement로 바뀐다. 커스텀 훅의 이름은 use로 시작한다. reducer는 모르는 type이 오면 state를 그대로 반환한다. TDZ는 Temporal Dead Zone의 줄임말이다.

    이름 퀴즈 객관식 8문제 대비

    Q1fetch로 받은 Response의 Body를 JS 객체로 바꾸는 메소드는?

    response.json()(await 필요). JSON.stringify는 반대로 객체 → 문자열(POST body 만들 때).

    Q2현재 페이지의 URL 정보를 가진 BOM 객체는?

    URL = location. navigator는 브라우저 환경 정보, history는 방문 기록.

    Q3Macrotask Queue에 들어가지 않는 것은?

    Promise.then은 Microtask. 그래서 setTimeout보다 먼저 실행돼요.

    Q4Promise의 상태가 아닌 것은?

    자료의 States는 Pending · Fulfilled · Rejected 세 개. Settled는 allSettled 이름에만 나와요.

    Q5useEffect에서 setInterval로 만든 타이머를 Unmount 때 정리하는 코드로 맞는 것은?

    Effect가 return하는 함수가 Cleanup. setInterval 짝은 clearInterval.

    Q6const [x, y] = useState(0); 에서 y의 역할은?

    useState는 [현재 값, setter]. dispatch는 useReducer 쪽.

    Q7input의 value를 State에 연결하고 onChange에서 setName(e.target.value)를 부르는 패턴의 이름은?

    Browser가 아니라 React(State)가 입력값을 관리 = Controlled Component.

    Q8Default Export에 대한 설명으로 맞는 것은?

    하나만 · 이름 자유 · React Component에서 자주 씀(export default class User도 자료 예).

    Q94xx 상태 코드가 아닌 것은?

    503은 5xx Server Error.

    Q10Hoisting 표에서 "선언 O · 초기화 X"라 선언 전에 쓰면 ReferenceError가 나는 것은?

    let · const = TDZ = ReferenceError. var는 undefined, function 선언은 호출 가능.

    내 말로 설명하기 주관식 개념 대비

    "fetch로 사용자 목록을 받아 State에 넣는 useEffect 코드"에 나오는 이름들(useEffect · [ ] · async/await · fetch · response.json · setUsers)이 각각 무슨 역할인지 한 줄씩 써 보세요.

    useEffect : Render 이후에 API 요청 같은 Side Effect를 실행하는 훅. [ ] : Dependency Array가 비어 있어서 Mount 때 한 번만 요청. async/await : Promise를 동기 코드처럼 기다리게 하는 문법(await는 그 함수만 멈춤). fetch : HTTP Request를 보내는 Web API, Response 객체를 Promise로 돌려줌. response.json() : Response의 Body를 JSON에서 JS 데이터로 변환. setUsers : 받은 데이터를 State에 넣는 setter, 그러면 Component가 Re-render돼서 목록이 화면에 나옴.
