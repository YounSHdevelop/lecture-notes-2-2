① HTTP 요청 4 · 응답 3 · 암무인

  • Request : Method · URL · Header · Body
  • Response : Status Code · Header · Body
  • 4xx : Client Error (400 · 401 · 403 · 404)
  • 5xx : Server Error (500 · 503)
  • HTTPS : HTTP + TLS (암호화 · 무결성 · 인증)

② DOM · BOM

  • 요소 찾기 : querySelector
  • 클래스 붙이기 : classList.add (DOM만 바뀜)
  • 현재 URL : location
  • 방문 기록 : history
  • 브라우저 정보 : navigator

③ JS 문법 빈 · 잠긴 · 꽉 찬 상자

  • 선언 전 var : undefined
  • 선언 전 let · const : ReferenceError (TDZ)
  • let : 재선언 불가 · 재할당 가능
  • 화살표 함수의 this : 바깥 this

④ 비동기 동 · 마 · 매

  • Promise 상태 : Pending · Fulfilled · Rejected

  • 404일 때 fetch : reject 안 됨, response.ok로 확인

  • useState 반환 : [state, setState]
