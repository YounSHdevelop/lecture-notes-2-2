장면 1

학교 커피 머신을 아무나 막 쓰게 두면 어떻게 될까?

운영체제의 역할 · 하드웨어 보호 · 제일 먼저 실행

1층에 커피 머신과 설탕을 두고 "마음대로 쓰세요" 했다

일주일 뒤면? 누군가는 설탕을 통째로 집에 가져가고, 누군가는 기계를 망가뜨리겠죠.

컴퓨터 안에도 소프트웨어가 엄청 많아요. 이 소프트웨어들은 전부 키보드·마우스·모니터·메모리 같은 하드웨어를 써서 일하죠. 여러 개가 동시에 돌면 서로 하드웨어를 차지하려고 싸우게 되고, 바이러스처럼 일부러 망가뜨리는 놈도 있어요. 그래서 누군가 중재를 해 줘야 합니다.

교수님 비유 — 커피 머신 앞에 바리스타를 세워요. 손님은 기계를 직접 만질 수 없고 "라떼 주세요" 하고 부탁만 할 수 있어요. 기계는 바리스타만 다루니까 고장도, 설탕 도둑도 사라지죠. 이 바리스타가 바로 운영체제예요. (기숙사에 사감이 있어야 규칙이 생기는 것과도 같아요.)

그래서 소프트웨어는 하드웨어에 직접 접근할 수 없고, 운영체제에 "메모리 이만큼 줘", "모니터에 이거 띄워 줘" 하고 요청해요. 운영체제는 그 요청들을 모아서 적당한 시점에 나눠 줍니다. 이래서 운영체제를 소프트웨어의 제왕이라고도 불러요.

하나 더. 손님보다 바리스타가 먼저 나와 있어야겠죠? 그래서 컴퓨터나 스마트폰을 켜면 가장 먼저 실행되는 소프트웨어가 운영체제예요. 윈도우·안드로이드·iOS가 먼저 올라와서 하드웨어를 다 잡아 놓고 "이제 나머지 애들 실행해" 하는 거예요.

시험엔 이렇게

운영체제는 응용 프로그램이 하드웨어에 직접 접근하지 못하게 막고, 요청을 받아 하드웨어 자원을 관리·배분하는 소프트웨어다. 컴퓨터를 켜면 가장 먼저 실행된다.

외우는 법: 손님은 부탁만, 기계는 바리스타만
바로 확인
바리스타 비유에서 "손님"에 해당하는 것은?
손님 = 응용 프로그램, 바리스타 = 운영체제, 커피 머신 = 하드웨어. 손님(프로그램)은 기계를 직접 못 만지고 바리스타(OS)에게 부탁만 해요.

장면 2

스마트워치와 그냥 시계, 뭐가 다를까?

임베디드 시스템 · 범용 컴퓨터 · OTA

그냥 시계는 공장에서 만든 기능 말고는 아무것도 못 해요. 기능을 바꾸려면 새로 만들어야 하죠. 그런데 스마트워치는 지도 앱을 깔면 지도가 되고, 카톡을 깔면 메신저가 돼요. 소프트웨어를 깔 때마다 기능이 바뀐다 — 이게 바로 컴퓨터라는 뜻이에요. 소프트웨어를 깔 수 있으려면 안에 운영체제가 있어야 하고요.

다만 시계 안에 고급 CPU나 큰 메모리는 못 들어가요. 그래서 스마트워치·스마트 TV처럼 작고 특정 기능 위주로 만든 컴퓨터를 임베디드 시스템이라 하고, 여기 들어가는 OS를 임베디드 OS라고 해요. OS인 건 맞지만 메모리도 성능도 제약이 많죠. 반대로 워드도 하고 영화도 보고 게임도 하는 우리 PC는 범용 컴퓨터예요.

임베디드 시스템범용 컴퓨터
예스마트워치, 스마트 TV, 자동차PC, 노트북
목적특정 기능 위주여러 가지 작업
OS임베디드 OS (작고 제약적)윈도우, 리눅스, macOS

교수님은 자동차 얘기도 했어요. 옛날 차는 창문·에어컨·의자마다 ECU(작은 CPU)가 따로 있어서 기능을 바꾸려면 부품을 갈아야 했어요. 테슬라는 리눅스 기반 OS로 중앙에서 소프트웨어로 제어해서, 소프트웨어만 바꾸면 "두 번 누르면 창문 끝까지 내려가기" 같은 기능이 생겨요. 이렇게 통신으로 알아서 내려받아 업데이트하는 기능을 OTA라고 해요. 폰의 안드로이드 업데이트도 OTA예요.

시험엔 이렇게

임베디드 시스템 = 특정 기능 위주로 만든 작은 컴퓨터(제약적인 임베디드 OS 탑재). 범용 컴퓨터 = 여러 작업을 하는 일반 컴퓨터. 소프트웨어를 설치해 기능이 바뀌면 컴퓨터다.

외우는 법: 깔면 바뀐다 → 컴퓨터 → OS가 있다
바로 확인
스마트 TV에 넷플릭스 앱을 설치할 수 있다는 사실이 알려 주는 것은?
소프트웨어를 깔 수 있다 = 그걸 관리할 운영체제가 있다는 뜻이에요. 다만 임베디드라서 PC만큼 고성능은 아니에요.

장면 3

미사일 각도 계산기인데, 왜 "계산기"가 아니라 "컴퓨터"라고 불렀을까?

에니악 · 하드와이어링 · 2진법 · 폰노이만 구조

세계 최초의 컴퓨터 에니악(ENIAC)은 미사일 각도를 빨리 계산하려고 만들었어요. 사람이 손으로 계산하면 2~7시간이 걸려서, 계산이 끝날 즈음엔 적이 이미 다른 데로 가 버렸거든요.

그런데 계산만 하면 계산기잖아요. 컴퓨터라고 부른 이유는 프로그래밍이 가능한 기계였기 때문이에요. 전선을 이렇게 꽂으면 덧셈, 저렇게 꽂으면 뺄셈 — 맑은 날 계산식과 비 오는 날 계산식을 선을 바꿔 꽂아서 바꿨어요. 이 방식을 하드와이어링이라고 해요.

에니악은 진공관으로 만들었는데, 진공관은 켜지면 1, 꺼지면 0밖에 표시를 못 해요. 그래서 지금 컴퓨터도 2진법을 써요. 지금 CPU는 그 소자와 선을 엄청 작게 만들어 수십억 개를 넣은 거예요.

폰노이만 구조 — 지금 컴퓨터의 뼈대

그 다음 등장한 천재가 폰노이만이에요. "선을 왜 꽂아? 프로그램을 메모리에 올려놓고 CPU가 돌리면 되잖아." 이 아이디어가 폰노이만 구조이고, 지금 컴퓨터의 거의 전부가 이 구조예요. 이때부터 "프로그래밍"이라는 개념이 생겨요. (이 구조의 가장 중요한 특징은 9/16에 다시 나와요.)

시험엔 이렇게

컴퓨터 = 프로그래밍이 가능한 기계. 에니악은 전선을 바꿔 꽂는 하드와이어링으로 프로그래밍했고, 폰노이만 구조는 프로그램과 데이터를 메모리에 올려 CPU가 실행하게 했다.

외우는 법: 선 꽂기(하드와이어링) → 메모리에 올리기(폰노이만)
바로 확인
에니악을 "계산기"가 아니라 "컴퓨터"라고 부르는 이유는?
컴퓨터의 정의 = 프로그래밍이 가능한 기계. 에니악은 하드와이어링으로 계산식을 바꿀 수 있었어요. 진공관은 2진법의 이유일 뿐이에요.

장면 4

CPU는 하나인데, 한글·카톡·음악이 어떻게 동시에 돌까?

일괄 처리 → 대화형 → 시분할 · 타임 슬라이스 · 멀티유저

초기 컴퓨터는 키보드도 모니터도 없었어요. 프로그램과 데이터를 천공 카드(구멍 뚫은 카드)로 넣고, 결과는 줄 프린터로 받았죠. 결과에 에러가 있으면? 카드에 구멍을 다시 뚫어야 했어요. 이렇게 한 번에 작업 하나만 처리하는 시스템을 일괄 처리 시스템(배치 시스템)이라고 해요. 교수님이 "꼭 기억하세요, 뒤에 또 나옵니다" 한 용어예요.

그 다음 키보드와 모니터가 생기면서 중간중간 컴퓨터와 주고받을 수 있게 됐어요. "1번 방식으로 계산할까요?" 하고 물어볼 수 있죠. 이게 대화형 시스템(인터랙티브 시스템)이에요.

시분할 — 아주 잘게 쪼개서 돌려 쓰기

그럼 CPU 하나로 어떻게 여러 프로그램이 동시에 돌까요? 프로그램 3개에 CPU를 1초씩 주면 다시 돌아오기까지 3초 동안 멈춰 보여요. 그런데 0.1초씩 줬다 뺏었다 하면 너무 빨라서 동시에 도는 것처럼 보이죠. 영화가 사진 한 장 한 장을 빠르게 넘겨서 움직이는 것처럼 보이는 것과 같아요.

이 방식이 시분할 시스템(타임 셰어링)이고, 잘게 쪼갠 시간 한 조각을 타임 슬라이스(또는 타임 퀀텀)라고 해요. 지금 시스템의 원조예요.

동시에 실행되는 프로그램 개수를 멀티프로그래밍 정도(degree of multiprogramming)라고 하는데, 일괄 처리 시스템은 1이에요. 한 사람이 여러 프로그램을 동시에 돌릴 수 있다면, 바꿔 말해 여러 사람도 동시에 한 컴퓨터를 쓸 수 있겠죠. 그래서 멀티유저 시스템이 나오고, 그걸 관리하는 멀티유저 OS로 유닉스가 만들어져요(9/14 수업 첫머리에서 정리).

시험엔 이렇게

일괄 처리(배치) 시스템 = 한 번에 하나의 작업만 처리(멀티프로그래밍 정도 1). 시분할 시스템 = CPU 시간을 타임 슬라이스로 잘게 나눠 여러 프로그램에 번갈아 할당해 동시에 실행되는 것처럼 보이게 한다.

외우는 법: 배치 → 대화 → 시분할 (하나씩 → 물어보며 → 쪼개서 동시에)
바로 확인
일괄 처리 시스템의 멀티프로그래밍 정도(degree of multiprogramming)는?
일괄 처리는 한 번에 하나만 실행하니까 1이에요. 시분할 시스템은 10개, 100개도 될 수 있어요.

① 운영체제의 역할 바리스타

  • 프로그램은 하드웨어 직접 접근 불가 → OS에 요청
  • OS = 자원 관리·배분, 컴퓨터 켜면 가장 먼저 실행

② 임베디드 / 범용

  • 임베디드 = 특정 기능 위주 작은 컴퓨터(스마트워치·TV)
  • 범용 = 여러 작업(PC) · 통신으로 자동 업데이트 = OTA

③ 컴퓨터의 시작

  • 컴퓨터 = 프로그래밍 가능한 기계 · 에니악 = 하드와이어링
  • 진공관 1/0 → 2진법 · 폰노이만: 프로그램을 메모리에 올려 CPU가 실행

④ 시스템의 변화 ★배치→대화→시분할

  • 일괄 처리(배치) = 한 번에 하나, 멀티프로그래밍 정도 1
  • 시분할 = 타임 슬라이스(타임 퀀텀)로 쪼개 번갈아 → 멀티유저 → 유닉스

빈칸 채우기 눌러서 정답 확인

응용 프로그램은 하드웨어에 직접 접근하지 못하고 운영체제에 요청한다. 운영체제는 컴퓨터를 켜면 가장 먼저 실행된다. 스마트워치처럼 특정 기능 위주의 작은 컴퓨터를 임베디드 시스템이라 한다. 에니악은 전선을 바꿔 꽂는 하드와이어링으로 프로그래밍했고, 진공관 때문에 2진법을 썼다. 한 번에 하나의 작업만 처리하는 시스템은 일괄 처리(배치) 시스템이고, CPU 시간을 잘게 나눈 한 조각을 타임 슬라이스라 한다.

프로그램(손님)은 하드웨어(기계)에 직접 못 가고 OS(바리스타)에게 부탁만 하기 때문.
컴퓨터를 켜면 가장 먼저 실행되는 소프트웨어는?
운영체제. 먼저 하드웨어를 잡아 두고 나머지 프로그램을 실행한다.
임베디드 시스템이란?
스마트워치·스마트 TV처럼 특정 기능 위주로 만든 작은 컴퓨터. 제약적인 임베디드 OS가 들어간다.
OTA란?
통신으로 소프트웨어를 자동으로 내려받아 업데이트하는 기능.
컴퓨터의 정의는?
프로그래밍이 가능한 기계.
하드와이어링이란?
전선을 바꿔 꽂아서 계산 방식을 바꾸는 초기 프로그래밍 방식(에니악).
폰노이만 구조의 핵심 아이디어는?
프로그램과 데이터를 메모리에 올려놓고 CPU가 실행한다.
일괄 처리(배치) 시스템이란?
한 번에 하나의 작업만 처리하는 시스템. 멀티프로그래밍 정도 1.
시분할 시스템과 타임 슬라이스는?
CPU 시간을 잘게 쪼갠 조각(타임 슬라이스)을 여러 프로그램에 번갈아 줘서 동시에 도는 것처럼 보이게 하는 시스템.

    퀴즈 다 풀고 채점하기

    Q1운영체제에 대한 설명으로 틀린 것은?

    응용 프로그램은 하드웨어에 직접 접근하지 못하고 OS에 요청만 해요. 그래서 바리스타 비유가 나와요.

    Q2다음 중 임베디드 시스템에 가장 가까운 것은?

    스마트워치는 특정 기능 위주의 작은 컴퓨터(임베디드). 태엽 시계는 소프트웨어를 깔 수 없으니 컴퓨터가 아니고, 데스크톱은 범용이에요.

    Q3현재 컴퓨터가 2진법을 쓰는 것과 가장 관련 있는 것은?

    에니악의 진공관은 켜짐(1)/꺼짐(0)만 표시했어요. 그 소자를 작게 만든 게 지금 CPU라 2진법을 써요.

    Q4결과를 다 받아 봐야 에러를 알 수 있고, 다시 카드를 뚫어 처음부터 넣어야 했던 시스템은?

    한 번에 하나를 끝까지 처리하고 결과만 받는 방식 = 일괄 처리(배치). 중간에 물어볼 수 있게 된 게 대화형이에요.

    Q5프로그램 3개에 CPU를 1초씩 번갈아 줬더니 화면이 뚝뚝 끊겼다. 동시에 도는 것처럼 보이게 하려면?

    시간을 잘게 쪼개야 다시 돌아오는 간격이 짧아져서 동시에 도는 것처럼 보여요. (너무 작게 하면 생기는 문제는 9/28에 나와요.)

    Q6시분할 기술로 가능해진 것이 아닌 것은?

    멀티프로그래밍 정도 1은 일괄 처리 시스템이에요. 시분할은 그 수를 10개, 100개로 늘렸어요.

    내 말로 설명하기 친구한테 말하듯이

    CPU가 하나뿐인데 카톡·음악·한글이 동시에 돌아가는 이유를 설명해 보세요.

    운영체제가 CPU 시간을 0.1초 같은 아주 작은 조각(타임 슬라이스)으로 쪼개서 카톡, 음악, 한글에 번갈아 줘요. 한 바퀴 돌아오는 시간이 아주 짧아서 사람 눈에는 셋이 동시에 도는 것처럼 보여요. 이게 시분할 시스템이에요. 영화가 사진을 빠르게 넘겨서 움직이는 것처럼 보이는 것과 같아요.
    더 알아두면 좋은 것 교수님이 "읽어 보라"고만 한 것

    운영체제의 목표와 특징

    자원 관리, 자원 보호, 하드웨어 인터페이스, 사용자 인터페이스 / 효율성, 안정성, 편리성. 교수님이 "직접 읽어 보시라, 그것보다 중요한 얘기가 엄청 많다"고 한 부분이에요.
