학교 커피 머신을 아무나 막 쓰게 두면 어떻게 될까?

운영체제의 정의 · 컴퓨터 자원 · 제일 먼저 실행

1층에 커피 머신과 설탕을 두고 "마음대로 쓰세요" 했다

일주일 뒤면? 누군가는 설탕을 통째로 가져가고, 누군가는 기계를 망가뜨리겠죠.

프로그램이 돌아가려면 CPU, 메모리, 하드디스크, 모니터, 키보드, 마우스 같은 것들이 필요해요. 교재는 이걸 묶어서 컴퓨터 자원이라고 불러요. 그런데 프로그램 여러 개가 이 자원을 먼저 차지하겠다고 싸우면, 서로 충돌하거나 비정상적으로 동작할 수 있어요. 그래서 누군가 자원을 정리해서 나눠 줘야 하죠.

교수님 비유 — 커피 머신 앞에 바리스타를 세워요. 손님은 기계를 직접 만질 수 없고 "라떼 주세요" 하고 부탁만 해요. 기계는 바리스타만 다루니까 고장도, 설탕 도둑도 사라지죠. 이 바리스타가 운영체제예요. 손님 = 응용 프로그램, 커피 머신 = 컴퓨터 자원.

교재 정의를 비유에 대 보면 딱 맞아요. 운영체제(OS)는 컴퓨터 자원을 효율적으로 관리하고(바리스타가 기계를 관리), 다양한 응용 프로그램이 원활하게 작동하도록 지원하는(손님들이 커피를 잘 받아 가게 하는) 소프트웨어예요. 윈도우·맥OS·리눅스, 스마트폰의 안드로이드·iOS가 다 운영체제고요.

하나 더. 손님보다 바리스타가 먼저 나와 있어야겠죠? 그래서 컴퓨터를 켜면 가장 먼저 실행되는 소프트웨어가 운영체제예요. 먼저 올라와서 자원을 다 잡아 놓고 "이제 나머지 실행해" 하는 거예요.

시험엔 이렇게

운영체제(OS)는 컴퓨터 자원을 효율적으로 관리하고, 다양한 응용 프로그램이 원활하게 작동할 수 있도록 지원하는 소프트웨어다.

외우는 법: 자원은 관리, 프로그램은 지원 · 손님은 부탁만, 기계는 바리스타만

장면 2

스마트워치와 그냥 시계, 뭐가 다를까?

임베디드 시스템 · 임베디드 운영체제 · 범용 컴퓨터 · OTA ★

그냥 시계는 공장에서 만든 기능 말고는 아무것도 못 해요. 그런데 스마트워치는 앱을 깔면 기능이 바뀌죠. 교재 그림 속 캐릭터도 이렇게 말해요. "스마트 워치나 스마트 TV는 프로그래밍할 수 있으므로 컴퓨터이다." 컴퓨터니까 안에 운영체제도 있어요.

다만 시계 안에 고급 CPU나 큰 메모리는 못 들어가요. 이렇게 특정 기능을 수행하도록 설계된 기기에 들어간 컴퓨터를 임베디드 시스템(임베디드 컴퓨터)이라고 해요. 일반 컴퓨터보다 CPU 성능이 낮고, 메모리 용량이 작고, 화면도 작아서 정해진 일만 하죠. 반대로 웹 서핑·문서 작성·게임·영상 감상 등 여러 가지 일을 다 하는 우리 PC는 범용 컴퓨터예요.

임베디드 시스템에 들어가는 OS가 임베디드 운영체제예요(애플 워치의 watchOS, 구글 워치의 WearOS). 기능은 윈도우·안드로이드보다 제한적이지만, 자원 관리 · 보호 · 인터페이스 제공이라는 운영체제의 핵심 역할은 그대로 해요. 자원이 부족한 걸 고려해서 작고 가볍게 만든 것뿐이에요.

OTA — 정비소 안 가고 차가 업그레이드된다

옛날 자동차는 기능을 추가하려면 하드웨어(스위치)를 갈아야 했어요. 요즘 차는 운영체제가 들어가서 소프트웨어 업그레이드만으로 기능을 만들어요. 서비스센터에 안 가도 무선 통신으로 업그레이드되죠(테슬라·현대차 등).

사물인터넷(IoT)이 발달하면서 많은 기기가 인터넷에 연결됐어요. 이렇게 소프트웨어를 원격으로 업그레이드하거나 설정을 바꾸는 기술을 OTA(Over-The-Air programming)라고 해요. 폰의 안드로이드·iOS 업그레이드, 앱 업데이트, 테슬라나 현대차 최신 모델의 차량 소프트웨어·내비게이션 업데이트가 다 OTA예요.

시험엔 이렇게

임베디드 시스템은 특정 기능을 수행하도록 설계된 기기에 탑재된 컴퓨터이고, 다양한 작업을 처리하는 일반 컴퓨터는 범용 컴퓨터라 한다. OTA는 인터넷에 연결된 기기의 소프트웨어를 원격으로 업그레이드하거나 설정을 변경하는 기술이다.

장면 3

키보드도 모니터도 없던 에니악, 왜 "컴퓨터"라고 불렀을까?

에니악 ★ · 2진법 · 하드와이어링 · 폰노이만 구조 ★

세계 최초의 전자식 컴퓨터 에니악(ENIAC)은 미사일 탄도 계산을 위해 만들었어요. 사람이 주판으로 7시간 걸리던 계산을 단 3초에 끝냈죠. 안에는 진공관이 잔뜩 들어 있었는데, 진공관이 켜지면 1, 꺼지면 0으로 인식했어요. 이게 오늘날 컴퓨터가 2진법을 쓰는 기초예요. (한때 10진법 컴퓨터도 만들어 봤지만, 계산 속도와 효율에서 2진법이 더 유리해서 지금은 2진법 컴퓨터만 남았어요.)

그런데 에니악엔 키보드·마우스·모니터가 하나도 없었어요. 그래도 교재는 "에니악은 컴퓨터가 맞다"고 해요. 이유는 딱 하나, 프로그래밍이 가능했기 때문이에요. 스위치와 전선을 바꿔 꽂아 회로를 만드는 방식, 즉 하드와이어링으로 프로그램을 대신했거든요. 계산 기능을 바꾸려면 4층 건물만 한 기계에서 스위치를 조정하고 전선을 다시 연결해야 했으니, 엄청 복잡하고 오래 걸렸어요.

폰노이만 구조 — 지금 컴퓨터의 뼈대

이 불편함을 해결한 사람이 폰노이만이에요. 아이디어는 이래요. "하드웨어는 그대로 두고, 프로그램을 메모리에 저장해 두면 CPU가 그걸 읽어서 처리하면 되잖아." 이게 폰노이만 구조예요. 핵심은 명령어와 데이터를 메모리에 저장하고, 순차적으로 처리한다는 점이에요.

덕분에 전선을 다시 꽂지 않아도 프로그램만 바꾸면 다양한 일을 시킬 수 있게 됐고, 작업 효율이 확 올라갔어요. 그래서 현대 컴퓨터는 대부분 폰노이만 구조를 기반으로 설계되어 있어요. (이 구조의 가장 중요한 특징은 9/16에 다시 나와요.)

시험엔 이렇게

에니악은 주변장치가 없었지만 하드와이어링(스위치와 전선으로 회로 구성)으로 프로그래밍이 가능했으므로 컴퓨터다. 폰노이만 구조는 하드웨어 구조를 그대로 유지하면서 프로그램을 메모리에 저장하여 CPU가 읽고 처리하도록 한 구조로, 명령어와 데이터를 메모리에 저장하고 순차적으로 처리하는 것이 핵심이다.

외우는 법: 선 꽂기(하드와이어링) → 메모리에 올리기(폰노이만)

실행 도중에 숫자 하나 못 고치던 시절, 컴퓨터는 어떻게 썼을까?

일괄 작업 시스템 ★ · 대화형 시스템

지금은 음악 들으면서 문서 작업하는 게 당연하죠. 그런데 옛날엔 작업을 하나씩 차례대로 처리해야 했어요. 프로그램과 데이터를 천공 카드(구멍 뚫은 카드)에 함께 담아 넣으면, 컴퓨터가 카드를 읽어 작업하고 결과를 라인 프린터로 뽑아 줬어요. 문제는 실행 도중에 데이터를 고치거나 새로 넣는 게 불가능했다는 거예요. 결과에 에러가 있으면? 카드를 다시 뚫어서 처음부터요.

이렇게 모든 작업을 한꺼번에 처리하는 시스템을 일괄 작업 시스템(또는 일괄 처리 시스템, batch)이라고 해요. 여기에도 간단한 운영체제가 있었고, 메인 메모리는 운영체제 영역과 사용자 작업 영역 두 칸으로 나뉘어 있었어요.

지금도 남아 있는 흔적 — MS-DOS의 autoexec.bat 파일이 그 흔적이에요. 부팅될 때 자동으로 실행되는 명령어를 모아 둔 파일인데, .bat가 바로 batch job이라는 뜻이에요. 유닉스 계열의 .sh 셸 스크립트도 같은 일괄 작업 방식이에요.

대화형 시스템 — 컴퓨터와 주고받을 수 있게 됐다

그다음 키보드와 모니터가 생기면서, 사용자가 컴퓨터와 실시간으로 주고받으며 작업할 수 있게 됐어요. 이걸 대화형 시스템(interactive system)이라고 해요. 일괄 작업 시스템은 단순 계산 위주였지만, 대화형 시스템 덕분에 문서 편집기나 게임 같은 프로그램이 가능해졌어요.

대신 잃은 것도 있어요. 일괄 작업은 입력만 끝나면 CPU가 혼자 쭉 돌리니까 작업 시간을 예측할 수 있었어요. 대화형은 사용자가 언제 반응할지 모르니 작업 시간을 예측하기 어려워졌죠. 그래도 사용자 중심 컴퓨팅으로 바뀐 획기적인 전환점이에요.

일괄 작업 시스템(일괄 처리 시스템)은 프로그램과 데이터를 한꺼번에 입력받아 모든 작업을 한꺼번에 순차 처리하는 시스템으로, 실행 도중 데이터를 수정하거나 입력할 수 없다. 대화형 시스템은 컴퓨터와 사용자가 실시간으로 상호작용하는 시스템이다.

외우는 법: 배치 = 몰아서 한 방에(.bat) · 대화형 = 주고받기, 대신 시간 예측 어려움
바로 확인
일괄 작업 시스템과 비교했을 때 대화형 시스템의 특징은?
대화형 = 실시간 상호작용. 사용자가 언제 반응할지 모르니 작업 시간 예측은 오히려 어려워졌어요. 예측 가능·수정 불가는 일괄 작업 쪽이에요.

CPU는 하나인데, 한글·카톡·음악이 어떻게 동시에 돌까?

시분할 시스템 ★ · 타임 슬라이스 · 멀티프로그래밍 수준 · 다중 사용자 · 유닉스

CPU 하나로 여러 작업을 동시에 돌리는 비결은 시간을 잘게 쪼개는 것이에요. 교재 그림처럼 메모리에 운영체제와 A·B·C 작업이 올라가 있고, CPU가 0.1초씩 돌아가며 A → B → C에 붙어 일해요. 그럼 A 입장에선 0.3초만 기다리면 다시 CPU를 얻죠. 너무 빨리 바뀌니까 사람 눈엔 셋이 동시에 도는 것처럼 보여요.

이렇게 짧은 시간 단위로 작업을 나눠서 동시에 이루어지는 것처럼 보이게 하는 시스템이 시분할 시스템(time sharing system)이에요. 잘게 나눈 시간 한 조각은 타임 슬라이스 또는 타임 퀀텀이라고 불러요. 둘은 같은 말이에요.

동시에 실행되는 작업의 개수는 멀티프로그래밍 수준(또는 멀티프로그래밍 정도)이라고 해요. 일괄 작업 시스템은 한 번에 하나니까 1, 위 그림은 A·B·C가 돌고 있으니 3이에요. 현대 시분할 시스템은 이 숫자가 훨씬 높죠.

한 사람이 여러 프로그램을 동시에 돌릴 수 있다면, 여러 사람이 동시에 접속해서 쓰는 것도 되겠죠? 그래서 비싼 컴퓨터를 여럿이 나눠 쓰는 다중 사용자 시스템이 나왔고, 1960년대 후반 AT&T 벨 연구소가 멀티프로그래밍과 다중 사용자 기능을 지원하는 유닉스를 만들었어요.

공짜는 아니에요. 메모리에 여러 프로그램이 올라가 있고 작업을 계속 바꿔 줘야 하니까, 작업 전환에 추가 작업이 필요하다는 게 시분할의 단점이에요. 또 작업이 너무 많으면 중요한 작업이 정해진 시간 안에 못 끝날 수도 있어요.

시험엔 이렇게

시분할 시스템은 짧은 시간 단위로 작업을 분할하여 동시에 이루어지는 것처럼 보이게 하는 시스템이며, 작업 시간을 잘게 나눈 조각을 타임 슬라이스(타임 퀀텀)라 한다. 동시에 실행되는 작업의 개수를 멀티프로그래밍 수준이라 하며, 일괄 작업 시스템은 1이다.

외우는 법: 배치 → 대화 → 시분할 (몰아서 → 주고받으며 → 쪼개서 동시에)
바로 확인
메모리에 A·B·C 세 작업이 올라가 0.1초씩 번갈아 실행된다. 멀티프로그래밍 수준은?
멀티프로그래밍 수준 = 동시에 실행되는 작업의 개수 → 3. 0.1초는 타임 슬라이스, 1은 일괄 작업 시스템이에요.

★ 교재 별표 · 시험 출제 표시

① 운영체제란 바리스타

  • 운영체제는 컴퓨터 자원(CPU, 메모리, 하드디스크, 키보드 등)을 효율적으로 관리하고, 응용 프로그램이 원활하게 작동하도록 지원하는 소프트웨어예요.
  • 컴퓨터를 켜면 가장 먼저 실행돼서 자원을 잡아 두고 나머지 프로그램을 실행해요.

② 임베디드와 OTA ★

  • 특정 기능을 하도록 설계된 기기에 들어간 컴퓨터를 임베디드 시스템, 여러 작업을 다 하는 PC를 범용 컴퓨터라고 해요.
  • 임베디드 운영체제(watchOS, WearOS)는 작고 가볍지만 자원 관리·보호·인터페이스 제공은 그대로 해요.
  • 소프트웨어를 원격으로 업그레이드하거나 설정을 바꾸는 기술이 OTA예요.

③ 에니악과 폰노이만 ★선 꽂기 → 메모리

  • 에니악은 주변장치가 없었지만 스위치와 전선으로 회로를 짜는 하드와이어링으로 프로그래밍이 가능해서 컴퓨터예요. 진공관 켜짐 1 · 꺼짐 0이 2진법의 기초예요.
  • 폰노이만 구조는 하드웨어는 그대로 두고 프로그램을 메모리에 저장해 CPU가 읽고 처리하게 한 구조예요. 핵심은 명령어와 데이터를 메모리에 두고 순차 처리하는 것이고, 현대 컴퓨터 대부분이 이 구조예요.

④ 일괄 작업 → 대화형 ★ 뒤에 또 나옴

  • 일괄 작업 시스템은 천공 카드로 넣은 작업을 한꺼번에 순차 처리하고, 실행 도중 수정이 불가능해요. 작업 시간은 예측 가능해요(흔적: .bat, .sh).
  • 대화형 시스템은 사용자와 실시간으로 주고받아서 문서 편집기·게임이 가능해졌지만, 작업 시간은 예측하기 어려워요.

⑤ 시분할 시스템 ★

  • 짧은 시간 단위로 작업을 나눠 동시에 실행되는 것처럼 보이게 하는 게 시분할 시스템, 그 시간 조각이 타임 슬라이스(타임 퀀텀)예요.
  • 동시에 실행되는 작업 개수가 멀티프로그래밍 수준이에요. 일괄 작업은 1이에요.
  • 여럿이 함께 쓰는 다중 사용자 시스템으로 이어졌고, 이를 지원하는 OS가 유닉스예요. 단점은 작업 전환에 추가 작업이 필요하다는 것.

빈칸 채우기 눌러서 정답 확인

운영체제는 컴퓨터 자원을 효율적으로 관리하고 응용 프로그램이 원활하게 작동하도록 지원하는 소프트웨어다. 특정 기능을 수행하도록 설계된 기기에 탑재된 컴퓨터를 임베디드 시스템이라 하고, 소프트웨어를 원격으로 업그레이드하는 기술을 OTA라 한다. 에니악은 스위치와 전선으로 회로를 구성하는 하드와이어링으로 프로그래밍했고, 프로그램을 메모리에 저장해 CPU가 읽고 처리하게 한 구조는 폰노이만 구조다. 모든 작업을 한꺼번에 처리하는 시스템은 일괄 작업 시스템이고, 사용자와 실시간으로 상호작용하는 시스템은 대화형 시스템이다. CPU 작업 시간을 잘게 나눈 조각을 타임 슬라이스라 하고, 동시에 실행되는 작업의 개수를 멀티프로그래밍 수준이라 한다.

컴퓨터 자원의 예는?

임베디드 운영체제가 그래도 하는 OS의 핵심 역할 3가지는?
자원 관리, 보호, 인터페이스 제공. 대신 작고 경량화된 구조.

Over-The-Air programming. 인터넷에 연결된 기기의 소프트웨어를 원격으로 업그레이드하거나 설정을 변경하는 기술.
에니악이 주변장치 없이도 컴퓨터인 이유는?
스위치와 전선으로 회로를 구성하는 하드와이어링으로 프로그래밍이 가능했기 때문.

일괄 작업 시스템이란?
모든 작업을 한꺼번에 순차 처리하는 시스템. 실행 도중 데이터 수정·입력 불가, 작업 시간 예측 가능. 흔적: .bat 파일.
대화형 시스템이란?
컴퓨터와 사용자가 실시간으로 상호작용하는 시스템. 문서 편집기·게임이 가능해졌지만 작업 시간 예측은 어렵다.

멀티프로그래밍 수준이란?

여러 작업을 메모리에 두고 전환해야 하므로 추가 작업이 필요하다.

    Q6프로그램 3개에 CPU를 1초씩 번갈아 줬더니 화면이 뚝뚝 끊겼다. 동시에 도는 것처럼 보이게 하려면?

    CPU가 하나뿐인데 카톡·음악·한글이 동시에 돌아가는 이유를 "타임 슬라이스", "멀티프로그래밍 수준"을 넣어 설명해 보세요.

    운영체제가 CPU 작업 시간을 0.1초 같은 아주 작은 조각(타임 슬라이스)으로 나눠서 카톡, 음악, 한글에 번갈아 줘요. 한 바퀴 돌아오는 데 0.3초밖에 안 걸려서 사람 눈엔 셋이 동시에 도는 것처럼 보여요. 이게 시분할 시스템이고, 지금 동시에 실행되는 작업이 3개니까 멀티프로그래밍 수준은 3이에요. 한 번에 하나만 하던 일괄 작업 시스템은 1이었어요.

    에니악은 존 모클리와 존 에커트가 만들었고 진공관 약 18,000개, 4층 건물 크기였어요. 폰노이만은 프린스턴 고등연구소 창립 멤버로 경제학·양자역학 등 여러 분야에 업적을 남긴 천재예요. 인물·연도는 시험과 무관해요.

    실시간 시스템

    시분할에서 작업이 너무 많으면 중요한 작업이 정해진 시간 안에 못 끝날 수 있어요. 원자력·미사일 제어처럼 그러면 큰일 나는 곳에는 정해진 시간 안에 반드시 끝내 주는 실시간 시스템을 써요(교재 Note, 사진 일부만 있음).
