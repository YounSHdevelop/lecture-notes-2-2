MP3를 서버 한 대에 다 모으면 서버가 터진다. 그럼 어떻게?

클라이언트-서버 · P2P · 클라우드 컴퓨팅

웹처럼 클라이언트가 요청하고 서버가 응답하는 구조를 클라이언트-서버라고 해요. 엄청 퍼졌지만 문제가 있었죠. 모든 사람이 서버에서 파일을 받으니까 부하가 서버에 몰려요.

그래서 나온 게 P2P(Peer-to-Peer)예요. 서버는 "누가 어떤 파일을 가졌는지" 중재만 하고, 파일은 그 파일을 가진 다른 사용자(peer)에게서 직접 받아요. 서버 과부하를 줄이는 효과적인 대안으로 자리 잡았고, 지금은 메신저, 블록체인, 파일 공유 시스템이 P2P 구조를 써요.

한편 초고속 통신망과 5G 같은 무선 기술이 발달하면서, 데이터와 소프트웨어를 직접 갖고 있지 않아도 인터넷으로 언제 어디서나 쓸 수 있게 됐어요. 이게 클라우드 컴퓨팅이에요. 하드웨어와 소프트웨어는 중앙에 두고, 사용자는 인터넷으로 필요한 기능만 제공받는 구조죠(AWS, 구글 드라이브). 뒤에서 어떤 컴퓨터가 도는지 구름에 가려 안 보인다고 클라우드예요.

시험엔 이렇게

P2P 시스템은 서버는 중재만 하고 파일은 그 파일을 가진 사용자(peer)로부터 직접 받는 구조로, 서버 과부하를 줄이기 위해 등장했다. 클라우드 컴퓨팅은 하드웨어와 소프트웨어를 중앙에 두고 사용자는 인터넷을 통해 필요한 기능만 제공받는 구조다.

외우는 법: P2P = 서버는 중재만, 파일은 직접 · 클라우드 = 중앙에 두고 빌려 쓰기
바로 확인
P2P가 만들어진 가장 직접적인 이유는?
P2P = 서버 과부하 줄이기. 중앙에 두고 빌려 쓰는 건 클라우드 컴퓨팅이에요.

운영체제를 열어 보면 무엇과 무엇으로 되어 있을까?

사용자 인터페이스 · 커널 ★ · 커널의 4가지 기능 · CLI와 GUI ★

운영체제는 사용자 인터페이스와 커널, 두 가지 핵심 구성 요소로 되어 있어요. 사용자 인터페이스는 사용자가 운영체제와 직접 소통하는 수단이고, 커널은 컴퓨터 자원을 관리하는 운영체제의 핵심이에요. 그리고 가장 중요한 규칙 하나. 사용자나 응용 프로그램은 커널이 제공하는 인터페이스를 통해서만 컴퓨터 자원에 접근할 수 있어요. 9/9의 바리스타가 바로 커널이에요.

교수님 비유 (교재도 같은 비유) — 커널은 자동차의 엔진이에요. 엔진이 차의 성능을 정하듯 커널이 전체 시스템의 성능과 안정성을 좌우하죠. 그런데 엔진만 있다고 차를 몰 수 있나요? 운전자가 쓰는 핸들·브레이크·계기판이 있어야죠. 그게 사용자 인터페이스예요. 사용자는 인터페이스로 커널에 명령을 내리고, 커널의 작업 결과를 다시 인터페이스로 확인해요.

커널이 하는 일 4가지

기능무슨 일?
프로세스 관리프로그램을 실행하면 프로세스가 되고, 커널은 프로세스에 CPU 시간을 배정하고 실행 환경을 만든다
메모리 관리메인 메모리는 여러 프로세스가 함께 쓰는 자원이라, 각 프로세스를 적절한 위치에 배치해 충돌 없이 돌게 한다
저장장치 관리메인 메모리는 전원이 꺼지면 데이터가 사라지는 휘발성 장치라, 데이터를 하드디스크·SSD·USB에 파일 시스템 형태로 안전하게 저장한다
입출력 관리키보드·마우스·모니터 같은 입출력 장치를 관리한다

앞으로 배울 목차(프로세스 → 스케줄링 → 메모리 → 파일 시스템 → 입출력)가 바로 이 순서예요.

CLI와 GUI

사용자 인터페이스는 크게 둘이에요. 사용자가 명령어를 글자로 직접 입력하는 CLI(문자 기반, 유닉스의 셸, MS-DOS 명령 프롬프트)와, 마우스로 아이콘을 클릭하는 GUI(그래픽 사용자 인터페이스)죠. 교수님이 짚은 착각 하나: "유닉스는 어렵고 윈도우는 쉽다"는 건 인터페이스 얘기지 커널 얘기가 아니에요. 스마트폰 OS도 유닉스 계열인데 쓰기 어렵지 않잖아요.

시험엔 이렇게

운영체제는 사용자 인터페이스와 커널로 이루어진다. 커널은 운영체제의 핵심 기능을 수행하는 중앙 제어 소프트웨어로 프로세스 관리, 메모리 관리, 저장장치 관리, 입출력 관리를 수행하며, 사용자나 응용 프로그램은 커널이 제공하는 인터페이스를 통해서만 컴퓨터 자원에 접근할 수 있다. 사용자 인터페이스는 CLI(문자 기반)와 GUI(그래픽)로 나뉜다.

내가 14를 써 둔 자리에 남이 21을 또 쓰면?

시스템 호출 ★ · 시스템 함수 read() / write()

모두가 하드디스크에 직접 쓸 수 있다면

한 사람이 14를 써 둔 자리에 다른 사람이 21을 덮어써 버려요. 비행기에서 "아무 데나 앉으세요" 하면 다들 앞자리로 몰리는 것처럼요.

그래서 OS는 하드디스크를 자기 뒤에 숨기고, 앞에 "저장해 주세요" 하고 부를 수 있는 함수만 내놓아요. 응용 프로그램은 자원에 직접 접근하지 않고, 커널이 제공하는 read()나 write() 같은 시스템 함수를 통해 요청을 보내요. 커널은 그 요청을 받아 자원을 안전하게 처리한 뒤, 결과만 돌려줘요. 프로그램은 값을 맡길 수는 있지만 위치는 정할 수 없어요.

이렇게 커널이 제공하는 시스템 함수를 불러서 쓰는 것을 시스템 호출(system call, 시스템 콜)이라고 해요. 교수님이 "별표, 이게 제일 중요하다"고 한 개념이에요. 시스템 호출은 OS가 자원과 자기 자신을 보호하는 방법이에요.

교수
나는 하드디스크의 몇 번째 위치에 저장할 수 있는 권한이 없어요. 대신 저장을 하려면 OS가 제공해 주는 함수를 불러서만 쓸 수 있다. 이게 제일 중요하죠.9/14 강의 중 (말을 조금 다듬음)
시험엔 이렇게

시스템 호출이란 커널이 제공하는 시스템 함수를 호출하여 사용하는 것이다. 응용 프로그램은 직접 자원에 접근하지 않고 커널이 제공하는 read()나 write() 같은 시스템 함수를 통해 요청을 보내며, 커널은 요청을 받아 자원을 안전하게 처리한 후 결과만 사용자에게 전달한다.

외우는 법: 값은 맡기되 자리는 커널이
✗ 틀린 생각시스템 호출을 쓰면 하드디스크의 원하는 위치에 직접 저장할 수 있다
○ 맞는 생각시스템 호출로 요청만 하고, 처리와 위치는 커널이 정한다
바로 확인
응용 프로그램이 파일을 저장하려 할 때 실제로 일어나는 일은?
프로그램은 시스템 호출로 부탁만 하고, 실제 저장은 커널이 해요. 그래야 남의 데이터를 덮어쓰는 일이 없어요.

printf 한 줄 쓸 때마다 내 프로그램은 커널에 들어갔다 나온다?

사용자 모드 · 커널 모드 · 이중 모드 연산 ★ · 비자발적 전환

프로세스는 기본적으로 사용자 모드에서 실행돼요. 덧셈 같은 간단한 계산은 사용자 모드에서 끝나죠. 그런데 파일을 저장하거나 네트워크로 데이터를 보내는 것처럼 자원에 접근해야 하는 작업은 read()나 write() 같은 시스템 호출을 통해 커널 모드로 전환돼서 처리돼요. 커널 모드는 운영체제의 핵심 기능이 실행되는 환경이라 자원을 직접 관리하고 보호할 수 있어요. 커널 모드 작업이 끝나면 프로세스는 결과를 받아 다시 사용자 모드로 돌아와요.

이렇게 사용자 모드와 커널 모드를 오가는 작업 방식을 이중 모드 연산(dual mode operation, 듀얼 모드)이라고 해요. C에서 쓰던 printf(), scanf()도 마찬가지예요. 이건 프로그래머가 쉽게 쓰라고 만든 고수준 함수인데, 화면에 글자를 찍거나 키보드 입력을 받으려면 내부적으로 write(), read() 같은 시스템 함수를 불러요. 사용자 모드에서 시작해서, 자원을 쓰는 순간 커널 모드로 바뀌어 시스템 호출을 실행하는 거죠. 우리는 모르고 있었지만 printf 한 줄마다 커널에 들어갔다 나왔던 거예요.

정리하면 컴퓨터에는 사용자 함수(사용자 모드에서 실행)와 커널 함수(커널 모드에서 실행)가 함께 있어요. 사용자 모드에서는 커널 자원에 직접 접근할 수 없고, 시스템 호출을 통해서만 커널 함수에 접근할 수 있어요.

교수
사용자가 자발적으로 커널 모드에 들어갈 수 있는 유일한 방법은 시스템 콜밖에 없어요. 그래서 거기다 색깔로 표시를 해 놨지.9/14 강의 중 (말을 조금 다듬음)

"자발적으로"라는 말에 주목하세요. 비자발적으로 커널 모드에 가는 경우도 있거든요. 사용자가 의도하지 않았어도 프로그램 실행 중 오류가 나면 커널 모드로 바뀌어요. 예를 들어 0으로 나누려고 하거나, 배열 범위를 벗어나 데이터를 저장하려 하면, 커널이 그 오류를 처리하려고 자동으로 커널 모드로 전환해서 예외 처리를 해요.

시험엔 이렇게

이중 모드 연산은 사용자 모드와 커널 모드를 오가는 작업 방식이다. 사용자 모드에서는 커널 자원에 직접 접근할 수 없고 시스템 호출을 통해서만 커널 함수에 접근할 수 있으며, 일반 프로세스가 자발적으로 커널 모드에 진입할 수 있는 유일한 방법은 시스템 호출뿐이다. 0으로 나누기나 배열 범위 초과 같은 오류가 나면 비자발적으로 커널 모드로 전환된다.

외우는 법: 자발적 문은 하나, 시스템 호출 · 비자발 = 오류(0 나누기, 배열 초과)
바로 확인
C 프로그램에서 a = b + c; 다음 줄에 printf("%d", a);가 있다. 각각 어느 모드에서 처리될까?
간단한 계산은 사용자 모드, 화면 출력은 자원을 쓰니까 printf 안의 write() 시스템 호출 → 커널 모드. 끝나면 다시 사용자 모드로 돌아와요.

새 프린터를 꽂으면 왜 "드라이버를 설치하세요"가 뜰까?

디바이스 드라이버 ★ · API ★ · SDK

마우스·키보드·그래픽카드·프린터는 규격이 제각각이에요. 운영체제가 세상 모든 하드웨어에 맞는 인터페이스를 다 갖추는 건 현실적으로 불가능하죠. 그런데 그 하드웨어를 가장 잘 아는 건 만든 회사잖아요? 그래서 하드웨어 제작자가 인터페이스를 설계해서 제공하는 편이 훨씬 효율적이에요. 이게 디바이스 드라이버예요. 교재 그림 속 캐릭터의 말 그대로, 디바이스 드라이버는 커널과 하드웨어 사이의 인터페이스예요.

요즘은 커널이 좋아져서 마우스·키보드는 꽂으면 바로 돼요(플러그 앤 플레이). 하지만 커널의 표준 기능으로는 그래픽카드의 고성능 연산 기능이나 프린터의 다양한 출력 옵션까지 지원하지 못해요. 그래서 이 둘은 지금도 제조사가 주는 드라이버를 설치해서 써야 해요.

API와 SDK — "사람들이 되게 헷갈려 한다"

운영체제가 응용 프로그램에 시스템 함수를 내주듯, 카카오톡 안에서 도는 게임을 만들려면 카카오톡이 제공하는 함수를 써야 해요. 이렇게 특정 플랫폼이나 소프트웨어와 관련된 프로그램을 개발할 수 있도록 제공되는 인터페이스가 API(응용 프로그램 인터페이스)예요. 예를 들어 구글 맵으로 배달 서비스나 길 찾기 서비스를 만든다면, 구글이 제공하는 다양한 함수 = 구글 맵 API를 쓰면 돼요.

그런데 함수만 덜렁 있으면 뭘 하는 함수인지 모르잖아요. 그래서 API뿐 아니라 API 사용 매뉴얼, 코드 편집기, 에뮬레이터 같은 각종 개발 도구를 하나로 묶어 제공하는 종합 개발 도구가 SDK(시스템 개발자 키트)예요. 윈도우 프로그램을 만들 때 쓰는 비주얼 스튜디오, 안드로이드 앱을 만드는 안드로이드 스튜디오가 대표 SDK예요.

디바이스 드라이버는 하드웨어 제작자가 설계하여 제공하는, 커널과 하드웨어 사이의 인터페이스다. API는 특정 플랫폼이나 소프트웨어와 관련된 프로그램을 개발할 수 있도록 제공되는 인터페이스이고, SDK는 API뿐 아니라 API 사용 매뉴얼, 코드 편집기, 에뮬레이터 같은 각종 개발 도구를 하나로 묶어 제공하는 종합 개발 도구다.

★ 교재 별표 · 시험 출제 표시

① P2P와 클라우드

  • 클라이언트-서버 구조는 부하가 서버에 몰려요. 그래서 서버는 중재만 하고 파일은 가진 사람에게서 직접 받는 P2P가 나왔어요(메신저, 블록체인, 파일 공유).
  • 하드웨어·소프트웨어는 중앙에 두고 인터넷으로 필요한 기능만 받는 게 클라우드 컴퓨팅이에요.

② 운영체제 = UI + 커널 ★엔진 + 핸들

  • 운영체제는 사용자와 소통하는 사용자 인터페이스와 자원을 관리하는 커널로 되어 있고, 자원에는 커널이 제공하는 인터페이스를 통해서만 접근할 수 있어요.
  • 커널은 프로세스 관리, 메모리 관리, 저장장치 관리, 입출력 관리를 해요(프·메·저·입).
  • UI는 명령어를 직접 치는 CLI(유닉스 셸, MS-DOS)와 클릭하는 GUI로 나뉘어요. 쉽다/어렵다는 UI 문제지 커널 문제가 아니에요.

③ 시스템 호출 ★ 제일 중요

  • 시스템 호출은 커널이 제공하는 시스템 함수(read, write)를 불러 쓰는 거예요. 프로그램은 직접 접근하지 않고 요청만 하고, 커널이 안전하게 처리한 뒤 결과만 돌려줘요.
  • 직접 쓰게 두면 같은 위치에 덮어쓸 수 있어서, 커널이 자원을 보호하려고 이렇게 해요.

④ 이중 모드 연산 ★

  • 평소엔 사용자 모드, 자원이 필요하면 시스템 호출로 커널 모드, 끝나면 결과를 받고 사용자 모드로. 이렇게 오가는 게 이중 모드 연산이에요. printf·scanf도 안에서 write·read를 불러요.
  • 자발적으로 커널 모드에 들어가는 유일한 방법은 시스템 호출이에요. 0으로 나누기·배열 범위 초과 같은 오류가 나면 비자발적으로 커널 모드로 가서 예외 처리를 해요.

⑤ 드라이버 / API / SDK ★함수 vs 선물 세트

  • 디바이스 드라이버는 하드웨어 제작자가 만들어 주는, 커널과 하드웨어 사이의 인터페이스예요. 그래픽카드·프린터는 지금도 따로 설치해요.
  • API는 특정 플랫폼용 프로그램을 개발하라고 주는 인터페이스(구글 맵 API), SDK는 API에 매뉴얼·코드 편집기·에뮬레이터까지 묶은 종합 개발 도구(안드로이드 스튜디오)예요.

빈칸 채우기 눌러서 정답 확인

운영체제는 사용자 인터페이스와 커널로 이루어지며, 커널은 프로세스·메모리·저장장치·입출력 관리를 수행한다. 명령어를 직접 입력하는 인터페이스는 CLI, 그래픽 인터페이스는 GUI다. 커널이 제공하는 시스템 함수를 호출해 사용하는 것을 시스템 호출이라 하고, 대표적인 시스템 함수로 read()와 write()가 있다. 사용자 모드와 커널 모드를 오가는 작업 방식을 이중 모드 연산이라 하며, 일반 프로세스가 자발적으로 커널 모드에 진입하는 유일한 방법은 시스템 호출이다. 0으로 나누기 같은 오류가 나면 비자발적으로 커널 모드로 전환된다. 커널과 하드웨어 사이의 인터페이스는 디바이스 드라이버이고, API에 매뉴얼·코드 편집기·에뮬레이터를 묶은 종합 개발 도구는 SDK다.

P2P가 만들어진 이유는?
클라이언트-서버 구조의 서버 과부하를 줄이기 위해. 서버는 중재만, 파일은 가진 사용자(peer)에게서 직접 받는다.
클라우드 컴퓨팅이란?
하드웨어와 소프트웨어를 중앙에 두고, 사용자는 인터넷을 통해 필요한 기능만 제공받는 구조.
운영체제의 두 핵심 구성 요소는?
사용자 인터페이스(사용자가 OS와 직접 소통하는 수단)와 커널(컴퓨터 자원을 관리하는 핵심).
커널의 4가지 핵심 기능은?
프로세스 관리, 메모리 관리, 저장장치 관리, 입출력 관리.
CLI와 GUI의 차이는?
CLI는 명령어를 직접 입력하는 문자 기반(유닉스 셸, MS-DOS 명령 프롬프트), GUI는 그래픽 사용자 인터페이스.
시스템 호출이란?
커널이 제공하는 시스템 함수(read, write 등)를 호출하여 사용하는 것. 커널이 자원을 안전하게 처리한 후 결과만 전달한다.
이중 모드 연산이란?
사용자 모드와 커널 모드를 오가는 작업 방식.
일반 프로세스가 자발적으로 커널 모드에 진입하는 유일한 방법은?
시스템 호출.
비자발적으로 커널 모드로 전환되는 경우는?
실행 중 오류가 날 때. 예: 0으로 나누기, 배열 범위를 벗어나 저장. 커널이 예외 처리를 한다.
printf()와 시스템 호출의 관계는?
printf는 고수준 함수이고, 내부적으로 write() 시스템 함수를 호출한다. 그 순간 커널 모드로 전환된다.
디바이스 드라이버란?
하드웨어 제작자가 설계해 제공하는, 커널과 하드웨어 사이의 인터페이스.
API와 SDK의 차이는?
API = 특정 플랫폼·소프트웨어용 프로그램을 개발하도록 제공되는 인터페이스(구글 맵 API). SDK = API + 사용 매뉴얼 + 코드 편집기 + 에뮬레이터 등을 묶은 종합 개발 도구(안드로이드 스튜디오).

    Q1운영체제 구조에 대한 설명으로 옳은 것은?

    하드웨어는 커널 뒤에 숨어 있고, 커널이 제공하는 인터페이스(시스템 호출)를 통해서만 쓸 수 있어요.

    Q2일반 프로세스가 자발적으로 커널 모드에 진입할 수 있는 유일한 방법은?

    교재에 색깔로 표시된 문장이에요. 0으로 나누기도 커널 모드로 가긴 하지만 그건 오류에 의한 비자발적 전환이에요.

    Q3배열 크기가 10인데 arr[50]에 값을 저장하려다 프로그램이 멈췄다. 이때 일어난 일은?

    배열 범위를 벗어나는 저장은 교재가 든 비자발적 커널 모드 전환의 예예요. 커널이 예외 처리를 해요.

    Q4새로 산 그래픽카드의 고성능 연산 기능을 쓰려면 제조사 프로그램을 설치하라고 한다. 이 프로그램은?

    커널 표준으로는 그래픽카드의 고성능 연산 기능이 지원되지 않아서, 하드웨어 제작자가 주는 드라이버(커널과 하드웨어 사이 인터페이스)를 설치해요.

    Q5구글 맵으로 배달 앱의 길 찾기 기능을 만들려고 한다. 구글이 제공하는 함수 모음은?

    특정 플랫폼용 프로그램을 개발하도록 제공되는 인터페이스 = API(구글 맵 API). 매뉴얼·편집기·에뮬레이터까지 묶여 있다면 SDK예요.

    Q6"스마트폰 OS는 유닉스 계열인데도 쓰기 쉽다"는 사실이 보여 주는 것은?

    같은 유닉스 계열이라도 CLI는 어렵게, 터치 GUI는 쉽게 느껴져요. 인터페이스 차이예요.

    Q7커널의 4가지 핵심 기능이 아닌 것은?

    커널 기능 = 프로세스·메모리·저장장치·입출력 관리(프·메·저·입). API는 플랫폼 회사가 개발자에게 주는 인터페이스예요.

    Q8두 프로그램이 하드디스크에 직접 접근해 14와 21을 저장하면 생길 수 있는 문제는?

    교재 그림 1-19 (a) 직접 접근: 같은 위치에 덮어쓸 수 있어요. 그래서 (b)처럼 write() 시스템 호출로 커널이 관리하게 해요.

    내 말로 설명하기 친구한테 말하듯이

    시스템 호출이 무엇이고 왜 필요한지, 이중 모드 연산과 엮어서 설명해 보세요.

    프로그램들이 하드디스크에 마음대로 쓰면 같은 위치에 덮어써서 서로 데이터를 날려 버려요. 그래서 커널은 자원을 숨기고 read()·write() 같은 시스템 함수만 내놓는데, 이 함수를 불러 쓰는 게 시스템 호출이에요. 프로그램은 요청만 하고 커널이 안전하게 처리한 뒤 결과만 돌려줘요. 평소 계산은 사용자 모드에서 하다가 시스템 호출을 부르면 커널 모드로 들어가고, 끝나면 사용자 모드로 돌아와요. 이렇게 오가는 게 이중 모드 연산이고, 일반 프로세스가 자발적으로 커널 모드에 들어가는 유일한 방법이 시스템 호출이에요. 0으로 나누기 같은 오류가 나면 비자발적으로 커널 모드로 가기도 해요.
