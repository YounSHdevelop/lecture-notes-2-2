네 줄 모두 같아요. 교수님 말로 "이진법이니까 말도 안 되는 소리가 성립하는 거예요". 정리하면 한쪽은 결과를 뒤집고, 한쪽은 입력 자체를 뒤집는다. 그러면서 더하기와 곱하기가 바뀐다. 반대 방향도 똑같이 돼요.

드모르간의 정리 (시험에 꼭)

(A + B)′ = A′ · B′     (A · B)′ = A′ + B′

3개 · 4개 · n개도 똑같이: (A + B + C)′ = A′B′C′, (ABC)′ = A′ + B′ + C′

왜 이게 맞는지 대수로도 보일 수 있어요. A′B′가 (A + B)의 보수라면, 둘을 더하면 1, 곱하면 0이어야 하죠. (A + B) + A′B′는 무조건 1이에요. A, B가 둘 다 0이면 A′B′ = 1이 되고, 하나라도 1이면 A + B = 1이니까요. 교수님이 0과 1을 하나씩 넣어 보며 확인한 부분이에요.

시험엔 이렇게

드모르간의 정리는 (A + B)′ = A′B′, (AB)′ = A′ + B′로, 연산 결과를 부정한 것은 각 입력을 부정하고 AND와 OR를 바꾼 것과 같다. 변수가 n개여도 성립하며, 진리표에서 좌변과 우변이 모든 입력 조합에 대해 같음으로 증명한다.

식 위에 길게 그은 바(부정)는 큰 모자예요. A · B · C 위에 큰 모자 하나가 씌워져 있으면, 그걸 작은 모자 3개로 잘라서 각자 씌워 줘요. 대신 모자를 자른 자리의 곱셈은 덧셈으로(덧셈은 곱셈으로) 바꿔요. 모자를 두 번 씌운 곳은 원래대로 돌아오고요(뒤집고 또 뒤집으면 제자리).

세 항이 두 항으로 — 의미 없는 1을 곱해서 증명하기

예제 5-1 · 합의의 정리 · 대수 증명 · 진리표 증명

합의의 정리는 세 항짜리 식이 두 항으로 줄어드는 신기한 법칙이에요. 교수님은 "아무 의미 없는" 걸 끼워 넣는 걸로 시작했어요. BC 항에 (A + A′)를 곱하는 거죠. A + A′는 항상 1이라 곱해도 값은 그대로예요.

AB + BC + A′C = AB + A′C (자료 p.9 · 예제 5-1)AB + BC + A′C
= AB + (A + A′)BC + A′C       // 의미 없는 1을 곱함 (A + A′ = 1)
= AB + ABC + A′BC + A′C       // 전개 → 네 항
= AB(1 + C) + A′C(B + 1)      // 같은 것끼리 묶기
= AB + A′C                    // 1 + X = 1

두 번째 식 (A + B)(B + C)(A′ + C) = (A + B)(A′ + C)는 반대로 (B + C)에 AA′(항상 0)를 더해서 시작해요. 0을 더해도 의미가 없으니까요. 그다음 분배법칙 X + YZ = (X + Y)(X + Z)를 써서 풀어요.

이것도 대수가 헷갈리면 진리표로 8줄을 비교하면 똑같이 나와요. 교수님이 "대수로 해도 되고 진리표로 해도 같다는 걸 볼 수 있다"고 했어요.

시험엔 이렇게

합의의 정리 AB + BC + A′C = AB + A′C는 BC에 (A + A′) = 1을 곱해 전개한 뒤 공통 인수로 묶고 1 + X = 1을 적용해 증명한다. 쌍대인 (A + B)(B + C)(A′ + C) = (A + B)(A′ + C)는 AA′ = 0을 더하고 분배법칙을 써서 증명한다.

논리회로 → 논리식 · 논리식 → 회로 · 보수 입력 vs NOT 게이트

교수님 말로 "회로를 딱 주고 논리식을 적으세요 하면 적을 수 있어야 된다". 방법은 게이트를 하나 지날 때마다 그 출력을 식으로 적으면서 출력 쪽으로 가는 거예요. 게이트 위에 이름(출력식)을 붙여 두면 안 헷갈려요.

회로 → 식 (연습용)[B, C] → AND        → BC
[A, B] → AND        → AB
[BC, AB] → OR       → BC + AB
[B′, C] → AND       → B′C
[(BC + AB), B′C] → AND  → (BC + AB)B′C     // 앞 결과를 다음 게이트로 넘기며 적기

식 → 회로는 반대로 곱(AND)을 먼저 만들고 합(OR)으로 모아요. 여기서 바(′)가 붙은 입력을 그리는 방법이 두 가지예요.

보수 입력을 따로 준비A, A′, B, B′… 입력선이 6개로 늘지만 NOT 게이트가 필요 없다
NOT 게이트 사용입력은 A, B, C 3개뿐 · 대신 선이 복잡해진다. "결과는 똑같다, 편한 쪽으로"

그리고 식 모양은 두 가지가 있어요. 곱을 먼저 하고 나중에 더하는 곱의 합, 더하기를 먼저 하고 나중에 곱하는 합의 곱(인수분해한 모양). 교수님 말로 회로가 깊어지면 "곱셈 덧셈 곱셈 덧셈 계속 반복해서 나중에는 결국 섞인다"고 했어요.

진리표에서 1인 줄만 모으면 식이 된다 — 최소항

SOP(곱의 합) · 최소항(minterm) · m 번호 · Σ 표기 · F′

곱의 합을 영어로 SOP(Sum of Products)라고 해요. 그중 최소항(minterm)은 모든 변수가 다 들어 있는 곱의 항이에요. 변수가 A, B, C, D 4개라면 A′BCD′처럼 네 글자가 다 있어야 최소항이고, 바가 있든 없든 상관없어요. A만 있는 항은 다른 변수가 0이든 1이든 영향을 안 받게 이미 간략화된 항이라 최소항이 아니에요.

변수가 n개면 진리표는 2n줄이고, 최소항도 2n개예요(2개 → 4개, 3개 → 8개, 4개 → 16개). 그런데 매번 A′B′C 이렇게 쓰면 너무 복잡하니까 번호로 써요. 그 줄의 입력을 2진수로 읽은 값이 번호예요.

AB최소항기호F

01A′Bm11

11ABm31

출력이 1인 m1, m2, m3만 모아서(m0은 0이라 의미가 없으니 빼고) F = A′B + AB′ + AB = Σm(1, 2, 3). 시그마(Σ)는 "1인 최소항들을 더한다"는 뜻이에요. 교수님 말로 "여기서부터 출발합니다".

3변수면 m0~m7. 예를 들어 1인 줄이 0, 1, 3, 5, 7이면 F = Σm(0, 1, 3, 5, 7)이고, 나머지 0인 줄 2, 4, 6을 모은 게 F′ = Σm(2, 4, 6)이에요. 0인 줄을 다르게 표현하는 방법(최대항)은 교수님이 "다음 시간에"로 넘겼어요.

시험엔 이렇게

최소항은 함수의 모든 변수를 포함한 표준 곱의 항이다. 진리표에서 출력이 1인 행의 최소항(변수 0은 보수, 1은 그대로)을 OR하면 SOP 형태의 최소항식이 되며 F = Σm(…)으로 표기한다. 출력이 0인 행의 번호를 모으면 F′의 최소항식이 된다.

빈칸 채우기 눌러서 정답 확인

드모르간에 의해 (A + B)′ = A′B′, (AB)′ = A′ + B′이다. 큰 모자를 자르면 곱셈은 덧셈으로 바뀐다. 두 논리식이 같음은 실습, 진리표, 불 대수로 보일 수 있다. 합의의 정리 증명에서는 BC에 A + A′을 곱한다. 모든 변수를 포함한 곱의 항을 최소항이라 하고, 출력이 1인 최소항의 합을 Σ로 표기한다.

플래시카드 알면 →, 모르면 ←

키보드: Space 뒤집기 · → 알아요 · ← 모르겠어요
드모르간의 정리 두 식은?
(A + B)′ = A′B′, (AB)′ = A′ + B′.
드모르간을 말로 하면?
결과를 뒤집은 것 = 입력을 각각 뒤집고 AND와 OR를 바꾼 것.
3항 드모르간은?
(A + B + C)′ = A′B′C′, (ABC)′ = A′ + B′ + C′.
교수님의 '모자' 비유는?
긴 바(부정) = 큰 모자. 잘라서 작은 모자로 나눠 씌우면 곱 ↔ 합이 바뀐다. 두 번 씌우면 벗겨진다.
(AB + C)′를 풀면?
(AB)′C′ = (A′ + B′)C′ = A′C′ + B′C′.
두 논리식이 같음을 보이는 3가지 방법은?
LogicWorks 실습(파형 비교), 진리표, 불 대수 전개.
합의의 정리와 증명 요령은?
AB + BC + A′C = AB + A′C. BC에 (A + A′) = 1을 곱해 전개 → 묶기 → 1 + X = 1.
회로를 논리식으로 적는 법은?
입력에서 출력 쪽으로, 게이트를 지날 때마다 그 출력식을 적어 나간다.
보수 입력을 그리는 두 방법은?
A′ 입력을 따로 준비(입력선 많음) 또는 NOT 게이트 사용(선 복잡). 결과는 같다.
최소항이란?
모든 변수를 포함한 곱의 항(바 유무는 상관없음). 변수 n개면 2ⁿ개.
2변수에서 1인 줄이 01, 10, 11이면?
F = A′B + AB′ + AB = Σm(1, 2, 3).

    퀴즈 다 풀고 채점하기

    Q1(A + B + C)′와 같은 것은?

    합에 씌운 모자를 자르면 곱.

    Q2(AB′)′을 정리하면?

    A′ + (B′)′ = A′ + B.

    Q3(A′ + BC)′을 정리하면?

    A · (BC)′ = A(B′ + C′) = AB′ + AC′.

    Q4교수님이 "누구나 할 수 있다"고 한, 두 식이 같음을 보이는 방법은?

    불 대수는 복잡해지면 쉽지 않아서, 안 되면 진리표로.

    Q5AB + BC + A′C를 간소화하면?

    합의의 정리.

    Q6A, B를 OR → 그 결과와 C를 AND → NOT. 출력식은?

    게이트를 지날 때마다 적기: A + B → (A + B)C → 전체 NOT.

    Q7변수 A, B, C, D인 함수에서 최소항인 것은?

    네 변수가 모두 들어간 곱의 항. 2번은 합(최대항 쪽).

    Q83변수 함수에서 출력이 1인 행이 000, 011, 110이다. F는?

    000 = 0, 011 = 3, 110 = 6. 3번은 F′.

    내 말로 설명하기 실습 과제 4번 · 시험 대비

    "드모르간의 정리를 설명하고, (A + B)′ = A′B′임을 진리표로 증명해 보세요."

    드모르간의 정리는 (A + B)′ = A′B′, (AB)′ = A′ + B′로, 연산한 결과를 부정한 것은 각 입력을 먼저 부정하고 AND와 OR를 서로 바꾼 것과 같다는 법칙이에요. 변수가 3개, 4개, n개여도 똑같이 성립해요. 증명은 A, B의 네 가지 조합 00, 01, 10, 11에 대해 좌변 (A + B)′를 계산하면 1, 0, 0, 0이고, 우변 A′B′도 1·1 = 1, 1·0 = 0, 0·1 = 0, 0·0 = 0으로 1, 0, 0, 0이 나와요. 모든 줄에서 같으므로 두 식은 같아요. 회로로는 NOR 게이트가 입력에 각각 NOT을 단 AND 게이트와 같다는 뜻이고, LogicWorks에서 두 회로의 출력 파형이 같은 것으로도 확인할 수 있어요.
