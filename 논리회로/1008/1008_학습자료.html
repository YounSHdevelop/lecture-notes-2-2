10/6에 식으로 배운 드모르간을 이번엔 회로 두 개로 확인해요. 실습 1 · 4의 질문이 "다음 두 논리회로는 동일한가?"예요.

시험엔 이렇게

드모르간의 정리에 의해 NOR 게이트((A + B)′)는 입력을 각각 반전한 AND 게이트(A′B′)와 같고, NAND 게이트((AB)′)는 입력을 각각 반전한 OR 게이트(A′ + B′)와 같다. 두 회로의 진리표 또는 출력 파형이 모든 입력에서 같으면 동일한 회로다.

논리회로의 논리식 변환 · 논리식의 회로 구성 · AND-OR / OR-AND

회로 → 식: 입력 쪽에서 출발해 게이트를 하나 지날 때마다 그 출력을 식으로 적으면서 출력 쪽으로 한 단계씩 가요(자료 p.17). 예를 들어 A, B가 AND로 들어가 AB, 그게 C와 OR로 들어가면 AB + C, 그 뒤에 NOT이 있으면 (AB + C)′.

식 → 회로: 곱(AND)을 먼저 만들고 그걸 합(OR)으로 모아요. 바(′)가 붙은 변수는 NOT 게이트를 쓰거나 보수 입력을 바로 써요(자료 p.20).

기본 형태구성예
AND-OR1단계 AND들 → 2단계 ORF = A′BC + AB′C + …
OR-AND1단계 OR들 → 2단계 ANDF = (A + B)(A′ + B + C)

OR-AND 형태도 분배법칙으로 전개하면 AND-OR 형태로 바꿀 수 있어요. 단계가 더 많은 다단계 논리회로도 있어요.

출력이 1인 줄마다 곱의 항 하나 — 최소항(minterm)

SOP(곱의 합) · 최소항 m0~m7 · Σm 표기 · 예제 5-3 · 5-4

SOP(Sum of Products, 곱의 합)는 1단계가 AND항(곱), 2단계가 OR(합)인 식이에요. 그중 함수의 모든 변수를 다 포함한 곱의 항을 최소항(minterm)이라고 해요. 변수 4개(A, B, C, D)라면 A′BCD′는 최소항, AC는 변수가 빠져서 최소항이 아니에요.

진리표에서 최소항 뽑기

규칙은 하나예요. 출력이 1인 줄에서, 그 줄의 변수 값이 0이면 바(′), 1이면 그대로 써서 곱하고, 그 항들을 다 더해요.

A B C최소항기호F
0 0 0A′B′C′m01
0 0 1A′B′Cm11
0 1 0A′BC′m20
0 1 1A′BCm31
1 0 0AB′C′m40
1 0 1AB′Cm51
1 1 0ABC′m60
1 1 1ABCm71

그래서 F(A, B, C) = A′B′C′ + A′B′C + A′BC + AB′C + ABC = Σm(0, 1, 3, 5, 7). 기호 m의 번호는 그 줄의 ABC를 2진수로 읽은 값이에요(101 → m5). 반대로 F′는 0인 줄을 모으면 돼요: F′ = Σm(2, 4, 6). (자료 p.28)

최소항이 아닌 식을 최소항식으로 (예제 5-4 방식)

빠진 변수가 있으면 (X′ + X) = 1을 곱해서 채워요. 예: 변수 A, B, C에서 AB는 C가 없으니 AB(C′ + C) = ABC′ + ABC.

시험엔 이렇게

SOP(곱의 합)는 1단계 AND항, 2단계 OR로 이루어진 식이다. 최소항은 함수의 모든 변수를 포함한 표준 곱의 항이며, 진리표에서 출력이 1인 행의 최소항을 OR하여 F = Σm(…)으로 나타낸다(변수 값 0 → 보수, 1 → 그대로).

이번엔 0인 줄을 모아 곱한다 — 최대항(maxterm)

POS(합의 곱) · 최대항 M0~M7 · ΠM 표기 · 최소항과의 보수 관계

POS(Product of Sums, 합의 곱)는 1단계가 OR항(합), 2단계가 AND(곱)인 식이에요. 모든 변수를 포함한 OR항이 최대항(maxterm)이에요. 최대항은 규칙이 최소항과 반대예요.

최소항 m출력 1인 줄 · 변수 0이면 바 · 곱 → 더해서 Σm
최대항 M출력 0인 줄 · 변수 1이면 바 · 합 → 곱해서 ΠM
A B C최소항 mi최대항 Mi
0 0 0A′B′C′ (m0)A + B + C (M0)
0 1 1A′BC (m3)A + B′ + C′ (M3)
1 1 0ABC′ (m6)A′ + B′ + C (M6)

같은 번호의 최소항과 최대항은 서로 보수예요: mi′ = Mi. 드모르간으로 확인해 보면 (A′B′C′)′ = A + B + C = M0이죠. 그래서 같은 함수를 두 가지로 쓸 수 있어요.

예제 5-3 · 5-7 방식 (자료 p.29, p.39)F(A, B, C) = Σm(1, 2, 3, 4, 5)       // 1인 줄: 1~5
           = ΠM(0, 6, 7)              // 0인 줄: 0, 6, 7
F′          = Σm(0, 6, 7) = ΠM(1, 2, 3, 4, 5)

자료 정리로는 "최소항을 부정하면 최대항 형식이 되고, 최대항을 부정하면 최소항 형식이 된다", 그리고 "일반적으로 최소항을 선호한다".

시험엔 이렇게

POS(합의 곱)는 1단계 OR항, 2단계 AND로 이루어진 식이며, 모든 변수를 포함한 OR항을 최대항이라 한다. 최소항은 출력이 1인 항을 SOP로, 최대항은 출력이 0인 항을 POS로 나타낸 것이고 서로 보수 관계(mi′ = Mi)다. Σm(1,2,3,4,5) = ΠM(0,6,7).

외우는 법: m은 1을 모아 더하고 · M은 0을 모아 곱한다 / 번호 합치면 전부(0~7)

다섯 항짜리 식이 두 항으로 줄어든다

불 대수로 간소화 · X + X = X 활용 · 예제 5-9 · 2변수 함수 16개

최소항식은 길어요. 10/6에 배운 법칙으로 줄여요. 핵심 도구는 세 개예요: 묶기(분배), X + X′ = 1, 그리고 같은 항을 하나 더 써도 되는 X + X = X.

F = Σm(0, 1, 3, 5, 7) 간소화F = A′B′C′ + A′B′C + A′BC + AB′C + ABC
  = A′B′(C′ + C) + C(A′B + AB′ + AB)     // 묶기
  = A′B′ + C(A′B + A)                    // C′ + C = 1, AB′ + AB = A
  = A′B′ + C(A + B)                      // A + A′B = A + B (분배 15)
  = A′B′ + AC + BC
  = A′B′ + C                          // C가 1인 줄(1, 3, 5, 7)은 전부 포함돼 있음

마지막 줄은 진리표로도 확인돼요. C = 1인 네 줄(m1, m3, m5, m7)이 다 1이니 그냥 C, 남은 m0(A′B′C′)은 A′B′가 덮어요. 한 줄 정리: F = A′B′ + C. 반대로 F′ = Σm(2, 4, 6) = C′(A + B) = AC′ + BC′.

예제 5-9 방식: F = Σm(1, 2, 3, 4, 5)F = A′B′C + A′BC′ + A′BC + AB′C′ + AB′C
  = A′C(B′ + B) + A′B(C′ + C) + AB′(C′ + C)   // A′BC를 한 번 더 써서(X + X = X) 묶기
  = A′C + A′B + AB′
F′ = Σm(0, 6, 7) = A′B′C′ + AB(C′ + C) = A′B′C′ + AB

덧붙여, 입력이 n개면 진리표 줄은 2n개이고 만들 수 있는 서로 다른 함수는 22ⁿ개예요. 2변수면 16개(F0 = 0, F1 = AB, … F15 = 1), 3변수면 256개.

그런데 이렇게 대수로 줄이는 건 교수님 말대로 "하다 보면 실수할 수도" 있어요. 그래서 다음엔 그림으로 줄이는 카르노 맵이 나와요.

시험엔 이렇게

최소항식은 공통 인수로 묶고 X + X′ = 1, X + X = X(동일 항 추가), 분배 · 흡수법칙을 이용해 간소화한다. n개 입력 변수에서 진리표의 행은 2n개, 서로 다른 함수는 22ⁿ개다.

외우는 법: 짝을 찾아 묶으면 변수 하나가 사라진다 (X′ + X = 1)
바로 확인
AB′C + ABC를 간소화하면?
AC(B′ + B) = AC · 1 = AC. B만 다른 짝이라 B가 사라져요.

빈칸 채우기 눌러서 정답 확인

NOR 게이트는 드모르간에 의해 입력을 각각 반전한 AND 게이트와 같다. 모든 변수를 포함한 곱의 항을 최소항, 합의 항을 최대항이라 한다. 최소항식은 출력이 1인 행을, 최대항식은 출력이 0인 행을 모은 것이다. 같은 번호의 최소항과 최대항은 서로 보수 관계다. 2변수로 만들 수 있는 서로 다른 함수는 16개다.

    내 말로 설명하기 서술형 대비

    "최소항과 최대항의 차이, 그리고 둘의 관계를 진리표를 예로 들어 설명해 보세요."

    최소항은 함수의 모든 변수를 포함한 곱의 항이고, 진리표에서 출력이 1인 행을 골라 변수 값이 0이면 보수로, 1이면 그대로 곱해 만들어요. 이 항들을 OR하면 SOP(곱의 합) 형태의 최소항식 F = Σm(…)이 돼요. 최대항은 모든 변수를 포함한 합의 항이고, 출력이 0인 행을 골라 변수 값이 1이면 보수로 더해 만들고, 이를 AND하면 POS(합의 곱) 형태의 최대항식 F = ΠM(…)이 돼요. 같은 번호의 최소항과 최대항은 서로 보수(mi′ = Mi)라서, 예를 들어 F = Σm(1,2,3,4,5)이면 F = ΠM(0,6,7)이고 F′ = Σm(0,6,7)이에요. 일반적으로는 최소항 표현을 더 많이 써요.
