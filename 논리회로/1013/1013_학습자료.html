시험에 "최소항이 뭐예요?"가 나오면 뭐라고 쓸까?

곱의 합(SOP) · 최소항(minterm) · m 번호 · Σm 표기 · 최소항 고르기

교수님: "시험에 최소항이 뭐예요, 설명하시오 이렇게 나오겠죠"

그러면 들어가야 할 내용이 있어요. 정의 한 줄, 그리고 예시 하나. 그 두 개만 있으면 돼요.

지난 시간에 배운 곱의 합(SOP)부터 다시 볼게요. 곱(AND)으로 묶은 항들을 합(OR)으로 이은 식이에요. 교수님은 "고비합"이라고 불렀죠. 그중에서 모든 변수가 다 들어 있는 곱의 항을 최소항(minterm)이라고 해요.

변수가 A, B, C, D 넷이면 최소항은 A, B, C, D가 바(′)를 달든 안 달든 넷 다 들어 있어야 해요. 그런 최소항이 변수 2개면 4개, 3개면 8개, 4개면 16개 나와요(2ⁿ개).

그런데 간소화가 된 항은 변수가 빠져 있죠. 예를 들어 ABCD + ABCD′를 분배법칙으로 묶으면 ABC(D + D′)가 되고, D + D′ = 1이니까 ABC만 남아요. D가 사라졌죠. 이렇게 변수가 하나라도 빠진 항은 최소항이 아니에요. 교수님이 "이것저것 적어 놓고 최소항을 고르세요"라고 낼 수 있다고 한 게 바로 이 구분이에요.

변수 A, B, C, D일 때최소항?이유
A′BCD′○네 변수가 다 있음
ABCD○네 변수가 다 있음
ABC✗D가 없음 (간소화된 항)
B✗A, C, D가 없음
A + B + C + D✗곱이 아니라 합 → 이건 최대항 쪽(장면 2)

번호 붙이기와 Σ 표기

진리표에서 각 줄의 입력을 2진수로 읽은 값이 그 최소항의 번호예요. 0은 바(′)를 달고, 1은 그대로 써요. 000이면 A′B′C′ = m₀, 101이면 AB′C = m₅. 그리고 출력이 1인 줄의 번호만 모아서 Σ(시그마)로 써요.

시험엔 이렇게

최소항(minterm)은 모든 변수를 포함하는 AND항(곱의 항)이다. n개 변수에서 2ⁿ개가 있으며, 입력이 0인 변수는 보수(′)로, 1인 변수는 그대로 쓴다. 진리표에서 출력이 1인 행의 최소항을 OR로 묶은 것이 최소항식이며 F = Σm(…)으로 표기한다. 예: 4변수에서 A′BCD′는 최소항, ABC는 D가 없으므로 최소항이 아니다.

외우는 법: 최소항 = 변수 전원 출석한 곱 · 0은 바, 1은 그대로 · 1인 줄을 모아 Σ

장면 2

이번엔 0인 줄을 모은다 — 최대항은 왜 0일 때 바를 안 붙일까?

합의 곱(POS) · 최대항(maxterm) · M 번호(대문자) · ΠM 표기 · 진리표 빈칸 채우기 ★

곱의 합을 뒤집으면 합의 곱(POS)이에요. 합(OR)으로 묶은 항들을 곱(AND)으로 이은 식이죠. (A + B + C)(A′ + B′ + C)처럼 괄호로 묶여 있어서 인수분해한 모양처럼 보여요. 그리고 모든 변수를 포함하는 OR항을 최대항(maxterm)이라고 해요. 최소항처럼 변수가 하나라도 빠지면 최대항이 아니에요.

표기에서 헷갈리는 게 두 가지 있어요.

  • 기호는 대문자 M, 모을 때는 Σ 대신 Π(파이)를 써요. 최소항은 소문자 m.
  • 0이면 그대로, 1이면 바(′)를 붙여요. 최소항과 정반대죠. 000이면 A + B + C = M₀, 001이면 A + B + C′ = M₁.

왜 반대일까요? 최대항은 그 줄에서만 0이 나와야 하는 OR항이거든요. OR가 0이 되려면 안에 든 것이 전부 0이어야 해요. 001 줄에서 A + B + C′를 계산하면 0 + 0 + 1′ = 0 + 0 + 0 = 0. 딱 이 줄에서만 0이 돼요. 그래서 1인 자리에 바를 달아 0으로 만들어 주는 거예요.

시험엔 이렇게

최대항(maxterm)은 모든 변수를 포함하는 OR항(합의 항)이다. 입력이 0인 변수는 그대로, 1인 변수는 보수(′)로 쓰고 기호는 대문자 M을 쓴다. 진리표에서 출력이 0인 행의 최대항을 AND로 묶은 것이 최대항식(합의 곱, POS)이며 F = ΠM(…)으로 표기한다.

외우는 법: 최소 = 1 모아 Σm, 0에 바 / 최대 = 0 모아 ΠM, 1에 바
✗ 틀린 생각011 줄의 최대항은 A′ + B + C (0에 바를 단다)
○ 맞는 생각최대항은 1에 바: 011 → A + B′ + C′ = M₃
바로 확인
3변수에서 입력 1 1 0 줄의 최대항과 기호는?
최대항은 1인 자리에 바: A와 B가 1이니 A′, B′, C는 0이니 그대로 → A′ + B′ + C. 110 = 6이라 M₆. ABC′는 같은 줄의 최소항 m₆이에요.

장면 3

D가 없는 항을 최대항으로 만들려면, 아무거나 붙이면 안 되는 이유

간소화의 거꾸로 · 최소항식 변환(예제 5-4) · 최대항식 변환(예제 5-6) · 분배법칙 ★ · 적용된 법칙 묻기

지금까지는 식을 줄이는 간소화를 했죠. 이번엔 거꾸로 가요. 변수가 빠진 항에 그 변수를 다시 채워 넣어서 모든 항을 최소항(또는 최대항)으로 만드는 거예요. 교수님: "간소화시키는 게 아니고 거꾸로 가는 거예요."

그런데 그냥 D를 붙이면 식의 값이 바뀌어 버리죠. 교수님 표현으로는 "오염이 되잖아". 그래서 값을 안 바꾸는 것만 붙여야 해요.

  • 최소항으로 만들 때(곱의 항): 1을 곱해도 값이 안 변하죠. 그래서 (D + D′) = 1을 곱해요.
  • 최대항으로 만들 때(합의 항): 0을 더해도 값이 안 변하죠. 그래서 DD′ = 0을 더해요.

예제 5-4: 최소항식으로 (1을 곱한다)

F(A, B, C, D) = AB′C + A′B′ + ABC′DAB′C  = AB′C(D′ + D)              = AB′CD′ + AB′CD          // D가 없으니 (D′ + D) = 1을 곱함
A′B′   = A′B′(C′ + C)(D′ + D)
       = A′B′C′D′ + A′B′C′D + A′B′CD′ + A′B′CD        // C, D 둘 다 없으니 두 개 곱함
ABC′D  // 이미 최소항
F = Σm(0, 1, 2, 3, 10, 11, 13)

예제 5-6: 최대항식으로 (0을 더하고 분배법칙)

F(A, B, C, D) = (A + B′ + C)(B′ + C + D′)(A + B′ + C′ + D)A + B′ + C = A + B′ + C + DD′                  // D가 없으니 DD′ = 0을 더함
          = (A + B′ + C + D)(A + B′ + C + D′)    // 분배법칙 X + YZ = (X + Y)(X + Z)
B′ + C + D′ = AA′ + B′ + C + D′
          = (A′ + B′ + C + D′)(A + B′ + C + D′)  // A가 없으니 AA′ = 0을 더하고 분배
A + B′ + C′ + D  // 이미 최대항
F = ΠM(4, 5, 6, 13)  // 겹친 (A + B′ + C + D′)는 하나만 (X · X = X)

둘째 줄이 핵심이에요. X = A + B′ + C, Y = D, Z = D′로 보면 X + YZ = (X + Y)(X + Z), 일반 수학에는 없는 그 분배법칙(10/6 실습 과제 3)이에요. 교수님이 이 대목에서 바로 물었어요. "이게 무슨 법칙? 분배법칙. 시험에 여기 적힌 법칙이 뭐냐고 나오면 분배법칙이라고 써야 돼."

최소항식으로 변환할 때는 없는 변수 X에 대해 (X + X′) = 1을 곱해 전개하고, 최대항식으로 변환할 때는 XX′ = 0을 더한 뒤 분배법칙 A + BC = (A + B)(A + C)로 나눈다. 1을 곱하거나 0을 더하므로 식의 값은 변하지 않는다(공리 X + X′ = 1, X · X′ = 0, X · 1 = X, X + 0 = X).

Σm(1, 2, 3, 4, 5)를 ΠM으로 바꾸면 번호는 어떻게 될까?

최소항과 최대항의 관계 · 상호 보수 · Mᵢ = mᵢ′ · 드모르간으로 증명 · 관계표(p.41) · 예제 5-7

교수님이 이 부분을 길게 한 이유는 딱 하나예요. "드모르간하고 연관을 지어 보려고." 결론부터 말하면 같은 번호의 최소항과 최대항은 서로 보수예요. M₃ = m₃′. 실제로 m₃ = A′BC에 드모르간을 쓰면 (A′BC)′ = A + B′ + C′ = M₃가 나와요.

모자를 두 번 씌우고 하나씩 자르기 (p.39)

F = Σm(1, 2, 3, 4, 5)F = A′B′C + A′BC′ + A′BC + AB′C′ + AB′C
  = ((A′B′C + A′BC′ + A′BC + AB′C′ + AB′C)′)′        // 모자 두 번 = 그대로 (이중 부정)
  = ((A′B′C)′ · (A′BC′)′ · (A′BC)′ · (AB′C′)′ · (AB′C)′)′   // 안쪽 큰 모자를 자름: + → · (드모르간)
  = ((A + B + C′)(A + B′ + C)(A + B′ + C′)(A′ + B + C)(A′ + B + C′))′
  = (ΠM(1, 2, 3, 4, 5))′

즉 Σm(1, 2, 3, 4, 5) = ΠM(1, 2, 3, 4, 5)에 모자를 씌운 것이에요. 그런데 진리표로 보면 F가 0인 줄은 0, 6, 7번이니까 F = ΠM(0, 6, 7)이기도 해요. 그래서 이렇게 네 개가 다 같아요.

같은 F를 쓰는 네 가지읽는 법
Σm(1, 2, 3, 4, 5)1인 줄을 모은 최소항식
ΠM(0, 6, 7)0인 줄을 모은 최대항식 — 나머지 번호
(ΠM(1, 2, 3, 4, 5))′같은 번호, 기호만 바꾸면 모자를 씌워야 함
(Σm(0, 6, 7))′F′ = Σm(0, 6, 7)이니까 그걸 뒤집은 것

교수님의 정리: "드모르간을 딱 정리해 보니까, 번호는 같게 적고 시그마를 파이로 바꾸면 위에 큰 모자를 씌워야 돼." 반대로 모자 없이 Σ ↔ Π를 바꾸려면 나머지 번호를 쓰면 돼요.

시험엔 이렇게

최소항은 출력이 1인 항을 SOP로, 최대항은 출력이 0인 항을 POS로 나타낸 것이며 둘은 상호 보수 관계(Mᵢ = mᵢ′)다. 최소항을 부정하면 최대항, 최대항을 부정하면 최소항 형식이 된다. 같은 함수에서 Σm과 ΠM의 번호는 서로 나머지이다. 예: Σm(1, 2, 3, 4, 5) = ΠM(0, 6, 7).

★ 시험에 나온다고 한 것

① 최소항 ★ 설명 · 고르기

  • 최소항 : 모든 변수를 포함하는 곱(AND)항. 0이면 바, 1이면 그대로. 기호 소문자 m
  • 최소항식 : 출력이 1인 줄의 최소항을 OR로 묶은 식(SOP). F = Σm(…)

② 최대항 ★ 표 빈칸

  • 최대항 : 모든 변수를 포함하는 합(OR)항. 0이면 그대로, 1이면 바. 기호 대문자 M
  • 최대항식 : 출력이 0인 줄의 최대항을 AND로 묶은 식(POS). F = ΠM(…)

③ 변환 ★ 법칙 묻기

  • 최소항식으로 : 없는 변수 X에 (X + X′) = 1을 곱해서 전개
  • 최대항식으로 : XX′ = 0을 더한 뒤 분배법칙 X + YZ = (X + Y)(X + Z)로 나눔

④ 관계 모자 없이 = 나머지 번호

  • 같은 번호의 최소항과 최대항은 상호 보수 : Mᵢ = mᵢ′ (드모르간)
  • Σm(1, 2, 3, 4, 5) = ΠM(0, 6, 7) = (ΠM(1, 2, 3, 4, 5))′ · F′ = Σm(0, 6, 7)

⑤ 간소화 · 실습 5

  • A′B′C′ + A′BC′ + A′BC + AB′C′ = B′C′ + A′B (분배 → X + X′ = 1 → X · 1 = X)
  • 짝이 남으면 X + X = X로 같은 항 추가 · 카르노 맵은 시험 범위 아님

빈칸 채우기 눌러서 정답 확인

모든 변수를 포함하는 AND항을 최소항, 모든 변수를 포함하는 OR항을 최대항이라 한다. 최소항은 출력이 1인 행을 모아 Σm으로, 최대항은 출력이 0인 행을 모아 ΠM으로 나타낸다. 3변수에서 입력 101의 최소항은 AB′C, 최대항은 A′ + B + C′이다. 최대항식으로 바꿀 때 없는 변수 D에 대해 DD′를 더하고 분배법칙으로 나눈다. Σm(1, 2, 3, 4, 5)를 최대항식으로 쓰면 ΠM(0, 6, 7)이다.

최소항(minterm)이란?
모든 변수를 포함하는 AND항(곱의 항). n변수면 2ⁿ개. 0인 변수는 보수, 1인 변수는 그대로.
최대항(maxterm)이란?
모든 변수를 포함하는 OR항(합의 항). 0인 변수는 그대로, 1인 변수는 보수. 기호는 대문자 M.
SOP와 POS는?
SOP = 곱의 합(AND항을 OR로), POS = 합의 곱(OR항을 AND로).
Σm과 ΠM은 각각 어떤 줄을 모을까?
Σm은 출력이 1인 줄, ΠM은 출력이 0인 줄.
4변수에서 ABC는 최소항일까?
아니다. D가 없다(간소화된 항). 최소항은 네 변수가 모두 있어야 한다.
3변수 011의 최소항 · 최대항은?
최소항 A′BC = m₃, 최대항 A + B′ + C′ = M₃.
최소항식으로 바꿀 때 없는 변수는 어떻게 넣나?
(X + X′) = 1을 곱해서 전개한다(1을 곱해도 값은 그대로).
최대항식으로 바꿀 때 없는 변수는 어떻게 넣나?
XX′ = 0을 더한 뒤 분배법칙 X + YZ = (X + Y)(X + Z)로 나눈다.
최소항과 최대항의 관계는?
상호 보수. Mᵢ = mᵢ′. 같은 함수의 Σm과 ΠM 번호는 서로 나머지.
Σm(1, 2, 3, 4, 5)를 ΠM으로?
ΠM(0, 6, 7). (같은 번호로 쓰면 (ΠM(1, 2, 3, 4, 5))′처럼 모자를 씌워야 함)
예제 5-8(실습 5)의 간소화 결과는?
A′B′C′ + A′BC′ + A′BC + AB′C′ = B′C′ + A′B.
짝이 안 맞을 때 같은 항을 더 써도 되는 근거는?
X + X = X (자기 자신을 더해도 그대로).

    Q14변수 A, B, C, D에서 최소항이 아닌 것은?

    A′BD는 C가 빠져 있어서 최소항이 아니에요. 나머지는 네 변수가 다 있는 곱이에요.

    Q24변수에서 입력 1 0 0 1의 최대항과 기호는?

    최대항은 1에 바: A와 D가 1이니 A′, D′. 1001 = 9라서 M₉. AB′C′D는 같은 줄의 최소항 m₉예요.

    Q3진리표에서 F가 0인 줄이 1 · 4 · 6번이다(3변수). F의 최소항식은?

    1인 줄은 나머지 0 · 2 · 3 · 5 · 7. 최대항식으로 쓰면 ΠM(1, 4, 6)이에요.

    Q4F(A, B) = (A + B)(A + B′)(A′ + B)를 ΠM으로 쓰면? (교재 p.35)

    A + B = M₀(00), A + B′ = M₁(01), A′ + B = M₂(10). 그래서 ΠM(0, 1, 2)이고, F는 11일 때만 1이에요.

    Q5AB′C를 4변수 최소항식으로 바꾸려면?

    1을 곱해야 값이 안 변해요. D + D′ = 1. D만 곱하면 식이 바뀌어요("오염"). DD′를 더하는 건 최대항식 변환 때예요.

    Q6F = Σm(0, 3, 5, 6)일 때 F′의 최대항식은? (3변수)

    F′는 F의 0인 줄(1 · 2 · 4 · 7)이 1이에요. F′의 0인 줄은 F가 1인 0 · 3 · 5 · 6 → F′ = ΠM(0, 3, 5, 6). F의 Σm 번호 = F′의 ΠM 번호.

    Q7A′B′C′ + AB′C′ = B′C′(A′ + A)에 쓰인 법칙은?

    공통인 B′C′를 밖으로 묶었으니 분배법칙이에요. 그다음 A′ + A = 1이 공리예요.

    Q8A′BC′ + A′BC + AB′C′ + AB′C + ABC를 간소화한 결과로 옳은 것은?

    AB′C를 한 번 더 써서(X + X = X) ABC와 묶으면 AC(B + B′) = AC. A′B + AB′ + AC (p.44). A′B + AB′ + BC도 같은 함수라 정답이 될 수 있어요. A′B + AB′만 쓰면 m₇(ABC)이 빠져요.

    내 말로 설명하기 친구한테 말하듯이

    "최소항이 뭐예요?"라는 시험 문제에 답한다고 생각하고, 최대항과 무엇이 다른지까지 설명해 보세요.

    최소항은 모든 변수를 포함하는 AND항이에요. 입력이 0인 변수는 보수로, 1인 변수는 그대로 쓰고, n개 변수면 2ⁿ개가 있어요. 예를 들어 3변수 101의 최소항은 AB′C(m₅)예요. 진리표에서 출력이 1인 줄의 최소항을 OR로 묶으면 최소항식(SOP)이고 Σm으로 써요. 최대항은 반대로 모든 변수를 포함하는 OR항이고 0이면 그대로, 1이면 보수를 써요(101 → A′ + B + C′ = M₅). 출력이 0인 줄을 AND로 묶어 ΠM으로 써요. 같은 번호의 최소항과 최대항은 서로 보수예요.

    변수 n개로 만들 수 있는 함수의 수
