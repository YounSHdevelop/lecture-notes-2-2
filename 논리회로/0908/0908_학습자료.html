한국 TV를 폴란드에 가져가면 왜 못 쓸까?

펄스 · 클록 · 주기 T와 주파수 f

숫자가 1, 2, 3 바뀌는 카운터를 만들려면 뭔가 "쿵, 쿵" 박자를 쳐 줘야 해요. 사람이 살려면 심장이 뛰어야 하듯, 회로도 심장이 필요해요. 0V → 5V → 0V를 일정하게 반복하는 신호, 이게 펄스이고 회로의 심장 역할을 하는 펄스를 클록이라고 해요.

같은 모양이 반복되니 두 가지로 말할 수 있어요.

  • 주기 T — 한 번 반복하는 데 몇 초 걸리나 (단위: 초)
  • 주파수 f — 1초에 몇 번 반복하나 (단위: Hz)

주기가 0.1초면 1초에 10번이니까 주파수는 10Hz. 같은 걸 뒤집어서 말한 것뿐이에요. 그래서 공식도 그냥 뒤집기예요: T = 1/f, f = 1/T.

교수
우리나라 콘센트는 220V에 60Hz예요. 그런데 폴란드로 이민을 가면 TV, 냉장고를 다 버려야 돼. 거긴 50Hz를 쓰거든. 그래서 삼성도 나라별로 다르게 만들어 팔아요. 50Hz면 주기는 1/50, 0.02초겠죠.9/8 강의 중 (말을 조금 다듬음)
시험엔 이렇게

주기와 주파수는 역수 관계다. T = 1/f, f = 1/T.

외우는 법: 주기 · 주파수는 뒤집기 (μs를 뒤집으면 MHz)
바로 확인
주기가 0.5초인 펄스의 주파수는?
f = 1/T = 1/0.5 = 2Hz. 1초에 두 번 반복해요.

시험 무조건 나오는 그 문제: 펄스 폭 50μs, 주기 250μs

펄스 폭 tw · 듀티 사이클 · 예제 1-4 · 1-5

한 주기 안에서 신호가 High(1)로 떠 있는 시간이 펄스 폭 tw예요. 그리고 한 주기 중 High인 비율을 퍼센트로 나타낸 게 듀티 사이클이에요. 주기 1초에 0.5초 동안 High면 듀티는 50%, 딱 반반이죠.

듀티 사이클 공식듀티 사이클 = tw / T × 100 (%)

예제 1-4 — 같이 풀어 봐요

펄스 폭이 50μs이고 주기가 250μs인 주기 파형의 주파수와 듀티 사이클을 구하라

μs(마이크로초) = 10⁻⁶초. 교수님 팁: 단위는 잠깐 떼고 숫자만 계산한 다음 붙이세요.

① 주파수f = 1 / T = 1 / 250μs
1/250 = 0.004,  μs를 뒤집으면 × 10⁶
0.004 × 10⁶ = 4000Hz = 4kHz

② 듀티 사이클50 / 250 × 100 = 20%      -- 250은 50의 5배 → 1/5 = 20%
교수
쉽죠? 엄청 쉽다. 이해했지? 다 알면 10문제 낼게. 여러분들 점수 주려고 10문제 나오면 틀리면 안 된다.9/8 강의 중 (말을 조금 다듬음)

예제 1-5 — 반대로 주파수에서 시작

주파수 250Hz면 주기 T = 1/250 = 0.004초 = 4ms. 여기서 듀티가 25%면 4ms 중 1ms만 High, 50%면 2ms, 75%면 3ms예요. 0%는 내내 Low, 100%는 내내 High.

시험엔 이렇게

tw = 50μs, T = 250μs → f = 1/T = 4kHz, 듀티 사이클 = tw/T × 100 = 20%.

외우는 법: 주파수는 뒤집기, 듀티는 폭 ÷ 주기
바로 확인 (변형 문제)
펄스 폭 20μs, 주기 100μs인 파형의 주파수와 듀티 사이클은?
f = 1/100μs = 0.01 × 10⁶ = 10kHz. 듀티 = 20/100 × 100 = 20%.

펄스를 일부러 살짝 기울이는 이유는? 자동차 점프 케이블의 번개

상승 에지 · 하강 에지 · 상승 시간

펄스에서 위로 올라가는 순간과 아래로 내려가는 순간에 이름이 있어요. 같은 뜻의 이름이 세 개씩이라 헷갈리니 묶어서 외워요.

올라가는 순간내려가는 순간
상승 에지 = 리딩(leading) = 포지티브(positive) = 라이징하강 에지 = 트레일링(trailing) = 네거티브(negative) = 폴링

왜 이런 걸 따로 부를까요? High "레벨"을 기준으로 동작하면 "언제" 동작해야 할지 애매해요. 그래서 올라가는/내려가는 순간(에지)을 기준으로 동작하는 회로를 많이 써요.

실제 펄스는 수직이 아니다

이상적인 펄스는 0에서 5V로 순식간에 수직으로 올라가요. 그런데 실제로 그렇게 만들면 회로가 오동작해요. 아주 짧은 시간에 전압이 확 변하면(dv/dt가 무한대) 커패시터에 번개 같은 전류가 흐르거든요. 그래서 일부러 10%쯤 기울여서 올려요. 이 시간이 상승 시간 tr, 내려가는 시간이 하강 시간 tf예요.

교수님 비유 — 방전된 차에 옆 차 배터리(12V)를 점프 케이블로 연결하는 순간 "팍!" 하고 불꽃이 튀죠. 0V가 순식간에 12V로 바뀌어서 전류가 확 흐르는 거예요. 번개가 하늘에서만 치는 게 아니에요.
시험엔 이렇게

이상적인 펄스는 두 개의 에지로 구성된다: 리딩 에지 = 상승 에지, 트레일링 에지 = 하강 에지.

외우는 법: 리 · 라 · 포 = 위로 / 트 · 폴 · 네 = 아래로
바로 확인
트레일링 에지와 같은 말은?
트레일링 = 하강 = 네거티브 = 폴링. 리딩이 상승이에요.

리모컨 "1번" 버튼과 "채널 업" 버튼은 속이 다르다

조합논리회로 · 순서논리회로

리모컨 안에는 논리회로가 잔뜩 들어 있어요. 버튼 두 종류를 비교해 봐요.

숫자 버튼 "1번""채널 업" 버튼
누르면지금 몇 번이든 무조건 1번지금 5번이면 6번, 8번이면 9번
성격절대적 — 과거를 몰라도 됨상대적 — 지금 상태를 기억해야 함
회로조합논리회로순서논리회로

조합논리회로는 기본 게이트(AND, OR, NOT…)를 조합해서 만든 회로예요. 입력이 들어오면 출력이 바로 정해지고 기억이 없어요. 예: 덧셈하는 가산기.

순서논리회로는 조합논리회로에 기억하는 부품(플립플롭, 메모리)을 더한 회로예요. 현재 상태를 기억했다가 그걸 바탕으로 다음 상태로 넘어가요. 예: 카운터, 타이머, 채널 업·다운, 볼륨 업·다운.

교수
조합논리는 기억이 없어. 과거가 없어. 난 몰라, 지금 태어났어. 그런데 저장 요소가 한 개라도 개입하면, 전체를 순서논리라고 해요.9/8 강의 중 (말을 조금 다듬음)
시험엔 이렇게

조합논리회로 = 기본 게이트의 조합(기억 없음). 순서논리회로 = 조합논리회로 + 플립플롭·메모리(저장 요소). 저장 요소가 하나라도 있으면 전체가 순서논리회로.

외우는 법: 숫자 버튼 = 조합, 업다운 = 순서 / 기억 있으면 순서
✗ 헷갈리는 생각조합논리회로가 들어 있으면 조합논리회로다
○ 맞는 생각저장 요소가 하나라도 섞이면 전체가 순서논리회로
바로 확인
전자레인지 타이머(1분 → 59초 → 58초…)는 어떤 회로일까?
지금 상태(남은 시간)를 기억해서 다음 상태로 가니까 순서논리회로예요.

내 목소리를 0과 1로 바꾸려면 1초에 몇 번 찍어야 할까?

ADC 3단계 · 샤논 정리 · DAC 계산 (예제 1-6)

ADC: 아날로그 → 디지털, 3단계

  1. 표본화(샘플링) — 매끈한 곡선 위에 일정 간격으로 점을 찍어요.
  2. 양자화 — 찍은 점의 값을 정수로 맞춰요. 0.9 → 1. 여기서 양자화 오차(0.1)가 생겨요.
  3. 부호화 — 정수를 2진 부호로 바꿔요. 1 → 0001, 3 → 0011.

점을 더 자주 찍으면 곡선에 더 가까워지지만, 데이터가 너무 많아지면 메모리도 많이 먹고 통신도 힘들어요. 그럼 얼마나 자주 찍어야 할까요?

샤논(Shannon)의 답: 최고 주파수의 2배 이상으로만 찍으면 된다

사람 목소리는 대략 4kHz까지 나와요. 그 2배인 8kHz, 즉 1초에 8000번만 찍으면 원래 소리로 완벽하게 되돌릴 수 있어요. 그보다 더 찍어도 데이터만 늘지 이득이 없어요.

DAC: 디지털 → 아날로그, 비례 계산 (예제 1-6)

8bit DAC에 0011 0010을 넣었더니 1.0V. 최대 입력이면?0011 0010 = 32 + 16 + 2 = 50          -- 자리값 128 64 32 16 8 4 2 1
8bit 최대  = 1111 1111 = 255
50 : 1V = 255 : x   →   x = 255 / 50 = 5.1V

DAC 출력은 입력 값에 비례하니까 비례식 하나면 끝이에요. 마이크 → 앰프 → ADC → CD 제작 → CD 플레이어 DAC → 앰프 → 스피커가 대표적인 흐름이에요.

시험엔 이렇게

ADC = 표본화 → 양자화 → 부호화. 샤논 정리: 최고 주파수의 2배 이상으로 샘플링하면 원신호 복구 가능. DAC 출력은 디지털 값에 비례.

외우는 법: 표 · 양 · 부 / 두 배면 충분
바로 확인
최고 주파수가 10kHz인 신호를 디지털로 바꿀 때, 샤논 정리에 따른 최소 샘플링 주파수는?
최고 주파수의 2배 = 20kHz. 그 이상은 데이터만 늘어요.

"키워드 가리기"를 누르면 형광펜 부분이 가려져요. 눌러서 하나씩 확인하세요.

= 정의 · → 흐름 · / 대비 · ★ 출제

① 주기 · 주파수 · 듀티 ★ 무조건 출제

  • T = 1/f · f = 1/T · 듀티 = tw/T × 100
  • 예제 1-4: 50μs / 250μs → 4kHz, 20%
  • 예제 1-5: 250Hz → 4ms, 듀티 25% = 1ms High

② 에지 리라포 위 · 트폴네 아래

  • 상승 = 리딩 = 포지티브 / 하강 = 트레일링 = 네거티브
  • 수직이면 dv/dt = ∞ → 번개 전류 → 상승 시간 tr을 일부러 둠

③ 조합 / 순서 ★

  • 조합 = 게이트 조합, 기억 없음 (숫자 버튼, 가산기)
  • 순서 = 조합 + 플립플롭·메모리 (업다운, 카운터, 타이머)

④ ADC · DAC 표 · 양 · 부

  • ADC = 표본화 → 양자화(오차) → 부호화
  • 샤논: 최고 주파수의 2배 이상 (목소리 4kHz → 8kHz)
  • 예제 1-6: 50 → 1V면 255 → 5.1V

빈칸 채우기 눌러서 정답 확인

이상적인 주기 펄스는 두 개의 에지로 구성되며, 리딩 에지는 상승 에지, 트레일링 에지는 하강 에지다. 주기와 주파수의 관계는 T = 1/f이고, 듀티 사이클은 펄스 폭 ÷ 주기 × 100%다. 펄스 폭 50μs, 주기 250μs인 파형의 주파수는 4kHz, 듀티 사이클은 20%다. 순서논리회로는 조합논리회로에 플립플롭 또는 메모리를 더한 것이다. 샤논 정리에 따르면 최고 주파수의 2배 이상으로 샘플링한다.

키보드: Space 뒤집기 · → 알아요 · ← 모르겠어요
예제 1-4: 펄스 폭 50μs, 주기 250μs → 주파수와 듀티는?
f = 1/250μs = 4kHz, 듀티 = 50/250 × 100 = 20%
예제 1-5: 250Hz 펄스의 주기와, 듀티 75%일 때 High 시간은?
T = 4ms. 75%면 3ms High.
예제 1-6: 8bit DAC에서 0011 0010이 1.0V면 255는?
0011 0010 = 50. 50 : 1V = 255 : x → 5.1V
상승 에지와 하강 에지의 다른 이름은?
상승 = 리딩 = 포지티브(라이징). 하강 = 트레일링 = 네거티브(폴링).
실제 펄스에 상승 시간을 두는 이유는?
수직이면 dv/dt가 무한대가 되어 커패시터에 번개 같은 전류가 흘러 오동작하기 때문.
주기 0.02초의 주파수는?
50Hz (폴란드 등 유럽). 한국은 60Hz.
리모컨 숫자 버튼과 채널 업 버튼은 각각?
숫자 버튼 = 조합논리(절대적, 기억 없음). 업다운 = 순서논리(현재 상태 기억).
순서논리회로의 정의는?
조합논리회로 + 플립플롭·메모리 같은 저장 요소. 하나라도 있으면 전체가 순서논리.
ADC 3단계는?
표본화(점 찍기) → 양자화(정수화, 오차 발생) → 부호화(2진 부호)
샤논 정리(샘플링 정리)는?
최고 주파수의 2배 이상으로 샘플링하면 원신호를 복구할 수 있다.

    퀴즈 다 풀고 채점하기

    Q1펄스 폭 50μs, 주기 250μs인 주기 파형의 주파수는? (예제 1-4)

    1/250μs = 0.004 × 10⁶ = 4000Hz = 4kHz.

    Q2같은 파형의 듀티 사이클은?

    50/250 × 100 = 20%. 250이 50의 5배라 1/5.

    Q3주파수 250Hz, 듀티 사이클 25%인 펄스에서 한 주기 중 High 시간은?

    T = 1/250 = 4ms. 그중 25% = 1ms (예제 1-5).

    Q4리모컨의 채널 업 버튼을 구현하는 회로와 그 이유는?

    현재 상태에 의존 → 저장 요소(플립플롭) 필요 → 순서논리.

    Q5ADC의 단계 순서로 옳은 것은?

    점 찍기 → 정수화 → 2진 부호 (표 · 양 · 부).

    Q68bit DAC에서 입력 50일 때 출력 1.0V였다. 입력 255(최대)일 때 출력은?

    비례식 50 : 1 = 255 : x → x = 5.1V (예제 1-6).

    Q7리딩 에지와 같은 뜻이 아닌 것은?

    네거티브는 하강(트레일링) 쪽이에요.

    내 말로 설명하기 친구한테 말하듯이

    조합논리회로와 순서논리회로의 차이를 리모컨 버튼으로 설명해 보세요.

    리모컨 숫자 1번 버튼은 지금 몇 번 채널을 보고 있든 무조건 1번으로 가요. 과거를 기억할 필요가 없으니 기본 게이트만 조합한 조합논리회로로 충분해요. 채널 업 버튼은 지금 5번이면 6번, 8번이면 9번으로 가니까 현재 채널을 기억해야 해요. 그래서 플립플롭 같은 저장 요소가 필요하고, 저장 요소가 하나라도 들어가면 순서논리회로예요.

    부논리가 실제로 쓰이는 예: 풀업 저항 스위치

    스위치 위쪽은 저항을 거쳐 5V, 아래쪽은 접지(0V)예요. 평소엔 저항을 통해 5V가 들어와 논리 1, 스위치를 누르면 접지로 연결돼 0V가 들어와 논리 0이에요. "누른다"는 동작이 0으로 표현되는 부논리죠. 저항이 없으면 누르는 순간 5V와 0V가 바로 이어져 합선돼요. 0을 받을 때 잡음에 덜 민감해서 입력 쪽엔 지금도 부논리를 많이 써요.

    IC 패키지: DIP와 SMD

    DIP(듀얼 인라인 패키지)는 기판에 구멍을 뚫어 다리를 꽂는 삽입 장착형, SMD는 기판 표면에 나비처럼 살짝 얹는 표면 실장형이에요. SMD가 훨씬 작고 가벼워서 스마트폰처럼 작게 만들 땐 무조건 SMD. 반면 전기차 모터 드라이브처럼 열이 많이 나는 전력전자 분야는 튼튼하고 방열이 좋은 DIP를 지금도 써요. SMD 종류로 SOIC(SOP), QFP, PLCC가 있어요.

    집적도

    칩 하나에 든 소자 수로 SSI(100개 이하) → MSI(~1,000) → LSI(~10,000) → VLSI(~1,000,000) → ULSI(1,000,000개 이상).

    트랜스듀서 · 센서 · 액추에이터

    트랜스듀서는 한 에너지를 다른 형태의 에너지로 바꾸는 장치 전반이에요. 그중 물리량을 전기 신호로 바꾸는 게 센서(마이크, 압력 센서), 전기 신호를 운동으로 바꾸는 게 액추에이터(자동 트렁크)예요.
