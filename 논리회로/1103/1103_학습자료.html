NAND 하나만 있으면 어떤 회로든 만들 수 있다고?

카르노 맵으로 줄인 식을 이제 NAND만, 또는 NOR만 써서 회로로 바꾸는 날이에요. 도구는 딱 하나, "NOT을 두 번 붙이면 원래 선과 같다"는 사실입니다.

이 페이지를 다 보면 할 수 있는 것

  1. NOT · AND · OR를 NAND만으로(또는 NOR만으로) 그릴 수 있다
  2. AND 뒤에 OR가 있는 회로에 NOT을 짝으로 붙여 NAND 회로로 바꿀 수 있다
  3. 예제 6-14를 2입력 NAND 5개짜리 회로로 직접 바꿀 수 있다

장면 1

NOT을 두 번 붙이면 왜 아무 일도 안 일어날까?

이중 부정 · NAND / NOR 입력 묶기 = NOT

0을 넣으면 NOT 하나를 지나 1, 또 하나를 지나 다시 0

두 번 뒤집으면 제자리예요. 오늘 수업 전체가 이 한 줄로 굴러갑니다.

NOT은 들어온 값을 뒤집기만 하는 게이트예요. 0이 들어가면 1, 1이 들어가면 0. 그러니 NOT을 두 개 연달아 붙이면 뒤집었다가 다시 뒤집는 거라서, 결과는 그냥 선 하나를 연결한 것과 똑같아요. 식으로는 (A′)′ = A, 5장에서 배운 이중 부정이죠.

교수
우리 배웠잖아요. 낫에 낫을 붙이면 원래 선과 같다. 그러니까 원래 있는 거에 낫을 하고 낫을 다시 하시면 이 선과 동일해요.11/3 강의 중 (말을 조금 다듬음)

두 번째로 알아 둘 건 NAND의 두 입력을 하나로 묶으면 NOT이 된다는 거예요. 입력이 둘 다 A면 AND 결과는 A·A = A고, 거기에 NAND 끝의 동그라미가 뒤집으니까 A′. NOT과 똑같죠. NOR도 마찬가지로 A + A = A를 뒤집어서 A′가 나와요.

왜 이게 중요하냐면, "NAND만 써라"라는 문제에서는 NOT 게이트조차 쓸 수 없거든요. 그때 NOT 자리에 입력 묶은 NAND를 넣으면 돼요.

시험엔 이렇게

NOT 두 개 = 선 하나 ((A′)′ = A). NAND나 NOR의 두 입력을 하나로 묶으면 NOT과 같다 ((AA)′ = (A + A)′ = A′).

외우는 법: 두 번 뒤집으면 제자리, 묶으면 NOT
바로 확인
NAND 게이트의 두 입력에 모두 1을 넣었다. 출력은? 이 연결은 어떤 게이트처럼 동작할까?
1·1 = 1을 NAND의 동그라미가 뒤집어서 0. 입력 1이 0으로 나왔으니 NOT이에요. 입력을 묶은 NAND는 항상 NOT처럼 동작합니다.

장면 2

NAND만 가지고 AND와 OR는 어떻게 만들까?

AND = NAND 2개 · OR = NAND 3개 · 만능 게이트

"내가 가지고 있는 게, 활용할 수 있는 게 NAND밖에 없어."

교수님이 깔아 둔 상황이에요. 이 상태로 AND와 OR를 만들어 봅시다.

AND 만들기 : NAND는 AND 뒤에 NOT이 붙은 거예요. 그러면 NAND 뒤에 NOT을 하나 더 붙이면 NOT 두 개가 상쇄돼서 AND만 남겠죠? 그 NOT을 장면 1처럼 입력 묶은 NAND로 바꾸면 NAND 2개로 AND가 완성돼요.

OR 만들기 : 드모르간에서 (A′B′)′ = A + B였어요. 그러니 A와 B를 각각 뒤집어서(묶은 NAND 2개) NAND에 넣으면 A + B가 나와요. 그래서 OR는 NAND 3개예요.

NOR만 써야 할 때는 거꾸로예요. NOR 뒤에 묶은 NOR를 붙이면 OR(2개), 입력을 각각 뒤집어 NOR에 넣으면 드모르간 (A′ + B′)′ = AB 때문에 AND(3개)가 됩니다.

이렇게 NAND 하나(또는 NOR 하나)만으로 NOT · AND · OR를 다 만들 수 있으니, 어떤 회로든 만들 수 있어요. 그래서 NAND와 NOR를 만능 게이트(universal gate)라고 불러요. 칩을 만들 때 한 종류 게이트만 찍어 내면 되니까 실제로도 많이 씁니다.

만들 것NAND만으로NOR만으로
NOT1개 (입력 묶기)1개 (입력 묶기)
AND2개 (NAND 뒤에 NOT)3개 (입력 각각 NOT → NOR)
OR3개 (입력 각각 NOT → NAND)2개 (NOR 뒤에 NOT)
시험엔 이렇게

NAND와 NOR는 다른 모든 게이트를 구성할 수 있어 만능 게이트(universal gate)라 한다. NAND로 AND는 2개, OR는 3개 / NOR로 OR는 2개, AND는 3개.

외우는 법: 이름 속 게이트는 2개, 반대 게이트는 3개 (NAND 속 AND = 2개)
바로 확인
NOR 게이트만으로 AND 게이트 하나를 만들려면 NOR가 최소 몇 개 필요할까?
A와 B를 각각 뒤집는 묶은 NOR 2개 + 마지막 NOR 1개 = 3개. (A′ + B′)′ = AB(드모르간). NOR로 2개면 되는 건 OR예요.

장면 3

NAND를 OR 모양으로 그려도 된다고?

동그라미 옮기기 · 드모르간 그림 버전

교재 74쪽은 같은 게이트를 다른 모양으로 그리는 법이에요. 드모르간 (AB)′ = A′ + B′을 그림으로 옮기면, 출력에 동그라미가 달린 NAND는 입력 쪽에 동그라미를 단 OR와 똑같아요. NOR도 (A + B)′ = A′B′이니 입력에 동그라미를 단 AND와 같고요.

규칙은 하나예요. 동그라미가 출력에서 입력으로 넘어가면, 몸통이 AND ↔ OR로 바뀐다. 드모르간에서 "바를 자르면 기호가 바뀐다"(· ↔ +)는 것과 같은 말이에요.

교수
핵심은 AND와 OR예요. AND일 때랑 NAND일 때, 부정하면서 기호가 바뀌는 것, 그것만 주의하시면 뒤에 훨씬 쉬울 거예요.11/3 강의 중 (말을 조금 다듬음)

이게 왜 필요하냐면, 다음 장면부터 회로 중간에 "입력에 동그라미 달린 OR"가 계속 생기거든요. 그걸 보는 순간 "아, 이건 NAND구나" 하고 바꿔 그리면 끝이에요.

시험엔 이렇게

NAND = 입력에 NOT을 단 OR ((AB)′ = A′ + B′). NOR = 입력에 NOT을 단 AND ((A + B)′ = A′B′).

외우는 법: 동그라미가 넘어가면 모양이 바뀐다
바로 확인
입력 A, B에 각각 동그라미(NOT)가 달린 AND 게이트가 있다. 이것과 같은 게이트는?
A′B′ = (A + B)′ 이니까 NOR예요. 입력 동그라미를 출력으로 옮기면서 AND 몸통이 OR로 바뀐 거죠.

장면 4

AND 뒤에 OR가 붙은 회로는 왜 통째로 NAND가 될까?

SOP 회로 → NAND-NAND · 교재 78~79쪽

F = AB′C′ + A′C′D′ + BD

카르노 맵에서 1을 묶어 얻은 SOP(곱의 합) 식이에요. 회로로 그리면 AND 3개 → OR 1개. 이걸 NAND만으로 바꿔 봅시다.

방법 ① 식으로 : 식 전체에 바를 두 번 씌워요(이중 부정이라 값은 그대로). 그리고 안쪽 바 하나를 드모르간으로 자르면 + 가 · 로 바뀌면서 이렇게 돼요.

F = AB′C′ + A′C′D′ + BD
  = ((AB′C′ + A′C′D′ + BD)′)′          ← 바 두 번
  = ((AB′C′)′ · (A′C′D′)′ · (BD)′)′    ← 안쪽 바를 드모르간으로 자름

괄호마다 ( )′가 붙은 곱이 바로 NAND예요. 앞의 세 개는 NAND 3개, 그걸 다시 곱해서 바를 씌운 바깥도 NAND. 그래서 NAND 4개로 끝나요.

방법 ② 그림으로 : AND 출력 뒤에 NOT을 두 개씩 붙여요. 하나는 AND 쪽으로 붙여서 NAND를 만들고, 하나는 OR 입력 쪽으로 붙이면 OR가 "입력에 동그라미 단 OR"가 되죠. 장면 3에서 봤듯 그건 NAND예요.

교수
수식은 오타 때문에 계산이 잘못되는 경우도 있어요. 불 대수식이 익숙하지 않은 친구라면 그림으로 바꾸는 게 훨씬 쉬워요. 그래도 나는 불 대수식이 더 편하다? 그럼 불 대수식으로 하셔도 돼요.11/3 강의 중 (말을 조금 다듬음)
시험엔 이렇게

SOP 식(AND → OR 2단 회로)은 이중 부정 + 드모르간으로 NAND → NAND 2단 회로가 된다. 그림에선 AND 뒤에 NOT을 두 개씩 붙이고 정리한다.

외우는 법: AND-OR = NAND-NAND (모양만 바꾸고 선은 그대로)
✗ 이렇게 하면 틀려요AND만 NAND로 바꾸고 마지막 OR는 OR로 남겨 둔다 → 값이 뒤집힌 채로 들어가서 답이 달라짐
○ 맞게 하기NOT은 항상 짝으로. AND 뒤에 하나 붙였으면 OR 입력에도 하나 → 그 OR까지 NAND로
바로 확인
F = AB + CD를 NAND만으로 바꿨다. 필요한 NAND 개수와 연결로 맞는 것은?
AND 2개 → OR 1개 회로라서 모양만 바꾸면 NAND 3개, 식은 ((AB)′(CD)′)′ = AB + CD (드모르간). 마지막 OR도 NAND로 바꿔야 값이 맞아요.

장면 5

입력이 2개짜리 NAND만 쓰라면 어떻게 할까? ★

2입력으로 묶기 · NOT 짝 붙이기 · 같은 게이트 공유 · 예제 6-14 (83쪽 시험 출제 가능성)

F = C′D′ + ABC′ + A′C + B′C 를 2입력 NAND 게이트만 사용하여 설계하시오.

교재 예제 6-14. 교수님이 이 83쪽 그림을 시험에 낼 수 있다고 한 문제예요. 순서대로 따라가면 어렵지 않아요.

장면 4에서는 3입력 NAND를 써도 됐어요. 그런데 2입력이라는 조건이 붙으면 게이트 하나에 선이 2개까지만 들어갈 수 있어요. ABC′처럼 변수가 3개 곱해진 항은 그대로 못 그리죠. 그래서 먼저 식을 2개씩 묶어 줘요.

1단계 · 식을 2개씩 묶이도록 정리

C′가 붙은 항끼리, C가 붙은 항끼리 묶어요(분배법칙).

F = C′D′ + ABC′ + A′C + B′C
  = C′(D′ + AB) + C(A′ + B′)

이제 어느 게이트든 입력이 2개예요. AB(2개) → D′와 OR(2개) → C′와 AND(2개) → 아래쪽과 OR(2개). 아래쪽도 A′ + B′(2개) → C와 AND(2개).

2단계 · AND 뒤에 NOT을 두 개씩 붙이고 정리

83쪽 제목 그대로 "AND 게이트 뒤에 NOT을 두 개씩 붙이고 정리한다"예요. 짝으로 붙인 NOT은 값을 안 바꾸니까 마음껏 붙여도 돼요. 붙이고 나서 보면 이렇게 정리돼요.

  • AND + 뒤에 붙은 NOT → NAND
  • 입력 두 곳에 다 동그라미가 달린 OR → NAND (장면 3)
  • D′ 입력에만 동그라미가 없다 → 여기에 NOT을 하나 달아야 하는데, D′를 뒤집으면 D니까 그냥 D를 넣으면 돼요
  • 아래쪽 OR(A′, B′) → A′ + B′ = (AB)′ 이니 이미 NAND(A, B)예요

3단계 · 같은 게이트는 하나로 합치기

정리하고 보면 위에도 NAND(A, B), 아래에도 NAND(A, B)가 있어요. 입력이 똑같으니 출력도 똑같죠. 그래서 하나만 두고 선을 갈라서 같이 쓰면 돼요. 결과는 2입력 NAND 5개.

교수
A, B가 똑같이 붙잖아요. 하나로 묶어서 표현하시면 NAND 게이트 하나, 둘, 셋, 넷, 다섯 개. 아까 했던 NAND와 OR와 NOT을 한꺼번에 해결해서 NAND 다섯 개면 결과가 동일하게 나타날 수 있어요.11/3 강의 중 (말을 조금 다듬음)

답을 확인하고 싶으면 NAND를 하나씩 식으로 풀어 보면 돼요. ② = ((AB)′ · D)′ = AB + D′, ③ = (②·C′)′, ④ = ((AB)′ · C)′, ⑤ = (③ · ④)′ = (AB + D′)C′ + (AB)′C = C′(D′ + AB) + C(A′ + B′). 원래 식과 같아요(16줄 진리표로도 확인했어요).

시험엔 이렇게

2입력 NAND만으로 : ① 식을 2입력씩 묶이게 정리(F = C′(D′ + AB) + C(A′ + B′)) ② 회로를 그리고 AND 뒤에 NOT을 두 개씩 붙여 정리 ③ 입력이 같은 NAND는 공유 → NAND 5개.

외우는 법: 묶고 → 짝 NOT 붙이고 → 겹치는 건 합친다
✗ 헷갈리는 곳동그라미가 하나만 남은 입력(D′)을 그대로 두거나, NOT 게이트를 따로 그려 넣는다 → "NAND만" 조건 위반
○ 맞게 하기남은 NOT 하나는 입력 변수에 흡수 : D′ 자리에 D를 넣는다 (D′를 한 번 뒤집은 값)
바로 확인
예제 6-14를 2입력 NAND로 바꿨더니 맨 앞 NAND(A, B)가 두 군데 생겼다. 가장 알맞은 처리는?
입력이 같으면 출력도 같아서 공유하면 돼요. 그래서 교재 마지막 그림은 NAND 5개예요. AND로 바꾸면 "NAND만" 조건을 어겨요.

장면 6

NOR만 쓰라면 카르노 맵에서 뭘 묶어야 할까?

0을 묶어 POS · OR-AND → NOR-NOR · 예제 6-15

NAND 회로는 SOP(곱의 합)에서 출발했어요. 1을 묶으면 SOP가 나오죠. NOR는 그 반대라서 0을 묶어 POS(합의 곱) 식을 만들고 시작해요. POS는 OR 여러 개 → AND 하나 회로라서, 장면 4를 거꾸로 하면 NOR → NOR가 됩니다.

교수
NAND 게이트는 1로 묶었잖아요. 거꾸로 NOR 게이트는 0을 묶어서 간소화시키면 돼요. 그래야 바꾸는 게 더 편리합니다.11/3 강의 중 (말을 조금 다듬음)

예제 6-15 : 진리표를 NOR 게이트만으로 설계하시오

카르노 맵에서 0을 묶으면 F = (B′ + D)(A′ + B + C)(A + C′ + D)

OR 3개가 AND 하나로 들어가는 회로예요. 이번엔 OR 뒤에 NOT을 두 개씩 붙여요. 하나는 OR에 붙어 NOR가 되고, 하나는 AND 입력에 붙어서 "입력에 동그라미 단 AND" = NOR가 돼요(장면 3).

2입력 NOR만 쓰라고 하면 NAND 때와 똑같이 3개짜리 OR를 2개씩 쪼개요. 예를 들어 (A′ + B + C) = ((A′ + B) + C)로 나눠 그리고, 이번엔 OR 출력에 NOT 두 개, AND 입력 쪽에 NOT 두 개를 붙여 정리해요(교재 86~87쪽 · 90~91쪽). 원리는 장면 5와 같아요. 짝으로 붙이고, 하나만 남은 NOT은 입력 변수에 흡수하고(B′ → B처럼), 3개가 겹친 NOT은 하나만 남겨요.

④ 2단 회로 변환 AND-OR = NAND-NAND

NOT을 두 개 연달아 붙이면 선 하나와 같다. NAND의 두 입력을 하나로 묶으면 NOT 게이트가 된다. NAND만으로 AND를 만들려면 2개, OR를 만들려면 3개가 필요하다. 이렇게 다른 모든 게이트를 만들 수 있어 NAND와 NOR를 만능 게이트라 한다. NAND는 입력에 동그라미를 단 OR와 같다. SOP 회로는 NAND-NAND 회로로, POS 회로는 NOR-NOR 회로로 바뀐다. NOR만 쓸 때는 카르노 맵에서 0을 묶는다.

    퀴즈 다 풀고 채점하기

    Q1NAND 게이트만으로 OR 게이트 하나를 만들 때 필요한 NAND의 최소 개수는?

    A, B를 각각 뒤집는 묶은 NAND 2개 + 마지막 NAND 1개 = 3개. (A′B′)′ = A + B예요. 2개면 되는 건 AND.

    Q2입력 A, B에 각각 NOT이 달린 OR 게이트와 같은 게이트는?

    A′ + B′ = (AB)′ (드모르간) = NAND. 동그라미가 출력 쪽으로 넘어가면 OR 몸통이 AND로 바뀌어요.

    Q3F = AB′C′ + A′C′D′ + BD를 3입력까지 쓸 수 있는 NAND만으로 그렸다. NAND 개수는?

    AND 3개 → OR 1개 회로를 모양만 NAND로 바꾸면 3 + 1 = 4개예요. 식으로는 ((AB′C′)′(A′C′D′)′(BD)′)′. (교재 78쪽)

    Q42입력 NAND로 바꾸는 중에 OR 게이트의 한 입력에는 동그라미가 생겼는데, 다른 입력 D′에는 동그라미가 없다. 어떻게 처리할까?

    D′에 NOT을 하나 달아야 하는데 D′를 뒤집으면 D예요. 입력을 D로 바꾸면 NOT 게이트 없이 NAND만으로 끝나요(예제 6-14).

    Q5예제 6-14 F = C′D′ + ABC′ + A′C + B′C를 2입력 게이트로 그리기 위해 먼저 정리한 식은?

    C′가 붙은 항(C′D′, ABC′)과 C가 붙은 항(A′C, B′C)을 분배법칙으로 묶으면 C′(D′ + AB) + C(A′ + B′). 이러면 모든 게이트 입력이 2개예요.

    Q6예제 6-14의 최종 2입력 NAND 회로에서 NAND(A, B)를 공유하면 NAND는 모두 몇 개인가?

    NAND(A, B) 1 + 위쪽 2개(D와, C′와) + 아래쪽 1개(C와) + 마지막 1 = 5개. 공유하지 않으면 6개예요.

    Q7F = (B′ + D)(A′ + B + C)(A + C′ + D)를 NOR만으로 그릴 때 회로 모양은?

    POS(OR → AND)는 모양만 바꾸면 NOR → NOR예요. AND를 그대로 두면 "NOR만" 조건 위반이고, 값도 뒤집혀요.

    Q8"NAND로 바꿀 땐 1을, NOR로 바꿀 땐 0을 묶는다"는 이유로 가장 알맞은 것은?

    SOP는 NAND-NAND로, POS는 NOR-NOR로 모양만 바꾸면 되니까 변환이 편해요. 교수님 말로 "그래야 바꾸는 게 더 편리합니다".

    내 말로 설명하기 친구한테 말하듯이

    AND 뒤에 OR가 있는 회로를 NAND만으로 바꾸는 방법을, "NOT 두 개"라는 말을 넣어서 설명해 보세요.

    NOT을 두 번 붙이면 원래 선과 같으니까, AND와 OR 사이 선에 NOT을 두 개 붙여도 값은 안 바뀌어요. 하나는 AND 쪽에 붙여서 AND + NOT = NAND로 만들고, 다른 하나는 OR 입력 쪽에 붙여요. 입력마다 동그라미가 달린 OR는 드모르간으로 (AB)′ = A′ + B′라서 NAND와 같아요. 그래서 AND-OR 회로는 선은 그대로 두고 모양만 전부 NAND로 바꾸면 돼요. 2입력만 쓰라고 하면 먼저 식을 2개씩 묶고, 동그라미가 하나만 남은 입력은 변수를 뒤집어 넣고(D′ → D), 똑같은 NAND는 하나로 합쳐요.

    이번 수업 끝의 다른 얘기

    1장 단위 얘기를 다시 하셨어요. 10진 단위(KB · MB · GB, 10의 거듭제곱)와 2진 단위(KiB · MiB · GiB, 2의 거듭제곱, 가운데 i가 붙음)는 크기가 살짝 달라서, 8GB를 사도 컴퓨터에는 8보다 조금 작게 보인다는 것. "단위 이름 정도는 알아 두면 좋겠다, 기본이다"라고 하셨어요. 이어서 중간고사 문제 구성(9문제)도 설명하셨어요.
