논리식과 논리회로는 같은 걸 두 가지로 쓴 것

기본 논리식 · 진리표 → 식 → 간소화 → 회로 · SOP / POS 맛보기

AND 게이트는 x, y가 둘 다 1일 때만 1이죠. 이걸 식으로 쓰면 곱셈 F = xy. OR은 덧셈 F = x + y, NOT은 위에 줄(바)을 그어 Ā 또는 A′. 그림(회로)으로 그리느냐, 식으로 쓰느냐의 차이일 뿐 같은 것이에요.

이럴 때 1을 내고 싶다논리식
A = 0 그리고 B = 1F = A′B
A = 0 또는 B = 1F = A′ + B
(A=0 그리고 B=1) 또는 (A=1 그리고 B=0)F = A′B + AB′
A = 1이거나 (B = 0이고 C = 1)F = A + B′C

교수님이 정리해 준 전체 흐름이에요. "이것만 기억하시면 돼요."

  1. 진리표를 만든다 (입력 3개면 2³ = 8줄, 4개면 16줄). 출력이 1인 줄을 체크.
  2. 1인 줄의 항을 다 뽑아 논리식을 만든다. 그대로면 복잡해요.
  3. 간소화: 불 대수로 줄이기(대수적 방법) — 실수하기 쉬워서 그림으로 하는 카르노 맵(변수 4개까지 편함), 5개 이상은 다른 방법(다음 시간).
  4. 간단해진 식으로 논리회로를 그린다. 회로가 훨씬 작아져요.

예: 진리표에서 1인 항 5개(A′B′C, AB′C′, AB′C, ABC′, ABC)를 뽑으면 식이 길지만, 묶어서 정리하면 F = A + B′C만 남아요. 인수분해랑 비슷하죠. 그리고 식의 모양은 두 가지 — 곱을 더한 SOP(Sum of Products, 곱의 합)와 합을 곱한 POS(Product of Sums, 합의 곱). 곱 = AND, 합 = OR. (자세히는 10/8)

시험엔 이렇게

기본 불 대수식은 AND(곱) · OR(합) · NOT(바)으로 표현한다. 진리표에서 출력이 1인 항으로 논리식을 만들고, 불 대수 법칙이나 카르노 맵으로 간소화한 뒤 논리회로로 구성한다.

외우는 법: 표 → 식 → 줄이기 → 그리기 / 곱은 AND · 합은 OR
바로 확인
"A = 1이고 B = 0일 때 1을 출력"하는 논리식은?
"그리고" = 곱(AND), B = 0이니 B′ → AB′.

증명 없이 그냥 받아들이는 7가지, 그리고 거기서 나온 법칙들

불 대수 공리 P1~P7 · 기본법칙 1~9 · 교환 · 결합

공리는 "아무 증명 없이도 바르다고 말할 수 있는 명제"예요. 불 대수 공리는 7가지. 핵심은 0과 1밖에 없다는 거예요. 2도, −1도 없어요. 그래서 일반 수학과 딱 하나 다른 게 나와요.

공리내용
P1A = 0 또는 A = 1
P2 · P30 · 0 = 0   1 · 1 = 1
P4 · P50 + 0 = 0   1 + 1 = 1 (2가 없으니까!)
P6 · P71 · 0 = 0 · 1 = 0   1 + 0 = 0 + 1 = 1

이 공리를 바탕으로 법칙이 나와요. 법칙은 공리로 증명할 수 있어요.

기본법칙+ 쪽· 쪽
0과 1A + 0 = A   A + 1 = 1A · 1 = A   A · 0 = 0
자기 자신A + A = AA · A = A
보수A + A′ = 1A · A′ = 0
이중 부정(A′)′ = A — 두 번 뒤집으면 자기 자신
교환A + B = B + AAB = BA
결합(A + B) + C = A + (B + C)(AB)C = A(BC)

표를 잘 보면 왼쪽과 오른쪽이 짝이에요. 0 ↔ 1, + ↔ ·를 서로 바꾸면 다른 쪽이 나와요. 이걸 쌍대성(duality)이라고 해요. 한쪽만 외우면 반대쪽은 공짜.

시험엔 이렇게

불 대수 공리는 증명 없이 받아들이는 명제로, 변수는 0 또는 1이고 1 + 1 = 1이다. 기본법칙: A + 0 = A, A + 1 = 1, A + A = A, A + A′ = 1, A·1 = A, A·0 = 0, A·A = A, A·A′ = 0. 쌍대성은 0과 1, ·과 +를 서로 바꾸면 다른 쪽 식이 얻어지는 성질이다.

외우는 법: 1은 OR의 블랙홀(A+1=1) · 0은 AND의 블랙홀(A·0=0) / 0↔1, +↔· 바꾸면 짝꿍
바로 확인
A + AB′C + 1을 간단히 하면?
무엇이든 + 1 = 1.

분배법칙 14 · 15 · 흡수법칙 · 합의의 정리
법칙식메모
분배 14A(B + C) = AB + AC일반 수학과 같음
분배 15A + BC = (A + B)(A + C)일반 수학엔 없음! (실습 과제 3)
흡수 18A + AB = AA(1 + B) = A · 1 = A

흡수법칙은 교수님이 "아주 증명이 쉽게 되죠" 한 부분이에요. A + AB에서 A를 묶어 내면 A(1 + B)인데, 1 + B는 무조건 1(블랙홀)이니 A · 1 = A. 자기 자신만 남아요.

합의의 정리는 앞에 A, 뒤에 A′가 있을 때, 그 둘의 짝(B와 C)을 곱한 가운데 항 BC는 없어도 된다는 뜻이에요.

합의의 정리 20 증명 (자료 p.9)AB + BC + A′C
= AB + (A + A′)BC + A′C      // BC에 1 = (A + A′)을 곱함
= AB + ABC + A′BC + A′C
= A(B + BC) + A′(C + BC)      // 묶기
= AB + A′C                    // 흡수법칙
시험엔 이렇게

분배법칙: A(B + C) = AB + AC, A + BC = (A + B)(A + C). 흡수법칙: A + AB = A, A(A + B) = A. 합의의 정리: AB + BC + A′C = AB + A′C, (A + B)(B + C)(A′ + C) = (A + B)(A′ + C).

외우는 법: 더하기도 곱하기에 분배된다(15번) / A가 A를 먹는다(흡수) / A와 A′ 사이 가운데는 빠져라(합의)
바로 확인
X + XYZ를 간단히 하면?
흡수법칙: X(1 + YZ) = X · 1 = X.

드모르간의 정리: (A + B)′ = A′B′, (AB)′ = A′ + B′. 일반식은 (A1 + … + An)′ = A1′ · … · An′, (A1 · … · An)′ = A1′ + … + An′이다. 진리표에서 좌변과 우변의 결과가 모든 입력 조합에서 같음으로 증명할 수 있다.

외우는 법: 끊고 · 바꾸고 (바를 끊고, +와 ·을 바꾼다) / NOR = 뒤집은 입력의 AND

A + BC와 (A + B)(A + C), 진짜 같은지 회로로 돌려 보자

실습 과제 3 · 분배법칙 · 진리표 · LogicWorks 파형 비교

진리표로 증명했던 분배법칙 15번을 실제 회로로 확인하는 실습이에요. 좌측식과 우측식 회로를 따로 그려서 입력 A, B, C를 넣고 두 출력이 항상 같은지 봐요.

A B CBC좌: A + BCA + BA + C우: (A + B)(A + C)
0 0 000000

0 1 000100

  • 좌측식: AND(B, C) → OR(A, ·)
  • 우측식: OR(A, B)와 OR(A, C) → AND

시험엔 이렇게

두 논리식이 같음은 진리표에서 모든 입력 조합(입력 n개면 2n가지)에 대해 출력이 같음을 보여 증명한다. A + BC = (A + B)(A + C)는 8가지 경우 모두 결과가 같다.

(0 + 1)(0 + 0) = 1 · 0 = 0. 좌변 A + BC = 0 + 0 = 0으로 같아요.

빈칸 채우기 눌러서 정답 확인

불 대수에서 1 + 1 = 1이다. A + A′ = 1, A · A′ = 0이다. 분배법칙 A + BC = (A + B)(A + C)는 일반 수학에 없다. 흡수법칙에 의해 A + AB = A이다. 드모르간의 정리에 의해 (A + B)′ = A′B′, (AB)′ = A′ + B′이다. 0과 1, ·과 +를 바꾸면 다른 쪽 식이 나오는 성질을 쌍대성이라 한다.

    내 말로 설명하기 실습 과제 4번 · 시험 대비

    "드모르간의 정리를 식으로 쓰고, 진리표로 어떻게 증명하는지 설명해 보세요."

    드모르간의 정리는 (A + B)′ = A′B′, (AB)′ = A′ + B′ 두 식이에요. 전체에 씌운 부정을 각 변수로 나눠 씌우면 OR은 AND로, AND는 OR로 바뀐다는 뜻이고, 변수가 n개여도 똑같이 성립해요. 증명은 A, B의 네 가지 입력 조합(00, 01, 10, 11)마다 좌변과 우변을 계산해 진리표를 만들면 돼요. 예를 들어 (A + B)′는 1, 0, 0, 0이고 A′B′도 1, 0, 0, 0으로 모든 줄이 같으므로 두 식은 같아요. 회로로는 NOR 게이트가 입력을 각각 NOT한 AND 게이트와 같다는 의미이고, LogicWorks에서 두 회로의 출력 파형이 같음으로도 확인할 수 있어요.
