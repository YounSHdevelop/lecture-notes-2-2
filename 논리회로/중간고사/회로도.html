게이트 기호, 손으로 어떻게 그리지?

제4장 논리 게이트 · 기호 8개와 식

회로도 문제는 결국 기호를 정확히 그리는 것부터예요. 모양은 딱 세 가지(D 모양 · 총알 모양 · 삼각형)고, 여기에 동그라미(NOT)와 뒤쪽 곡선 한 줄(XOR)만 붙이면 8개가 다 나와요.

그리는 요령

  • AND : 뒤는 일자, 앞은 반원(D 모양). 식에서 붙여 쓴 곱(AB)
  • OR : 뒤가 안으로 휘고 앞이 뾰족한 총알 모양. 식에서 +
  • NOT : 삼각형 + 끝에 작은 동그라미. 식에서 ′(바)
  • 버퍼 : 동그라미 없는 삼각형. 값은 그대로(F = A)
  • NAND · NOR : AND · OR 끝에 동그라미만 붙인 것. 식 전체에 큰 바
  • XOR : OR 뒤쪽에 휜 선을 한 줄 더 그린 것. 식에서 ⊕
  • XNOR : XOR 끝에 동그라미
  • 입력이 3개 이상 : 같은 기호에 선만 더 붙인다(ABC는 3입력 AND 하나)
시험엔 이렇게

곱(붙여 쓰기)은 AND, +는 OR, ′는 NOT, ⊕는 XOR. 동그라미가 붙으면 그 결과를 뒤집는다는 뜻이다.

외우는 법: 모양 셋(D · 총알 · 삼각형) + 동그라미 = NOT + 뒤쪽 곡선 = XOR
바로 확인
OR 기호 뒤쪽에 휜 선이 한 줄 더 있고, 끝에 동그라미가 붙은 게이트는?
뒤쪽 곡선 = XOR, 끝 동그라미 = NOT이라 XNOR예요. NOR는 뒤쪽 곡선이 없는 OR + 동그라미예요.

식을 보고 회로를 그리려면 어디서부터 시작할까?

제5장 04절 논리식의 회로 구성 · 교재 20~22쪽

순서는 수식 계산이랑 똑같아요. 괄호 안 → 곱 → 마지막 +. 곱의 합(SOP)이면 AND들을 먼저 세우고 OR 하나로 모으면 끝이에요(AND-OR 2단). 합의 곱(POS)은 반대로 OR들을 세우고 AND 하나로 모아요(OR-AND 2단).

그리는 순서

  • 1단계 : 항을 나눈다. + 로 나뉘면 마지막 게이트가 OR, 괄호끼리 곱이면 마지막 게이트가 AND
  • 2단계 : 각 항을 게이트 하나로 그린다(항의 변수 개수 = 입력 개수)
  • 3단계 : 항 게이트의 출력을 마지막 게이트 하나에 모은다
  • 보수 입력(A′) : 입력 이름을 A′이라고 바로 쓰거나(보수 입력 사용), A에 NOT 게이트를 단다(NOT 게이트 사용). 둘 다 정답
교수
보수 입력을 이렇게 해도 되고, 바 없는 것에다가 NOT을 입혀서 회로를 그려도 되고, 편한 게 이게 편하다면 이렇게 해도 되고요. 요거 문제 나올 수 있으니까 연습을 꼭 해야 됩니다.10/8 강의 중 (말을 조금 다듬음)

① F = A′B + AB′ + BC 곱의 합 · 교재 20쪽

② F = (A + B)(A′ + B′ + C) 합의 곱 · 교재 21쪽

③ F = A′BC′ + A′BC + AB′C′ + AB′C + ABC 최소항식 · 교재 21쪽

④ F = E′ + BC′D + (CE + B′)A 여러 단계 · 교재 22쪽

시험엔 이렇게

식을 회로로 그릴 때는 괄호 안과 곱의 항을 먼저 게이트로 만들고, 마지막 연산(+면 OR, 곱이면 AND)으로 모은다. 곱의 합은 AND-OR, 합의 곱은 OR-AND 2단 회로가 된다.

외우는 법: 괄호 → 곱 → 마지막 + / SOP = AND-OR · POS = OR-AND
바로 확인
F = (A + B)C를 회로로 그릴 때 필요한 게이트는?
괄호 안 A + B가 OR 하나, 그 출력과 C의 곱이 AND 하나예요.

회로를 보고 식을 쓰려면? 게이트마다 출력을 적어 나가면 돼요

제5장 03절 논리회로의 논리식 변환 · 교재 17~19쪽 · 예제 5-2

교재 한 줄 요약이 이거예요. "게이트를 거칠 때마다 게이트의 출력을 적어 주면서 한 단계씩 출력 쪽으로 나아가면 된다." 입력 쪽 게이트부터 출력식을 선 위에 적고, 그걸 다음 게이트의 입력으로 그대로 가져가면 마지막 게이트에서 F가 나와요.

적는 규칙

  • AND 게이트 : 들어온 것들을 붙여 쓴다(곱). 들어온 게 합이면 괄호로 감싼다 → (C + D)AB
  • OR 게이트 : 들어온 것들을 + 로 잇는다
  • NOT 게이트 : 들어온 것에 ′ 를 붙인다(A → A′)
  • NAND · NOR : AND · OR로 적은 다음 전체에 ′ 를 붙인다 → (AB)′
  • 마지막 게이트 출력 : 그게 F

① 교재 17쪽

정답 보기 게이트마다 출력식을 적은 그림
  • OR 게이트 출력 : C + D
  • AND 게이트 출력 : AB
  • AND 게이트 출력 : (C + D)AB
  • AND 게이트 출력 : B′C
  • 최종 : F = (C + D)AB + B′C

② 교재 18쪽 예 1

정답 보기 게이트마다 출력식을 적은 그림
  • AND 게이트 출력 : A′BC
  • AND 게이트 출력 : B′D
  • AND 게이트 출력 : A′C
  • 최종 : F = A′BC + B′D + A′C

③ 교재 18쪽 예 2

정답 보기 게이트마다 출력식을 적은 그림
  • OR 게이트 출력 : A′ + B + C
  • OR 게이트 출력 : B′ + D
  • OR 게이트 출력 : A′ + C
  • 최종 : F = (A′ + B + C)(B′ + D)(A′ + C)

④ 예제 5-2 (NOT 게이트 포함)

정답 보기 게이트마다 출력식을 적은 그림
  • OR 게이트 출력 : B + C
  • AND 게이트 출력 : (B + C)A′
  • AND 게이트 출력 : ABC′
  • 최종 : F = (B + C)A′ + ABC′
시험엔 이렇게

회로를 논리식으로 바꿀 때는 입력 쪽 게이트부터 각 게이트의 출력식을 적으면서 한 단계씩 출력 쪽으로 나아가고, 마지막 게이트의 출력식이 F가 된다.

외우는 법: 입력 쪽부터 · 선 위에 출력식 · 합이 곱으로 들어가면 괄호
✗ 이렇게 쓰면 틀려요C + D와 AB가 AND로 만날 때 → C + DAB
○ 맞게 쓰기합이 곱으로 들어가면 괄호 → (C + D)AB
바로 확인
A, B가 들어가는 OR 게이트의 출력과 C가 NAND 게이트로 들어간다. F는?
OR 출력 A + B와 C를 AND로 적으면 (A + B)C, NAND라 전체에 ′ → ((A + B)C)′

법칙 양쪽을 회로로 그리면 정말 똑같이 동작할까?

제5장 02절 불 대수 법칙 · 실습과제 3 · 4 (LogicWorks)

실습 시간에 한 게 이거였어요. 법칙의 왼쪽 식과 오른쪽 식을 각각 회로로 그리고, 같은 입력을 넣어 출력 파형이 같은지 보는 것. 이게 "같음을 보이는 3방법" 중 회로 실습이에요. 생긴 건 달라도 진리표는 똑같아요.

① 분배법칙 : A + BC = (A + B)(A + C) 실습 3

② 드모르간 : (A + B)′ = A′B′ 실습 1

③ 드모르간 : (AB)′ = A′ + B′

④ NAND만으로 만든 회로 = AND-OR 회로 실습 4

  • 왜 같은가 : 바깥 큰 바를 드모르간으로 자르면 ((AB′C′)′)′ + ((A′C′D′)′)′ + ((BD)′)′, 바 두 개는 벗겨져서 AB′C′ + A′C′D′ + BD
  • NAND-NAND 2단 : AND-OR 2단 회로의 게이트를 전부 NAND로 바꾼 것과 같다
시험엔 이렇게

두 논리식이 같음은 두 식을 각각 회로로 그려 같은 입력을 넣었을 때 출력 파형이 같은지로 보일 수 있다. 예를 들어 NOR 게이트는 입력마다 NOT을 단 AND 게이트와 같다(드모르간).

외우는 법: NOR = NOT 단 AND · NAND = NOT 단 OR · NAND-NAND = AND-OR
바로 확인
입력 A, B에 각각 NOT을 달고 OR 게이트로 모은 회로와 같은 게이트 하나는?
A′ + B′ = (AB)′ 이므로 NAND예요. 드모르간 (AB)′ = A′ + B′.

간소화하면 회로가 얼마나 작아지고, XOR는 기본 게이트로 어떻게 만들까?

실습과제 5 논리식 간소화 · 예제 4-9 · XOR 내부 구성

간소화를 하는 이유가 그림으로 보이는 장면이에요. 같은 동작인데 게이트 수와 입력 수가 확 줄어요. 칩이 작아지고, 싸지고, 전력도 덜 먹고, 빨라지죠.

① 간소화 전 F1 = A′B′C′ + A′BC′ + A′BC + AB′C′ 실습 5

② 간소화 후 F2 = B′C′ + A′B

  • 간소화 과정 : A′B′C′ + AB′C′ = B′C′(A′ + A) = B′C′, A′BC′ + A′BC = A′B(C′ + C) = A′B
  • 쓰인 법칙 : 분배법칙으로 묶고, A′ + A = 1(기본법칙 7), X · 1 = X(기본법칙 2)

③ XOR를 기본 게이트로 : A ⊕ B = A′B + AB′

④ 2입력 XOR 2개로 3입력 XOR : F = (A ⊕ B) ⊕ C 예제 4-9

시험엔 이렇게

간소화하면 같은 동작을 더 적은 게이트와 입력으로 구현할 수 있어 회로가 작아지고 비용과 전력이 줄며 속도가 빨라진다. XOR는 A′B + AB′로 AND-OR 회로로 만들 수 있다.

외우는 법: 간소화 = 작고 · 싸고 · 전력↓ · 빠름 / XOR = A′B + AB′
바로 확인
A ⊕ B를 AND · OR · NOT으로 만들 때의 식은?
XOR는 두 입력이 다를 때 1이라 A′B + AB′예요. AB + A′B′는 같을 때 1인 XNOR예요.
