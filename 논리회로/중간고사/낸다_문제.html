★ 1. "최소항이 뭐예요?" 설명하시오.

출처: 10/13 수업 "시험에 최소항이 뭐예요, 설명하시오 이렇게 나오겠죠"

최소항(minterm)은 모든 입력 변수를 한 번씩 포함하는 곱(AND)항으로, 각 변수는 그대로 또는 보수(′)로 들어간다. 진리표의 한 줄에서만 1이 되며, 변수가 n개면 2ⁿ개가 있다(3변수는 m0~m7, 4변수는 m0~m15). 예를 들어 4변수에서 AB′C′D는 1001이므로 m9이다. 변수가 하나라도 빠진 항(예: ABC)은 간소화된 항이라 최소항이 아니다.
채점 포인트: 모든 변수 포함 · 곱 · 2ⁿ개 · 예시 하나

2. 최대항이란 무엇인지 설명하시오.

출처: 10/13 수업(최소항과 짝) · 시험 메모 "최대항 표현방법"

최대항(maxterm)은 모든 입력 변수를 한 번씩 포함하는 합(OR)항이다. 진리표의 한 줄에서만 0이 되며, 그 줄의 값이 0인 변수는 그대로, 1인 변수는 보수(′)로 쓴다. 함수 F는 F가 0인 줄의 최대항들을 곱해 F = ΠM( )으로 나타내며(POS, 합의 곱), 최소항식 Σm에서 빠진 번호가 ΠM의 번호가 된다.
채점 포인트: 모든 변수 포함 · 합 · 0이면 그대로 1이면 ′ · F가 0인 줄을 곱해 ΠM

★ 3. "BCD 코드가 뭐예요?" 2~3문장으로 답하시오.

출처: 10/1 수업 "BCD 코드 뭐예요? 이렇게 물으면 답을 잘해야 돼요"

BCD 코드는 10진수의 각 자리를 4비트 2진수로 표현한 코드(8421 코드)다. 예를 들어 32는 0011 0010으로 쓴다. 0000~1001만 쓰고 1010~1111은 쓰지 않아 비트가 낭비되며, 덧셈에서 자리 합이 9를 넘으면 0110(6)을 더해 보정한다.
채점 포인트: 10진 한 자리 = 4비트 · 예시 · 1010~1111 안 씀 · +6 보정

4. 2의 보수가 왜 필요한지, 1의 보수와 비교한 장단점, 컴퓨터가 결국 무엇을 쓰는지 설명하시오.

출처: 2의 보수 "장단점 · 왜 · 뭘 쓰는지 꼭 기억"

보수는 덧셈기만으로 뺄셈을 하기 위해 음수를 표현하는 방법이다. 1의 보수는 모든 비트를 반전하면 되므로 만들기 쉽지만 0이 +0(0000)과 −0(1111) 두 개 생겨 결과를 다시 보정해야 한다. 2의 보수는 1의 보수에 1을 더해 만들어 한 단계가 더 필요하지만 0이 하나라 결과가 정확하다. 그래서 컴퓨터는 2의 보수를 쓴다.
채점 포인트: 덧셈으로 뺄셈 · 1의 보수 = 반전, 0이 두 개 · 2의 보수 = +1, 0이 하나 · 결론 2의 보수

5. 패리티 비트와 해밍 코드의 차이를 설명하시오.

출처: 9/29 "패리티는 그레이 코드만큼 중요해요" · 10/1 설명 (단, "낸다"는 말은 없음)

패리티 비트는 데이터에 비트 1개를 덧붙여 1의 개수를 짝수(짝수 패리티) 또는 홀수(홀수 패리티)로 맞추는 것이다. 받는 쪽에서 1의 개수가 약속과 다르면 에러를 검출할 수 있지만, 어느 비트가 틀렸는지는 알 수 없다. 해밍 코드는 패리티 비트를 여러 개(1, 2, 4, 8번 자리) 넣어 에러의 위치까지 찾아 정정할 수 있다.
채점 포인트: 1의 개수 맞추기 · 짝수/홀수 · 패리티 = 검출만 · 해밍 = 위치 찾아 정정

출처: 10/8 · 10/13 수업, 실습 과제 5 "불 대수로 증명했는데 실습으로도 증명할 수 있나요?"

제1장 — 듀티 사이클, 숫자만 바꿔서 계속 (예제 1-4 ★)

9/8 "10문제 낼게" · 필기 "무조건 나옴" · f = 1/T · 듀티 = tw/T × 100 · 거꾸로 구하기
시험엔 이렇게

주파수 f = 1 / T, 듀티 사이클 = (tw / T) × 100 [%]. 예제 1-4: tw = 50 μs, T = 250 μs → f = 4 kHz, 듀티 = 20 %.

외우는 법: 주파수는 뒤집기 · 듀티는 폭 ÷ 주기 / μs 뒤집으면 MHz · ms 뒤집으면 kHz · ns 뒤집으면 GHz

직접 풀기 — 듀티 사이클 (예제 1-4 숫자 바꾸기) (20문제 · 회색 칸을 누르면 답)

제2장 — 1의 보수 · 2의 보수, 만들고 왜 쓰는지 말하기 (★ 서술)

시험엔 이렇게

보수는 덧셈기만으로 뺄셈을 하기 위해 음수를 표현하는 방법이다. 1의 보수는 비트를 반전해 만들기 쉽지만 0이 +0과 −0 두 개 생기고, 2의 보수는 1의 보수에 1을 더해 0이 하나라 결과가 정확하다. 그래서 컴퓨터는 2의 보수를 쓴다.

외우는 법: 1의 보수는 "쉽지만 둘", 2의 보수는 "한 단계 더, 대신 정확" / 뒤집고 +1

제5장 — 회로를 보고 식, 식을 보고 회로 (★)

  2. [회로 → 식] A, B를 OR → 그 결과와 C를 AND F = (A + B)C
  3. [회로 → 식] A, B를 AND / C, D를 AND → 두 결과를 OR F = AB + CD
  4. [회로 → 식] A를 NOT → 그 결과와 B를 AND F = A′B
  5. [회로 → 식] A, B를 AND → 그 결과와 C를 OR → 마지막에 NOT F = (AB + C)′ = (A′ + B′)C′
  6. [회로 → 식] A, B를 OR / B, C를 OR → 두 결과를 AND F = (A + B)(B + C)
  7. [회로 → 식] A′와 B를 AND / A와 B′를 AND → 두 결과를 OR F = A′B + AB′ (XOR)
  8. [회로 → 식] (10/8 연습) B, C를 AND / A, B를 AND → 두 결과를 OR / B′, C를 AND → 앞의 OR 결과와 이것을 AND BC → AB → BC + AB → B′C → F = (BC + AB)B′C

  11. [식 → 회로] F = (A + B)C′ NOT(C) · OR(A, B) → AND(A + B, C′)
  12. [식 → 회로] F = A′B′ + AB NOT 2개(A′, B′) → AND 2개(A′B′, AB) → OR (XNOR)
  13. [식 → 회로] F = (A + B′)(A′ + C) NOT 2개(B′, A′) → OR 2개(A + B′, A′ + C) → AND
  14. [식 → 회로] F = (AB)′ + C NAND(A, B) → OR(그 결과, C)

최소항은 모든 변수를 포함하는 AND항(0인 변수는 보수, 1인 변수는 그대로, 기호 m)이고 출력이 1인 행을 OR로 묶어 F = Σm(…)으로 쓴다. 최대항은 모든 변수를 포함하는 OR항(0인 변수는 그대로, 1인 변수는 보수, 기호 M)이고 출력이 0인 행을 AND로 묶어 F = ΠM(…)으로 쓴다. 같은 함수의 Σm과 ΠM 번호는 서로 나머지다. 빠진 변수 X는 최소항식이면 (X + X′)를 곱하고, 최대항식이면 XX′를 더한 뒤 분배법칙으로 나눈다.

외우는 법: 최소 = 1 모아 Σm, 0에 바 / 최대 = 0 모아 ΠM, 1에 바 / 모자 없이 바꾸면 나머지 번호

제5장 — "이 식에 적용된 법칙은?" 이름 대기 (★ 시험 메모)

간소화 과정을 쓸 때는 줄마다 적용한 법칙 이름을 함께 쓴다. 공통인 것을 묶거나 풀면 분배법칙, X + YZ = (X + Y)(X + Z)로 쪼개면 불 대수에만 있는 분배법칙, X + X′ = 1과 X · X′ = 0은 보수 법칙, X · 1 = X와 X + 0 = X는 기본법칙이다.

외우는 법: 묶으면 분배 · 1 만들면 보수 · 지우면 기본법칙

직접 풀기 — "이 식에 적용된 법칙은?" (20문제 · 회색 칸을 누르면 답)

  1. A + AB = A 흡수법칙
  2. A + A′B = (A + A′)(A + B) 분배법칙 X + YZ = (X + Y)(X + Z) (불 대수에만 있는 쪽)
  3. (A + A′)(A + B) = 1 · (A + B) 보수 법칙 A + A′ = 1
  4. 1 · (A + B) = A + B 기본법칙 1 · X = X
  5. A′B′C′ + AB′C′ = B′C′(A′ + A) 분배법칙 AB + AC = A(B + C) (공통인 것 묶기)
  6. B′C′(A′ + A) = B′C′ · 1 보수 법칙 A′ + A = 1
  7. A + B′ + C + DD′ = (A + B′ + C + D)(A + B′ + C + D′) 분배법칙 X + YZ = (X + Y)(X + Z) — 10/13 "법칙이 뭐냐고 나오면 분배법칙"
  8. A + B′ + C = A + B′ + C + DD′ (DD′를 더해도 되는 근거) 보수 법칙 D · D′ = 0 (0을 더해도 그대로, X + 0 = X)
  9. AB′C = AB′C(D + D′) (D + D′를 곱해도 되는 근거) 보수 법칙 D + D′ = 1 (1을 곱해도 그대로, X · 1 = X)
  10. ((A + B)′)′ = A + B 이중 부정 (X′)′ = X
  11. AB + BC + A′C = AB + A′C 합의의 정리
  12. (A + B)′ = A′B′ 드모르간의 정리
  13. A + A = A 기본법칙(자기 자신)
  14. AB = BA 교환법칙
  15. (A + B) + C = A + (B + C) 결합법칙
  16. A + 1 = 1 기본법칙(1은 OR의 블랙홀)
  17. A · 0 = 0 기본법칙(0은 AND의 블랙홀)
  18. A · A′ = 0 보수 법칙
  19. A′BC′ + AB′C에서 AB′C를 한 번 더 써서 묶어도 되는 근거 기본법칙 X + X = X (자기 자신을 더해도 그대로)
  20. A + 0 = A ↔ A · 1 = A 처럼 0 ↔ 1, + ↔ · 를 바꾼 짝 쌍대성

"2의 보수가 왜 필요한지, 1의 보수와 비교한 장단점, 컴퓨터가 결국 무엇을 쓰는지 설명하시오."

보수는 덧셈기만으로 뺄셈을 하기 위해 음수를 표현하는 방법이다. 1의 보수는 모든 비트를 반전하면 되므로 만들기 쉽지만 0이 +0(0000)과 −0(1111) 두 개 생겨 결과를 다시 보정해야 한다. 2의 보수는 1의 보수에 1을 더해 만들어 한 단계가 더 필요하지만 0이 하나라 결과가 정확하다. 그래서 컴퓨터는 2의 보수를 쓴다.

"BCD 코드가 뭐예요?" 2~3문장으로 답하시오.

BCD 코드는 10진수의 각 자리를 4비트 2진수로 표현한 코드(8421 코드)다. 예를 들어 32는 0011 0010으로 쓴다. 0000~1001만 쓰고 1010~1111은 쓰지 않아 비트가 낭비되며, 덧셈에서 자리 합이 9를 넘으면 0110을 더해 보정한다. 사람이 자리별로 읽기 쉬워 숫자 표시 장치 등에 쓰인다.
