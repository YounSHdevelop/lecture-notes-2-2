장면 1

AND · OR · NAND · NOR · XOR, 기호와 진리표를 바로 그릴 수 있을까?

4장 · 게이트 기호 8개 · 2입력 진리표 · 식 → 회로

게이트 문제는 "기호를 그려라" 또는 "진리표를 채워라"로 나와요. 기호는 몸통 두 개(AND는 D 모양, OR는 총알 모양)에 동그라미와 곡선을 붙여서 만들어요.

게이트 (언제 1이 나오나)

  • AND : 입력이 모두 1일 때만 1. F = AB
  • OR : 입력이 하나라도 1이면 1, 모두 0일 때만 0. F = A + B
  • NOT : 입력을 반전. F = A′
  • 버퍼 : 입력을 그대로 출력. F = A
  • NAND : 입력이 모두 1일 때만 0(AND 뒤에 NOT). F = (AB)′
  • NOR : 입력이 모두 0일 때만 1(OR 뒤에 NOT). F = (A + B)′
  • XOR : 1의 개수가 홀수면 1. 2입력이면 두 입력이 다를 때 1. F = A ⊕ B = A′B + AB′
  • XNOR : 1의 개수가 짝수면 1. 2입력이면 두 입력이 같을 때 1. F = (A ⊕ B)′

식을 보고 회로를 그릴 땐 곱(붙여 쓴 것) = AND, + = OR, ′ = NOT만 지키면 돼요. 예를 들어 F = AB + C′는 AND 하나(A, B) → OR, C는 NOT을 거쳐 같은 OR로 들어가요.

시험엔 이렇게

AND는 모두 1일 때만 1, OR는 모두 0일 때만 0, NAND · NOR는 그 반대, XOR는 1의 개수가 홀수(다르면) 1, XNOR는 짝수(같으면) 1.

외우는 법: 동그라미 = 뒤집기 · 곡선 하나 더 = XOR

직접 풀기

  1. A = 1, B = 0일 때 NAND 출력 1
  2. A = 1, B = 1일 때 XOR 출력 0
  3. A = 0, B = 0일 때 NOR 출력 1
  4. 3입력 XOR에 1, 1, 1을 넣으면 1 (1의 개수 3개, 홀수)
  5. F = AB + C′를 그릴 때 필요한 게이트 AND 1 · NOT 1 · OR 1
바로 확인
두 입력이 같을 때만 1을 내는 게이트는?
같을 때 1 = XNOR(1의 개수가 짝수). XOR는 다를 때 1이에요.

"이 식에 적용된 법칙은?" 이름을 바로 댈 수 있을까?

5장 · 기본법칙 · 교환 · 결합 · 분배 · 흡수 · 드모르간 · 합의 · 쌍대성

"이 식에 적용된 법칙이 무엇이냐"는 이름을 정확히 써야 점수가 나와요. 그리고 이 법칙들이 그대로 간소화(장면 4)의 도구예요.

기본법칙

  • A + 0 = A, A · 1 = A : 기본법칙 1 · 2 (0을 더하거나 1을 곱해도 그대로)
  • A + 1 = 1, A · 0 = 0 : 기본법칙 3 · 4 (1은 OR를, 0은 AND를 삼킨다)
  • A + A = A, A · A = A : 기본법칙 5 · 6 (같은 걸 여러 번 써도 그대로)
  • A + A′ = 1, A · A′ = 0 : 기본법칙 7 · 8 (자기와 보수)
  • (A′)′ = A : 기본법칙 9 (이중 부정)

이름이 있는 법칙

  • 교환법칙 : A + B = B + A, AB = BA
  • 결합법칙 : (A + B) + C = A + (B + C), (AB)C = A(BC)
  • 분배법칙(일반 수학과 같은 쪽) : A(B + C) = AB + AC
  • 분배법칙(불 대수에만 있는 쪽) : A + BC = (A + B)(A + C). 최대항식으로 쪼갤 때 쓴다
  • 흡수법칙 : A + AB = A, A(A + B) = A
  • 드모르간의 정리 : (A + B)′ = A′B′, (AB)′ = A′ + B′
  • 합의의 정리 : AB + A′C + BC = AB + A′C (A와 A′ 사이 가운데 항이 사라짐)
  • 쌍대성 : 0 ↔ 1, · ↔ + 를 동시에 바꾸면 짝이 되는 식이 나오는 성질
교수
A + BC를 (A + B)(A + C)로 바꾸는 것, 여기에 적용된 법칙이 뭐예요? 분배법칙. 이런 거 시험 내기 좋잖아요.10/13 강의 중 (말을 조금 다듬음)
시험엔 이렇게

식 한 줄을 보고 법칙 이름을 쓴다. A + AB = A는 흡수법칙, A + BC = (A + B)(A + C)는 분배법칙, (AB)′ = A′ + B′는 드모르간의 정리.

외우는 법: 먹으면 흡수 · 쪼개면 분배 · 바를 자르면 드모르간

직접 풀기 : 적용된 법칙은?

  1. X + XY = X 흡수법칙
  2. A + B′C = (A + B′)(A + C) 분배법칙
  3. (XY)′ = X′ + Y′ 드모르간의 정리
  4. A + A′B = (A + A′)(A + B) 분배법칙
  5. AB + A′C + BC = AB + A′C 합의의 정리
  6. (A + B) + C = A + (B + C) 결합법칙
  7. A · A′ = 0 기본법칙 8 (A · A′ = 0)
  8. ((A + B)′)′ = A + B 기본법칙 9 (이중 부정)
바로 확인
A(A + B) = A에 적용된 법칙은?
흡수법칙이에요. A(A + B) = AA + AB = A + AB = A(1 + B) = A.

시험에 반드시 나오는 드모르간, 바를 어떻게 자를까?

5장 · 드모르간의 정리 · 모자 자르기 · 진리표 증명

(A + B)′ = A′B′, (AB)′ = A′ + B′

시험 메모에 "반드시"라고 적혀 있는 단 하나의 법칙이에요.

방법은 바를 자르고, 자른 자리의 + 와 · 를 바꾸는 것이에요. 긴 바(큰 모자)를 잘라 각 변수에 작은 모자를 씌운다고 생각하면 돼요. 이미 모자가 있던 변수는 모자가 두 개가 되니 벗겨지고요(이중 부정).

(A + B + C)′  = A′ · B′ · C′          + 를 · 로
(AB′ + C)′    = (AB′)′ · C′            바깥 + 를 · 로
              = (A′ + B) · C′          안쪽 · 를 + 로, B′′ = B
((A + B′)C)′  = (A + B′)′ + C′
              = A′B + C′

드모르간

  • 드모르간의 정리 : 연산 결과를 부정한 것은 각 입력을 부정하고 AND와 OR를 바꾼 것과 같다. (A + B)′ = A′B′, (AB)′ = A′ + B′
  • 변수가 n개일 때 : 그대로 성립. (A + B + C)′ = A′B′C′
  • 진리표로 증명 : 입력 00 · 01 · 10 · 11 네 경우 모두 좌변과 우변이 같음을 보인다((A + B)′와 A′B′ 둘 다 1, 0, 0, 0)
  • 회로로 보면 : NOR = 입력마다 NOT을 단 AND, NAND = 입력마다 NOT을 단 OR

시험엔 이렇게

(A + B)′ = A′B′, (AB)′ = A′ + B′. 바를 끊고 + 와 · 를 바꾼다. 진리표 네 줄에서 양변이 같음으로 증명한다.

외우는 법: 끊고 · 바꾸고
✗ 이렇게 하면 틀려요(AB)′ = A′B′ (바만 나누고 기호를 안 바꿈)
○ 맞게 하기(AB)′ = A′ + B′ — 끊은 자리의 · 는 + 로

직접 풀기 : 드모르간으로 바 풀기

  1. (A + B′)′ A′B
  2. (A′B′)′ A + B
  3. (A + B + C′)′ A′B′C
  4. (AB + C)′ (A′ + B′)C′
  5. (A′ + BC)′ A(B′ + C′)
  6. ((A + B)C′)′ A′B′ + C
바로 확인
(A + BC′)′를 드모르간으로 풀면?
바깥 + 를 · 로 : A′ · (BC′)′, 안쪽 · 를 + 로 : (BC′)′ = B′ + C → A′(B′ + C).

카르노 맵 없이 불 대수식을 어떻게 줄일까?

5장 · 간소화 2문제 대비 · 분배 · 기본법칙 · 흡수 · 합의

11/3 안내에서 간소화가 2문제라고 하셨어요. 카르노 맵은 안 내니까 법칙으로만 줄여요. 순서는 늘 같아요. ① 공통인 걸 묶는다(분배) → ② 괄호 안이 A + A′ 꼴이면 1로 → ③ 흡수 · 분배(A + A′B = A + B)로 마무리.

예 1)  F = AB + AB′
       = A(B + B′)          분배법칙
       = A · 1 = A          기본법칙 7, 2

예 2)  F = A + A′B
       = (A + A′)(A + B)    분배법칙 A + BC = (A + B)(A + C)
       = 1 · (A + B) = A + B

예 3)  F = AB + AB′C
       = A(B + B′C)         분배법칙
       = A(B + B′)(B + C)   분배법칙(불 대수 쪽)
       = A(B + C) = AB + AC

예 4)  F = A′B′C + A′BC + AB′C
       = A′C(B′ + B) + AB′C = A′C + AB′C
       = C(A′ + AB′) = C(A′ + A)(A′ + B′) = C(A′ + B′)

예 5)  F = (A + B)(A + B′)
       = A + BB′            분배법칙(거꾸로)
       = A + 0 = A

예 6)  F = AB + A′C + BC = AB + A′C     합의의 정리

답은 진리표로 확인할 수 있어요. 변수 3개면 8줄을 다 넣어서 처음 식과 줄인 식의 결과가 같으면 맞아요. 시간이 없으면 0 · 1을 몇 개만 넣어 봐도 틀린 답은 대부분 걸러져요.

간소화에서 자주 쓰는 한 줄

  • A + A′B : A + B
  • A′ + AB : A′ + B
  • A(A′ + B) : AB
  • AB + AB′ : A
  • (A + B)(A + B′) : A
  • A + AB : A (흡수법칙)
시험엔 이렇게

공통 인수로 묶고(분배법칙), A + A′ = 1 · AA′ = 0으로 지우고, A + A′B = A + B(분배법칙)와 흡수법칙으로 마무리한다.

외우는 법: 묶고 · 지우고 · 흡수 (A + A′B = A + B)

직접 풀기 : 간소화

  1. A′B′ + A′B + AB A′ + B
  2. AB + AB′ + A′B A + B
  3. ABC + ABC′ + AB′C A(B + C) = AB + AC
  4. (A + B)(A′ + B) B
  5. A′BC + ABC + BC′ B
  6. X(X′ + Y) XY
  7. AB + A(B + C) + B(B + C) B + AC
바로 확인
F = A′ + AB를 간소화하면?
분배법칙으로 (A′ + A)(A′ + B) = 1 · (A′ + B) = A′ + B.

진리표 한 장으로 SOP와 POS를 둘 다 쓰려면?

5장 · SOP · POS · 최소항 · 최대항 · Σm ↔ ΠM · 진리표 빈칸 · 변수 채우기

SOP는 곱의 합(AND항을 OR로), POS는 합의 곱(OR항을 AND로)이에요. 변수가 하나도 빠짐없이 들어간 항을 쓰면 표준형이 되고, 그 항 하나하나가 최소항 · 최대항이에요.

최소항 · 최대항

  • SOP(곱의 합) : AND항들을 OR로 이은 식. AND-OR 회로
  • POS(합의 곱) : OR항들을 AND로 이은 식. OR-AND 회로
  • 최소항(minterm) : 함수의 모든 변수를 포함하는 AND항. 입력이 0인 변수는 보수(′), 1인 변수는 그대로(011 → A′BC)
  • 최대항(maxterm) : 함수의 모든 변수를 포함하는 OR항. 입력이 0인 변수는 그대로, 1인 변수는 보수(011 → A + B′ + C′)
  • 최소항식 Σm : 출력이 1인 줄의 최소항을 OR로 묶은 식
  • 최대항식 ΠM : 출력이 0인 줄의 최대항을 AND로 묶은 식
  • 최소항과 최대항의 관계 : 같은 번호끼리 서로 보수(Mi = mi′). 같은 함수의 Σm 번호와 ΠM 번호는 서로 나머지
  • 변수 n개일 때 항의 개수 : 최소항 · 최대항 각각 2n개

진리표 빈칸 채우기 연습 : F = A + B′C

F가 1인 줄은 1, 4, 5, 6, 7번 → F = Σm(1, 4, 5, 6, 7). 0인 줄은 0, 2, 3번 → F = ΠM(0, 2, 3) = (A + B + C)(A + B′ + C)(A + B′ + C′). 번호가 서로 나머지인 걸 확인하세요.

식으로 바꾸기 (변수 채우기)

최소항식(SOP) : 빠진 변수 X에 (X + X′) = 1을 곱한다
  F = A + B′C
    = A(B + B′)(C + C′) + (A + A′)B′C
    = ABC + ABC′ + AB′C + AB′C′ + AB′C + A′B′C
    = Σm(1, 4, 5, 6, 7)          같은 항(AB′C)은 한 번만

최대항식(POS) : 빠진 변수 X에 XX′ = 0을 더하고 분배법칙으로 쪼갠다
  F = A + B′C = (A + B′)(A + C)                       분배법칙
    = (A + B′ + CC′)(A + BB′ + C)
    = (A + B′ + C)(A + B′ + C′)(A + B + C)(A + B′ + C)
    = ΠM(0, 2, 3)
시험엔 이렇게

최소항 = 모든 변수를 포함하는 AND항(0에 바), 출력 1인 줄을 OR → Σm. 최대항 = 모든 변수를 포함하는 OR항(1에 바), 출력 0인 줄을 AND → ΠM. 같은 번호의 최소항과 최대항은 서로 보수.

외우는 법: 최소는 0에 바 · 최대는 1에 바 / Σm과 ΠM 번호는 서로 나머지
✗ 이렇게 하면 틀려요011 줄의 최대항 = A′ + B + C (최소항처럼 0에 바)
○ 맞게 하기최대항은 1에 바 : 011 → A + B′ + C′ = M3

직접 풀기

  1. 3변수 m5를 식으로 AB′C

용어 : 설명 · ★ 출제

① 게이트 ★동그라미 = 뒤집기

  • AND : 모두 1일 때만 1
  • OR : 모두 0일 때만 0
  • NAND / NOR : AND / OR 뒤집기
  • XOR : 1이 홀수면 1(다르면 1)
  • XNOR : 1이 짝수면 1(같으면 1)

② 법칙 이름 ★먹으면 흡수 · 쪼개면 분배

  • A + AB = A : 흡수법칙
  • A + BC = (A + B)(A + C) : 분배법칙
  • AB + A′C + BC = AB + A′C : 합의의 정리
  • (A′)′ = A : 이중 부정(기본법칙 9)

③ 드모르간 ★ 반드시끊고 · 바꾸고

  • (A + B)′ = A′B′
  • (AB)′ = A′ + B′
  • 증명 : 진리표 4줄에서 양변 같음

④ 간소화 ★ 2문제묶고 · 지우고 · 흡수

  • AB + AB′ = A
  • A + A′B = A + B
  • (A + B)(A + B′) = A
  • 확인 : 진리표 8줄

⑤ 최소항 · 최대항 ★최소 0에 바 · 최대 1에 바

  • 최소항 : 모든 변수의 AND항, 1인 줄 → Σm
  • 최대항 : 모든 변수의 OR항, 0인 줄 → ΠM
  • Mi = mi′, 번호는 서로 나머지

빈칸 채우기 눌러서 정답 확인

NAND는 입력이 모두 1일 때만 0을 낸다. XOR는 입력 중 1의 개수가 홀수면 1이다. A + AB = A는 흡수법칙이다. A + BC = (A + B)(A + C)는 분배법칙이다. (AB)′ = A′ + B′이다. A + A′B를 간소화하면 A + B다. 최소항은 모든 변수를 포함하는 AND항이고 출력이 1인 줄을 모은다. 같은 번호의 최소항과 최대항은 서로 보수다.

    퀴즈 다 풀고 채점하기

    Q1A = 1, B = 1일 때 출력이 0인 게이트끼리 묶은 것은?

    NAND는 모두 1이면 0, XOR는 같으면 0. NOR도 0이지만 함께 묶인 AND가 1이에요.

    Q2A + B′C = (A + B′)(A + C)에 적용된 법칙은?

    X + YZ = (X + Y)(X + Z), 불 대수에만 있는 분배법칙이에요.

    Q3(AB′ + C)′를 드모르간으로 풀면?

    바깥 + 를 · 로 → (AB′)′ · C′, 안쪽 · 를 + 로 → (A′ + B)C′.

    Q4F = AB + AB′ + A′B를 간소화하면?

    AB + AB′ = A, 그다음 A + A′B = A + B.

    Q5F = (A + B)(A′ + B)를 간소화하면?

    분배법칙(거꾸로)으로 B + AA′ = B + 0 = B.

    Q63변수에서 입력 101에 해당하는 최대항은?

    최대항은 1에 바 : A′ + B + C′ = M5. AB′C는 같은 줄의 최소항이에요.

    Q73변수 F = Σm(0, 2, 5, 7)의 최대항식은?

    0~7 중 Σm에 없는 1, 3, 4, 6이 ΠM 번호예요.

    Q84변수 A, B, C, D 함수에서 최소항인 것은?

    네 변수가 다 들어 있는 AND항은 A′BC′D뿐. A + B + C + D는 최대항, ABC는 D가 빠졌어요.

    내 말로 설명하기 답안지에 쓰듯이

    드모르간의 정리를 식으로 쓰고, 진리표로 증명하는 방법을 설명하시오.

    드모르간의 정리는 (A + B)′ = A′B′, (AB)′ = A′ + B′로, 연산 결과를 부정한 것은 각 입력을 부정하고 AND와 OR를 바꾼 것과 같다는 법칙이며 변수가 n개여도 성립한다. 증명은 A, B의 네 가지 입력 조합 00, 01, 10, 11에 대해 좌변과 우변을 계산해 비교한다. (A + B)′는 1, 0, 0, 0이고 A′B′도 1, 0, 0, 0으로 모든 줄이 같으므로 두 식은 같다.
