논리회로 이론, 1시간 안에 다 외울 수 있을까?

다 외우는 건 무리예요. 그런데 외울 필요도 없어요. 논리회로 시험은 대부분 계산 절차를 묻고, 절차는 한 번 손으로 따라 하면 외워져요. 그래서 이 페이지는 교수님이 "무조건 · 100% · 반드시"라고 한 것만 남기고, 계산은 한 줄씩 왜 그렇게 하는지까지 풀어 썼어요. 위에서부터 시간표대로 가세요. 종이랑 펜을 옆에 두고 예제를 같이 풀면 훨씬 빨리 들어와요.

장면 1

펄스 하나 주고 주파수 · 듀티 사이클을 물으면? (0~8분)

제1장 · 예제 1-4 "무조건" · 주기와 주파수 · 디지털 장단점 · 조합/순서 · ADC

펄스는 0과 1을 왔다 갔다 하는 네모 신호예요. 여기서 숫자 세 개만 알면 돼요. 주기 T는 한 번 올라갔다 내려와서 다시 올라갈 때까지 걸리는 시간, 펄스 폭 tw는 그중 High(1)로 있는 시간, 주파수 f는 1초에 몇 번 반복하느냐예요.

주기가 짧을수록 1초에 많이 반복하니까 둘은 뒤집기(역수) 관계예요: f = 1 / T. 그리고 듀티 사이클은 "한 주기 중에 High인 비율"이라 tw ÷ T × 100 (%)예요.

예제 1-4 (교수님: "숫자 바꿔서 낼게") · tw = 50 μs, T = 250 μsf = 1 / T = 1 / 250 μs
듀티 = tw / T × 100 = 50 / 250 × 100
  • 1 / 250 μsμs는 100만분의 1초예요. 1 ÷ 250 = 0.004이고, μs를 뒤집으면 "100만"이 위로 올라가서 0.004 × 1,000,000 = 4,000 Hz = 4 kHz. (외우기: μs를 뒤집으면 MHz, 1/250 MHz = 0.004 MHz = 4 kHz)
  • 50 / 250단위가 같으니 그냥 나누면 0.2 → × 100 = 20 %. 한 주기의 5분의 1만 켜져 있다는 뜻이에요.

펄스 용어

  • 주기(T) : 펄스가 한 번 반복되는 데 걸리는 시간
  • 펄스 폭(tw) : 한 주기 중 High(1)로 있는 시간
  • 주파수(f) : 1초에 반복되는 횟수. 주기의 역수 f = 1 / T
  • 듀티 사이클 : 한 주기 중 High인 시간의 비율. (tw / T) × 100 [%]
  • 리딩 에지 : 펄스가 올라가는 쪽(상승 에지)
  • 트레일링 에지 : 펄스가 내려가는 쪽(하강 에지)

디지털 기본 용어

  • 디지털의 장점 : 잡음에 강하다
  • 양자화 오차 : 연속된 값을 계단처럼 끊어 저장하면서 생기는 오차(5.5를 5로). 디지털의 최대 단점
  • word : 특정 CPU가 한 번에 다루는 명령어나 데이터의 길이에 해당하는 비트 수
  • nibble : 4비트
  • byte : 8비트
  • 정논리 : High를 1, Low를 0으로 읽는 방식
  • 부논리 : High를 0, Low를 1로 읽는 방식
  • 조합논리회로 : 기본 게이트만 조합한 회로. 기억 기능이 없다
  • 순서논리회로 : 조합논리회로에 플립플롭 · 메모리 같은 저장 요소가 더해진 회로. 저장 요소가 하나라도 있으면 순서논리
  • ADC : 아날로그를 디지털로 바꾸는 변환기. 표본화 → 양자화 → 부호화 순서
  • 샤논 정리 : 최고 주파수의 2배 이상으로 샘플링하면 원신호를 복구할 수 있다
시험엔 이렇게

f = 1 / T, 듀티 사이클 = (tw / T) × 100 [%]. 예제 1-4: tw = 50 μs, T = 250 μs → f = 4 kHz, 듀티 = 20 %.

외우는 법: 주파수는 뒤집기 · 듀티는 폭 ÷ 주기 / μs 뒤집으면 MHz
바로 확인
tw = 2 ms, T = 8 ms인 펄스의 주파수와 듀티 사이클은?
1 / 8 ms = 1 / 0.008 s = 125 Hz (ms를 뒤집으면 kHz → 1/8 kHz = 0.125 kHz). 듀티 = 2 / 8 × 100 = 25 %. 듀티는 100 %를 넘을 수 없어요.

장면 2

2진수 ↔ 10진수, 손으로 어떻게 바꿀까? (8~22분)

제2장 · 예제 2-1 "100%" · 나눠서 거꾸로 · 곱해서 순서대로 · 8진 · 16진 · 2의 보수 · 뺄셈

① 2진 → 10진 : 자리값을 곱해서 더하기 (예제 2-1)

10진수 352가 3×100 + 5×10 + 2×1인 것처럼, 2진수도 자리마다 값이 있어요. 소수점 바로 왼쪽이 1, 왼쪽으로 갈수록 두 배(2, 4, 8, 16, 32…), 오른쪽으로 갈수록 반(0.5, 0.25, 0.125…). 1이 있는 자리의 값만 더하면 끝이에요.

110010.011(2) → 10진수자리값 :  32  16   8   4   2   1 .  0.5  0.25  0.125
숫자   :   1   1   0   0   1   0 .   0    1     1
더하기 :  32 + 16           + 2      +  0.25 + 0.125 = 50.375
  • 자리값 먼저소수점 기준으로 왼쪽에 1, 2, 4, 8, 16, 32 / 오른쪽에 0.5, 0.25, 0.125를 먼저 써 놓으면 실수가 없어요.
  • 1인 자리만정수 부분 32 + 16 + 2 = 50, 소수 부분 0.25 + 0.125 = 0.375 → 50.375. 과정이 맞으면 점수를 준다고 했으니 이 줄을 꼭 쓰세요.

② 10진 → 2진 : 정수는 나눠서 거꾸로, 소수는 곱해서 순서대로

정수 부분과 소수 부분을 따로 해요. 정수는 2로 계속 나누면서 나머지를 적고, 다 나눈 뒤 아래에서 위로 읽어요. 소수는 2를 계속 곱하면서 소수점 앞에 생긴 정수(0 또는 1)를 적고, 위에서 아래로 읽어요.

48.8125 → 2진수 · 정수 4848 ÷ 2 = 24 … 0   ↑
24 ÷ 2 = 12 … 0   │
12 ÷ 2 =  6 … 0   │  아래에서 위로 읽기
 6 ÷ 2 =  3 … 0   │
 3 ÷ 2 =  1 … 1   │
 1 ÷ 2 =  0 … 1   │   → 110000

소수 0.81250.8125 × 2 = 1.625  → 1   │
0.625  × 2 = 1.25   → 1   │  위에서 아래로 읽기
0.25   × 2 = 0.5    → 0   │
0.5    × 2 = 1.0    → 1   ↓  (소수 부분이 0이 되면 멈춤) → .1101

48.8125 = 110000.1101(2)
  • 소수 곱할 때정수가 1로 나왔으면 그 1은 떼고 소수 부분만 다음 줄로 가져가요(1.625 → 0.625).
  • 검산110000 = 32 + 16 = 48, .1101 = 0.5 + 0.25 + 0.0625 = 0.8125. 맞아요.

③ 2진 → 8진 · 16진 : 소수점에서 묶기

2³ = 8, 2⁴ = 16이라서 2진수 3자리 = 8진수 1자리, 4자리 = 16진수 1자리예요. 소수점에서 시작해서 정수는 왼쪽으로, 소수는 오른쪽으로 묶고, 모자라면 0을 채워요.

110000.1101(2)8진  : 110 000 . 110 100  → 60.64(8)
       // 소수 1101은 셋씩 110 | 1 → 뒤에 00 채워 100
16진 : 0011 0000 . 1101   → 30.D(16)
       // 1101 = 13 = D (A=10 … F=15)

④ 2의 보수와 뺄셈 : 왜 굳이 이렇게 할까?

컴퓨터는 회로를 간단히 하려고 덧셈기 하나로 뺄셈까지 하고 싶어요. 5 − 3을 5 + (−3)으로 바꾸려면 −3을 2진수로 만들어야 하는데, 그 방법이 보수예요.

보수 용어

  • 보수 : 덧셈기만으로 뺄셈을 하기 위해 음수를 표현하는 방법
  • 1의 보수 : 모든 비트를 0 ↔ 1로 뒤집은 것. 만들기 쉽지만 0이 +0(0000)과 −0(1111) 두 개 생긴다
  • 2의 보수 : 1의 보수에 1을 더한 것. 0이 하나라 결과가 정확해서 컴퓨터가 쓴다
45 = 00101101 의 2의 보수 (−45 만들기)00101101      // 45
11010010      // ① 1의 보수: 전부 뒤집기
11010011      // ② +1 (맨 끝 0이 1로)

5 − 3 (4비트) = 5 + (−3)0011 → 뒤집기 1100 → +1 → 1101      // −3
  0101      // 5
+ 1101      // −3
 1 0010      // 4비트를 넘어간 맨 앞 1은 버림
→ 0010 = 2
  • +1 할 때끝자리가 1이면 받아올림이 생겨요. 예: 1의 보수가 1011이면 +1 → 1100.
  • 맨 앞 1 버림4비트 계산이라 5번째 자리로 넘친 1은 버려요. 그게 2의 보수 뺄셈의 규칙이에요.
시험엔 이렇게

2진 → 10진은 각 자리 × 2ⁿ의 합(110010.011 = 50.375). 10진 → 2진은 정수부를 2로 나눈 나머지를 역순으로, 소수부는 2를 곱해 나온 정수를 순서대로. 보수는 덧셈기만으로 뺄셈을 하기 위한 음수 표현이며, 1의 보수는 비트 반전이라 쉽지만 0이 두 개 생기고, 2의 보수는 1의 보수 + 1로 0이 하나라 정확하다. 컴퓨터는 2의 보수를 쓴다.

외우는 법: 나거 · 곱순(나눠서 거꾸로 · 곱해서 순서대로) / 삼팔 · 사십육 / 1의 보수는 쉽지만 둘
바로 확인
10진수 25를 2진수로 바꾸면?
25÷2=12…1, 12÷2=6…0, 6÷2=3…0, 3÷2=1…1, 1÷2=0…1 → 아래에서 위로 11001. 검산: 16 + 8 + 1 = 25.
바로 확인
8비트 00010100(20)의 2의 보수는?
뒤집으면 11101011, +1 하면 끝자리 1+1 = 10이라 받아올림 → 11101100. 11101011은 1의 보수에서 멈춘 거예요.

장면 3

BCD · 그레이 · 패리티 · 해밍, 하나씩 손으로 바꿔 보면? (22~36분)

제3장 · BCD 덧셈(+6) · 2진 ↔ 그레이(시험 메모) · 패리티 검출 · 해밍 정정 · 3초과

① BCD : 10진수 한 자리씩 4비트로

BCD는 10진수의 각 자리를 따로 4비트 2진수로 적는 코드예요(8421 코드). 32를 진짜 2진수로 쓰면 100000이지만, BCD는 3과 2를 따로 써서 0011 0010. 사람이 자리별로 읽기 쉬워서 숫자 표시 장치에 써요. 4비트는 0~15까지 되는데 BCD는 0000~1001(0~9)만 써요. 1010~1111 여섯 개는 버려요(비트 낭비).

그래서 BCD끼리 더하다가 한 자리 합이 9를 넘으면 그 "버린 6칸"을 건너뛰어야 해요. 그래서 0110(6)을 더해 보정해요.

69 + 85 (BCD 덧셈)   0110 1001      // 69 = 6 | 9
 + 1000 0101      // 85 = 8 | 5
 = 1110 1110      // 그냥 더한 결과: 두 칸 다 1110 = 14 → 9 초과!
 + 0110 0110      // 9를 넘은 칸마다 0110을 더함
 = 0001 0101 0100  // 1 | 5 | 4 = 154
  • 오른쪽 칸1110 + 0110 = 1 0100 → 이 칸엔 0100(4), 넘친 1은 왼쪽 칸으로
  • 왼쪽 칸1110 + 0110 + 넘어온 1 = 1 0101 → 0101(5), 넘친 1은 새 칸 0001로
  • 검산69 + 85 = 154. 칸마다 1 | 5 | 4가 맞아요.

② 2진 ↔ 그레이 (시험 메모에 있음)

그레이 코드는 바로 옆 숫자끼리 1비트만 다른 코드라 입출력 장치에서 오차가 적어요. 변환은 XOR(⊕: 같으면 0, 다르면 1)로 해요. 규칙이 비슷해 보여서 헷갈리는데, 차이는 무엇과 XOR하느냐 하나예요.

2진 1011 → 그레이 : 첫 비트 그대로, 그다음은 "2진의 앞 비트 ⊕ 2진의 현재 비트"1번째 : 2진 첫 비트 그대로        = 1
2번째 : 2진 1번째 ⊕ 2번째 = 1 ⊕ 0 = 1
3번째 : 2진 2번째 ⊕ 3번째 = 0 ⊕ 1 = 1
4번째 : 2진 3번째 ⊕ 4번째 = 1 ⊕ 1 = 0
→ 그레이 1110

그레이 1110 → 2진 : 첫 비트 그대로, 그다음은 "방금 구한 2진 ⊕ 그레이의 현재 비트"1번째 : 그레이 첫 비트 그대로          = 1
2번째 : 방금 구한 1 ⊕ 그레이 2번째 1 = 0
3번째 : 방금 구한 0 ⊕ 그레이 3번째 1 = 1
4번째 : 방금 구한 1 ⊕ 그레이 4번째 0 = 1
→ 2진 1011
  • 2진 → 그레이재료가 전부 위 줄(2진)에 있어요. 이웃한 두 개씩 XOR. "위끼리".
  • 그레이 → 2진방금 내가 구한 답과 그레이 다음 비트를 XOR. 한 칸씩 이어 가요. "결과와".
  • 검산1011 → 1110 → 1011로 돌아왔으니 맞아요.

③ 패리티 : 에러를 "알아채기만"

데이터에 비트 하나를 더 붙여서 1의 개수를 맞춰요. 짝수 패리티면 패리티 포함 1의 개수가 짝수, 홀수 패리티면 홀수. 받은 쪽에서 세어 보고 안 맞으면 에러예요. 짝수 패리티로 받은 10110은 1이 3개(홀수)라 에러. 단, 비트 2개가 동시에 바뀌면 다시 짝수가 돼서 못 잡아요. 그리고 어디가 틀렸는지는 몰라요(검출만).

④ 해밍 코드 : 틀린 자리까지 찾아서 고치기

해밍 코드는 패리티를 여러 개, 1 · 2 · 4 · 8번 자리(2의 거듭제곱)에 심어요(짝수 패리티). 각 패리티는 자기 번호 비트가 1인 자리들을 맡아요. P1은 1·3·5·7…, P2는 2·3·6·7…, P4는 4·5·6·7…. 받은 쪽에서 맡은 자리의 1을 다시 세어(짝수면 0, 홀수면 1) P8 P4 P2 P1 순서로 세우면 그 2진수가 틀린 자리 번호예요.

7비트 예시 · 5번 자리가 뒤집혀서 도착자리 :  7  6  5  4  3  2  1
받음 :  1  1  1  0  1  1  0
C1 = 1·3·5·7번 = 0+1+1+1 = 3개(홀수) → 1
C2 = 2·3·6·7번 = 1+1+1+1 = 4개(짝수) → 0
C4 = 4·5·6·7번 = 0+1+1+1 = 3개(홀수) → 1
C4 C2 C1 = 101 = 5 → 5번 자리를 뒤집어 정정

패리티 개수는 공식(2ᵖ⁻¹ − p + 1 ≤ d ≤ 2ᵖ − p − 1)으로 정하는데, p = 4면 데이터 5~11비트, 즉 8비트 데이터면 패리티 4개 · 총 12비트만 기억하면 충분해요. 검사 결과가 0000이면 에러 없음.

코드 용어

  • BCD 코드 : 10진수 각 자리를 4비트 2진수로 표현한 코드(8421 코드). 0000~1001만 쓴다
  • 3초과 코드 : BCD에 0011(3)을 더한 코드. 비가중치 코드
  • 자기보수 : 비트를 반전하면 9의 보수가 되는 성질. 3초과 코드가 가진다
  • 그레이 코드 : 인접한 값끼리 1비트만 다른 코드. 입출력 장치의 오차가 적다
  • 패리티 비트 : 에러 검사를 위해 데이터에 덧붙이는 1비트. 에러 검출만 가능
  • 짝수 패리티 : 패리티 포함 1의 개수를 짝수로 맞추는 방식
  • 홀수 패리티 : 패리티 포함 1의 개수를 홀수로 맞추는 방식
  • 해밍 코드 : 1 · 2 · 4 · 8번 자리에 패리티를 두어 에러 위치를 찾아 정정하는 코드. 짝수 패리티 사용
시험엔 이렇게

BCD는 10진수 각 자리를 4비트 2진수로 표현한 코드(8421)로 0000~1001만 쓰며, 덧셈에서 자리 합이 9를 넘으면 0110을 더해 보정한다. 2진 → 그레이는 첫 비트 그대로, 이후 2진의 앞 비트 ⊕ 현재 비트. 그레이 → 2진은 첫 비트 그대로, 이후 방금 구한 2진 비트 ⊕ 현재 그레이 비트. 패리티는 에러 검출만, 해밍 코드는 1 · 2 · 4 · 8번 자리 패리티로 에러 위치를 찾아 정정한다.

외우는 법: 9 넘으면 6 더해 / 2진→그레이는 위끼리, 그레이→2진은 결과와 / 해밍은 검사값 거꾸로 세우면 범인 주소
바로 확인
2진수 0110을 그레이 코드로 바꾸면?
첫 비트 0 그대로, 0⊕1 = 1, 1⊕1 = 0, 1⊕0 = 1 → 0101. 재료는 전부 2진(위 줄)에서.
바로 확인
그레이 코드 1011을 2진수로 바꾸면?
첫 비트 1. 방금 구한 1 ⊕ 다음 그레이 0 = 1, 1 ⊕ 1 = 0, 0 ⊕ 1 = 1 → 1101. 1110은 "위끼리"로 잘못 한 답이에요.

게이트가 얼마나 빠르고, 잡음에 버티고, 몇 개를 먹여 살릴까? (36~46분)

제4장 · 게이트 규칙 · 예제 4-8 XOR · 전파지연(4-11) · 잡음 여유도(4-13) · 팬아웃(4-15) · 3상태 버퍼

게이트 용어

  • AND : 입력이 모두 1일 때만 1. 식 AB
  • OR : 입력 중 하나라도 1이면 1. 식 A + B
  • NOT : 입력을 반전. 식 A′
  • NAND : AND의 반대. 입력이 모두 1일 때만 0. 식 (AB)′
  • NOR : OR의 반대. 입력이 모두 0일 때만 1. 식 (A + B)′
  • XOR : 입력 중 1의 개수가 홀수면 1(2입력이면 서로 다를 때 1). 식 A′B + AB′
  • XNOR : XOR의 반대. 2입력이면 서로 같을 때 1
  • 3상태 버퍼 : High · Low · Hi-Z 세 상태를 갖는 버퍼. 여러 출력이 한 선을 공유할 때 충돌을 막는다
  • Hi-Z : 선이 끊긴 것 같은 고임피던스 상태

예제 4-8 XOR의 B를 손잡이처럼 써요. B = 0이면 A가 그대로, B = 1이면 A가 뒤집혀서 나와요. A ⊕ 0 = A, A ⊕ 1 = A′이니까요. 비슷하게 AND는 한쪽이 1이면 다른 입력이 통과하고, OR는 한쪽이 0이면 통과해요.

① 전파지연 → 최대 동작 주파수

게이트에 신호를 넣어도 출력은 아주 조금 늦게 나와요. 출력이 High→Low로 바뀔 때 늦는 시간이 tPHL, Low→High일 때가 tPLH. 둘을 더하면 한 번 내려갔다 올라오는 시간, 곧 한 주기니까 뒤집으면 최대 동작 주파수예요(장면 1의 f = 1/T 그대로).

예제 4-11 · 어느 게이트가 더 빠를까?게이트 X : 5 ns + 4.5 ns = 9.5 ns   → 1 / 9.5 ns  = 105.26 MHz
게이트 Y : 8 ns + 7.5 ns = 15.5 ns  → 1 / 15.5 ns = 64.52 MHz
→ 지연이 짧은 X가 더 빠르다
  • ns 뒤집기ns는 10억분의 1초라 뒤집으면 GHz. 1 / 9.5 GHz = 0.10526 GHz = 105.26 MHz. 계산기 없으면 "1000 ÷ 9.5 ≈ 105 MHz"로 생각하면 돼요.

② 잡음 여유도 : 보내는 쪽과 받는 쪽의 "마진"

O는 Output(보내는 쪽), I는 Input(받는 쪽)이에요. Low 쪽은 받는 쪽이 "여기까진 Low로 봐 줄게"(VIL max)와 보내는 쪽이 "Low는 최대 이만큼"(VOL max)의 차이, High 쪽은 보내는 쪽 최소 High(VOH min)와 받는 쪽이 High로 인정하는 최소값(VIH min)의 차이예요. 둘 다 큰 값 − 작은 값이 되게 빼면 돼요.

예제 4-13 (74HC)VNL = VIL(max) − VOL(max) = 1.35 − 0.33 = 1.02 V    // Low는 입력 − 출력
VNH = VOH(min) − VIH(min) = 3.84 − 3.15 = 0.69 V    // High는 출력 − 입력

③ 팬아웃 : 나눠서 작은 쪽

게이트 출력 하나에 입력 몇 개를 연결할 수 있나예요. 출력이 내줄 수 있는 전류 ÷ 입력 하나가 먹는 전류. High일 때와 Low일 때 둘 다 계산해서, 둘 다 만족해야 하니 작은 쪽이 답이에요(먼저 바닥나는 쪽).

예제 4-15 (74F00)High : IOH ÷ IIH = 1 mA ÷ 0.02 mA = 50
Low  : IOL ÷ IIL = 20 mA ÷ 0.6 mA = 33.3
→ 작은 쪽, 소수는 버림 → 팬아웃 33

전력은 P = VCC × ICC (5 V × 2 mA = 10 mW).

게이트 성능 용어

  • 전파지연시간 : 입력이 바뀐 뒤 출력이 바뀔 때까지 걸리는 시간. tPHL + tPLH
  • tPHL : 출력이 High → Low로 바뀔 때의 지연
  • tPLH : 출력이 Low → High로 바뀔 때의 지연
  • 최대 동작 주파수 : 게이트가 동작할 수 있는 가장 빠른 주파수. 1 / 전파지연시간
  • 잡음 여유도 : 잡음이 섞여도 0 · 1이 바뀌지 않고 버틸 수 있는 전압 여유. 클수록 잡음에 강하다
  • 팬아웃 : 게이트 출력 하나에 연결할 수 있는 입력의 최대 개수
  • 소비 전력 : P = VCC × ICC
시험엔 이렇게

전파지연 = tPHL + tPLH, 최대 동작 주파수 = 1 / 전파지연. VNL = VIL(max) − VOL(max), VNH = VOH(min) − VIH(min). 팬아웃 = IOH/IIH와 IOL/IIL 중 작은 값. P = VCC × ICC. XOR은 1의 개수가 홀수일 때 1이며, 한 입력이 0이면 다른 입력을 그대로, 1이면 반전해 출력한다.

외우는 법: Low는 입력 − 출력, High는 출력 − 입력 / 팬아웃은 나눠서 작은 쪽 / XOR은 0이면 그대로, 1이면 뒤집기
바로 확인
tPHL = 6 ns, tPLH = 4 ns인 게이트의 최대 동작 주파수는?
6 + 4 = 10 ns → 1 / 10 ns = 0.1 GHz = 100 MHz. 10 ns는 지연이지 주파수가 아니고, 250 MHz는 4 ns 하나만 뒤집은 답이에요.

불 대수식이 나오면 무슨 법칙으로 줄일까? (46~60분)

제5장 · 공리 · 기본법칙 · 분배(일반 수학에 없는 쪽) · 흡수 · 합의 · 드모르간 "반드시" · 최소항 · 최대항 빈칸 · Σm ↔ ΠM

불 대수는 값이 0과 1밖에 없는 수학이에요. 그래서 일반 수학과 다른 게 생겨요. 1 + 1 = 2가 아니라 1 + 1 = 1(OR니까). 아래 표가 "적용된 법칙이 뭐냐" 문제의 답 목록이에요.

불 대수 용어

  • 공리 : 증명 없이 받아들이는 명제. 불 대수에서 변수는 0 또는 1이고 1 + 1 = 1
  • 쌍대성 : 0 ↔ 1, + ↔ · 를 서로 바꾸면 짝이 되는 식이 얻어지는 성질 (A + 0 = A ↔ A · 1 = A)
  • SOP(곱의 합) : AND항들을 OR로 이은 식
  • POS(합의 곱) : OR항들을 AND로 이은 식

법칙 이름 (적용된 법칙 문제용)

  • 기본법칙(0과 1) : A + 0 = A, A + 1 = 1, A · 1 = A, A · 0 = 0
  • 기본법칙(자기 자신) : A + A = A, A · A = A. 같은 걸 몇 번 써도 그대로
  • 보수 법칙 : A + A′ = 1, A · A′ = 0
  • 이중 부정 : (A′)′ = A
  • 교환 · 결합법칙 : 순서나 괄호 위치를 바꿔도 같다 (A + B = B + A)
  • 분배법칙 (일반 수학과 같음) : A(B + C) = AB + AC. 공통인 것 묶기 · 풀기
  • 분배법칙 (불 대수에만) : A + BC = (A + B)(A + C). 합 쪽으로 쪼개기
  • 흡수법칙 : A + AB = A
  • 합의의 정리 : AB + BC + A′C = AB + A′C. 가운데 BC는 없어도 된다
  • 드모르간의 정리 : (A + B)′ = A′B′, (AB)′ = A′ + B′

① 드모르간 (시험에 반드시)

식 위에 긴 바(모자)가 있으면 모자를 끊고, 그 아래 + 와 · 를 바꿔요. (A + B)′ = A′B′, (AB)′ = A′ + B′. 변수가 몇 개든 똑같아요.

(A′B + C)′ 풀기(A′B + C)′
= (A′B)′ · C′          // ① 큰 모자: 가운데 + 를 · 로 바꾸고 각자 모자
= (A″ + B′) · C′       // ② 작은 모자 (A′B)′: · 를 + 로, 각자 모자
= (A + B′)C′          // ③ A″ = A (이중 부정)
= AC′ + B′C′           // ④ 풀어 쓰면 (분배법칙)
  • 순서 주의큰 모자부터 한 겹씩. 한 번에 다 뒤집으려다가 이중 부정을 놓치는 실수가 제일 많아요.

② 줄이면서 줄마다 법칙 이름 대기

A + A′B = A + B 증명A + A′B
= (A + A′)(A + B)      // 분배법칙 X + YZ = (X + Y)(X + Z) (일반 수학에 없는 쪽)
= 1 · (A + B)          // 보수 A + A′ = 1
= A + B                // 기본법칙 1 · X = X

예제 5-8 (실습 5) : A′B′C′ + A′BC′ + A′BC + AB′C′= B′C′(A′ + A) + A′B(C′ + C)   // 공통인 것 묶기 → 분배법칙 A(B + C) = AB + AC
= B′C′ · 1 + A′B · 1           // 보수 A + A′ = 1
= B′C′ + A′B                  // 기본법칙 X · 1 = X
  • 어떻게 짝을 찾나글자 하나만 바(′)가 다르고 나머지가 똑같은 두 항을 찾아요. A′B′C′와 AB′C′는 A만 달라요 → 묶으면 A가 사라져요.
  • 짝이 남으면이미 있는 항을 한 번 더 써도 돼요(A + A = A). 이것도 법칙 문제로 나올 수 있어요.

③ 최소항 · 최대항 (진리표 빈칸)

  • 최소항(minterm) : 모든 변수를 포함하는 AND항. 입력이 0인 변수는 보수(바), 1인 변수는 그대로. 기호 소문자 m
  • 최소항식 : 출력이 1인 줄의 최소항을 OR로 묶은 식. F = Σm(…)
  • 최대항(maxterm) : 모든 변수를 포함하는 OR항. 입력이 0인 변수는 그대로, 1인 변수는 보수(바). 기호 대문자 M
  • 최대항식 : 출력이 0인 줄의 최대항을 AND로 묶은 식. F = ΠM(…)
  • 최소항과 최대항의 관계 : 같은 번호끼리 서로 보수(Mᵢ = mᵢ′)

최대항이 1에 바를 다는 건, 그 줄에서만 OR 결과가 0이 되게 하려고예요. 4변수에서 ABC처럼 변수가 하나라도 빠진 항은 최소항이 아니에요.

④ 변환 규칙

  • Σm ↔ ΠM : 같은 진리표를 1인 줄로 쓰느냐 0인 줄로 쓰느냐의 차이라 번호가 서로 나머지. F = Σm(1, 2, 3, 4, 5) = ΠM(0, 6, 7)
  • 최소항식으로 바꾸기 : 빠진 변수 D에 대해 (D + D′) = 1을 곱해서 전개
  • 최대항식으로 바꾸기 : DD′ = 0을 더한 뒤 분배법칙으로 쪼갬. A + B′ + C + DD′ = (A + B′ + C + D)(A + B′ + C + D′)
시험엔 이렇게

드모르간: (A + B)′ = A′B′, (AB)′ = A′ + B′. 불 대수에만 있는 분배법칙 A + BC = (A + B)(A + C). 최소항은 모든 변수를 포함한 AND항(0은 보수)으로 출력 1인 행을 모아 Σm, 최대항은 모든 변수를 포함한 OR항(1은 보수)으로 출력 0인 행을 모아 ΠM. 같은 함수의 Σm과 ΠM 번호는 서로 나머지다.

외우는 법: 모자 끊고 · 기호 바꾸고 / 최소 = 1 모아 Σm, 0에 바 · 최대 = 0 모아 ΠM, 1에 바 / 쪼갤 때 = 분배법칙
✗ 이렇게 쓰면 틀려요(A + B)′ = A′ + B′ (모자만 나눠 주고 기호를 안 바꿈)
○ 맞게 쓰기(A + B)′ = A′B′ — 모자를 끊으면 + 가 · 로 바뀐다

② 제2장 ★ 예제 2-1나거 · 곱순 / 삼팔 · 사십육

  • 2진 → 10진 : 자리값(2ⁿ)을 곱해 더한다. 110010.011 = 50.375
  • 10진 → 2진 : 정수는 나눠서 거꾸로, 소수는 곱해서 순서대로
  • 8진 · 16진 : 2진수 3자리 · 4자리씩 묶기
  • 2의 보수 : 1의 보수 + 1
  • 컴퓨터가 2의 보수를 쓰는 이유 : 0이 하나라 정확

③ 제3장 ★ 그레이 · BCD9 넘으면 6 / 위끼리 · 결과와

  • BCD : 10진수 각 자리를 4비트 2진수로
  • BCD 덧셈 보정 : 자리 합이 9를 넘으면 +0110
  • 2진 → 그레이 : 첫 비트 그대로, 이후 2진끼리 XOR (1011 → 1110)
  • 그레이 → 2진 : 첫 비트 그대로, 이후 방금 구한 2진과 XOR
  • 패리티 : 에러 검출만
  • 해밍 코드 : 에러 정정까지, 패리티 자리 1 · 2 · 4 · 8

④ 제4장 Low는 입력 − 출력 · 팬아웃은 작은 쪽

  • XOR : 1의 개수가 홀수면 1
  • 최대 동작 주파수 : 1 / (tPHL + tPLH)
  • VNL : VIL(max) − VOL(max)
  • VNH : VOH(min) − VIH(min)
  • 팬아웃 : IOH/IIH와 IOL/IIL 중 작은 값

⑤ 제5장 ★ 드모르간 · 법칙 · 최대항모자 끊고 기호 바꾸고 / 최대는 1에 바

  • 드모르간 : (A + B)′ = A′B′, (AB)′ = A′ + B′
  • 불 대수에만 있는 분배법칙 : A + BC = (A + B)(A + C)
  • 흡수법칙 : A + AB = A
  • 최소항 : 모든 변수의 AND항, 0에 바 (011 → A′BC)
  • 최대항 : 모든 변수의 OR항, 1에 바 (011 → A + B′ + C′)
  • Σm ↔ ΠM : 번호는 서로 나머지 (Σm(1, 2, 3, 4, 5) = ΠM(0, 6, 7))

퀴즈 8문항 종이에 먼저 풀고 고르기

Q1tw = 10 μs, T = 40 μs인 펄스의 주파수와 듀티 사이클은?

1 / 40 μs = 1/40 MHz = 0.025 MHz = 25 kHz. 10 / 40 × 100 = 25 %.

Q21101.01(2)을 10진수로?

자리값 8 4 2 1 . 0.5 0.25 → 8 + 4 + 1 + 0.25 = 13.25. 소수 첫째 자리는 0이라 0.5는 안 더해요.

Q32진수 11110110을 16진수로?

4자리씩: 1111 = 15 = F, 0110 = 6 → F6.

Q4BCD 덧셈 0111 + 0101 (7 + 5)의 결과는?

0111 + 0101 = 1100(12) → 9 초과라 +0110 → 1 0010 → 십의 자리 0001, 일의 자리 0010 = 12.

Q52진수 1001을 그레이 코드로?

1 그대로, 1⊕0 = 1, 0⊕0 = 0, 0⊕1 = 1 → 1101.

Q6IOH/IIH = 20, IOL/IIL = 10일 때 팬아웃은?

둘 다 만족해야 하니 작은 쪽 10.

Q7(A′ + B)′와 같은 것은?

모자 끊고 + → · : (A′)′ · B′ = AB′. 이중 부정 A″ = A를 놓치면 A′B′를 고르게 돼요.

Q83변수에서 입력 1 0 1 줄의 최대항과 기호는?

최대항은 1에 바: A와 C가 1 → A′, C′, B는 그대로 → A′ + B + C′. 101 = 5라서 M₅.

내 말로 설명하기 자기 직전 1분

"BCD 코드가 뭐예요?" 시험에 나왔다고 생각하고 2~3문장으로 답해 보세요.

BCD는 10진수의 각 자리를 4비트 2진수로 따로 표현한 코드(8421 코드)예요. 예를 들어 32는 0011 0010으로 써요. 0000~1001만 쓰고 1010~1111은 쓰지 않아서 비트가 낭비되고, 덧셈에서 자리 합이 9를 넘으면 0110을 더해 보정해야 해요. 대신 사람이 자리별로 읽기 쉬워서 숫자 표시 장치 같은 곳에 써요.
여기서 뺀 것 시간 남으면 압축본에서

병렬 패리티 효율(7N / 8(N+1)), 해밍 패리티 개수 공식의 유도, 합의의 정리 증명 과정, 회로 ↔ 식 바꾸기, 싱크 · 소스 전류는 이 페이지에서 짧게 넘기거나 뺐어요. 압축본과 각 날짜 페이지에 있어요. 카르노 맵(10/15)은 기말 범위예요.
