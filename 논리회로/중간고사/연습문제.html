제1장 — 듀티 사이클, 숫자만 바꿔서 10번 (예제 1-4 "무조건")

주파수 f = 1/T · 듀티 사이클 = tw/T × 100 · 단위 변환
시험엔 이렇게

주파수 f = 1 / T, 듀티 사이클 = (tw / T) × 100 [%]. 예제 1-4: tw = 50 μs, T = 250 μs → f = 4 kHz, 듀티 사이클 20 %.

외우는 법: 주파수는 뒤집기, 듀티는 폭 ÷ 주기 × 100 · 단위부터 맞추기(μs ↔ ms)

직접 풀기 — 숫자 바꾼 예제 1-4 (14문제 · 회색 칸을 누르면 답)

교수님: "숫자 바꿔서 10문제 낼게." 계산기 없이 분수로 먼저 써 보세요.

  1. tw = 50 μs, T = 250 μs (예제 1-4 원본) → 주파수와 듀티 사이클은? f = 1 / 250μs = 4 kHz, 듀티 = 50 / 250 × 100 = 20 %
  2. tw = 2 ms, T = 8 ms → 주파수와 듀티 사이클은? f = 1 / 8ms = 125 Hz, 듀티 = 2 / 8 × 100 = 25 %
  3. tw = 10 μs, T = 40 μs → 주파수와 듀티 사이클은? f = 1 / 40μs = 25 kHz, 듀티 = 10 / 40 × 100 = 25 %
  4. tw = 1 ms, T = 5 ms → 주파수와 듀티 사이클은? f = 1 / 5ms = 200 Hz, 듀티 = 1 / 5 × 100 = 20 %
  5. tw = 0.5 ms, T = 2 ms → 주파수와 듀티 사이클은? f = 1 / 2ms = 500 Hz, 듀티 = 0.5 / 2 × 100 = 25 %
  6. tw = 30 μs, T = 50 μs → 주파수와 듀티 사이클은? f = 1 / 50μs = 20 kHz, 듀티 = 30 / 50 × 100 = 60 %
  7. tw = 25 ns, T = 100 ns → 주파수와 듀티 사이클은? f = 1 / 100ns = 10 MHz, 듀티 = 25 / 100 × 100 = 25 %
  8. tw = 40 μs, T = 200 μs → 주파수와 듀티 사이클은? f = 1 / 200μs = 5 kHz, 듀티 = 40 / 200 × 100 = 20 %
  9. tw = 6 ms, T = 20 ms → 주파수와 듀티 사이클은? f = 1 / 20ms = 50 Hz, 듀티 = 6 / 20 × 100 = 30 %
  10. tw = 4 μs, T = 16 μs → 주파수와 듀티 사이클은? f = 1 / 16μs = 62.5 kHz, 듀티 = 4 / 16 × 100 = 25 %
  11. f = 1 kHz, 듀티 사이클 30 %인 펄스의 주기 T와 펄스 폭 tw는? T = 1 / f = 1 ms, tw = T × 30 / 100 = 300 μs
  12. f = 50 kHz, 듀티 사이클 40 %인 펄스의 주기 T와 펄스 폭 tw는? T = 1 / f = 20 μs, tw = T × 40 / 100 = 8 μs
  13. f = 200 Hz, 듀티 사이클 25 %인 펄스의 주기 T와 펄스 폭 tw는? T = 1 / f = 5 ms, tw = T × 25 / 100 = 1.25 ms
  14. f = 4 kHz, 듀티 사이클 75 %인 펄스의 주기 T와 펄스 폭 tw는? T = 1 / f = 250 μs, tw = T × 75 / 100 = 187.5 μs
바로 확인
T = 400 μs, tw = 100 μs인 펄스의 주파수와 듀티 사이클은?
f = 1 / 400μs = 2,500 Hz = 2.5 kHz, 듀티 = 100 / 400 × 100 = 25 %.
바로 확인
주기 10 ms, 듀티 사이클 60 %인 펄스에서 Low로 있는 시간은?
High(펄스 폭) = 10 × 0.6 = 6 ms이니 Low는 10 − 6 = 4 ms.

제2장 — 2진 → 10진은 100% 출제, 2의 보수는 서술까지

예제 2-1 · 10진 → 2 · 8 · 16진 · 묶어서 변환 · 1의 보수 · 2의 보수 · 보수 뺄셈
시험엔 이렇게

2진 → 10진은 자리값(2ⁿ)을 곱해 더한다. 예제 2-1: 110010.011(2) = 32 + 16 + 2 + 0.25 + 0.125 = 50.375. 2의 보수 = 1의 보수(비트 반전) + 1이며, 0이 하나뿐이라 컴퓨터는 2의 보수로 뺄셈을 덧셈으로 처리한다.

외우는 법: 정수는 나눠서 나머지 거꾸로, 소수는 곱해서 정수 순서대로 · 8진 3자리 · 16진 4자리

직접 풀기 — 진법 변환 (예제 2-1 "100% 출제") (18문제 · 회색 칸을 누르면 답)

과정이 맞으면 점수를 준다고 했으니, 자리값을 적는 줄까지 쓰는 연습을 하세요.

  1. 110010.011(2) (예제 2-1 원본) → 10진수 32 + 16 + 2 + 0.25 + 0.125 = 50.375
  2. 1011.101(2) → 10진수 8 + 2 + 1 + 0.5 + 0.125 = 11.625
  3. 1101.01(2) → 10진수 8 + 4 + 1 + 0.25 = 13.25
  4. 10110.1(2) → 10진수 16 + 4 + 2 + 0.5 = 22.5
  5. 111.111(2) → 10진수 4 + 2 + 1 + 0.5 + 0.25 + 0.125 = 7.875
  6. 100001.001(2) → 10진수 32 + 1 + 0.125 = 33.125
  7. 1010.011(2) → 10진수 8 + 2 + 0.25 + 0.125 = 10.375
  8. 11001.101(2) → 10진수 16 + 8 + 1 + 0.5 + 0.125 = 25.625
  9. 25(10) → 2진수 11001(2)
  10. 37(10) → 2진수 100101(2)
  11. 100(10) → 2진수 1100100(2)
  12. 0.625(10) → 2진수 0.101(2)
  13. 13.625(10) → 2진수 1101.101(2)
  14. 156(10) → 8진수, 16진수 234(8), 9C(16)
  15. 255(10) → 8진수, 16진수 377(8), FF(16)
  16. 48.8125(10) → 8진수, 16진수 60.64(8), 30.D(16)
  17. 11010110(2) → 8진수, 16진수 (3자리 · 4자리씩 묶기) 326(8), D6(16)
  18. 101111.01(2) → 8진수, 16진수 (3자리 · 4자리씩 묶기) 57.2(8), 2F.4(16)

직접 풀기 — 2의 보수 (7문제 · 회색 칸을 누르면 답)

  1. −23의 8비트 2의 보수 (+23 = 00010111) 1의 보수 11101000 → +1 → 11101001
  2. −45의 8비트 2의 보수 (+45 = 00101101) 1의 보수 11010010 → +1 → 11010011
  3. −100의 8비트 2의 보수 (+100 = 01100100) 1의 보수 10011011 → +1 → 10011100
  4. −1의 8비트 2의 보수 (+1 = 00000001) 1의 보수 11111110 → +1 → 11111111
  5. 4비트 2의 보수로 7 − 5 0111 + 1011 = 10010 → 자리올림 버리면 0010 = 2
  6. 4비트 2의 보수로 6 − 2 0110 + 1110 = 10100 → 자리올림 버리면 0100 = 4
  7. 4비트 2의 보수로 3 − 5 0011 + 1011 = 1110 → −2 (맨 앞이 1이라 음수: 2의 보수를 다시 취하면 0010 = 2)
바로 확인
100.101(2)를 10진수로 바꾸면?
4 + 0.5 + 0.125 = 4.625.
바로 확인
2의 보수를 쓰는 이유로 옳은 것은?
1의 보수는 반전만 하면 돼서 쉽지만 0이 두 개예요. 2의 보수는 0이 하나라 결과가 정확해서 컴퓨터가 써요.

제4장 — 게이트에 0과 1을 넣으면 뭐가 나올까

진리표 · XOR(예제 4-8) · 잡음 여유도 · 팬아웃 · 소비 전력
시험엔 이렇게

XOR는 1의 개수가 홀수면 1(2입력: 다르면 1), XNOR는 그 반대. AND는 모두 1일 때만 1, OR는 하나라도 1이면 1, NAND · NOR는 각각의 반전. 잡음 여유도 VNL = VIL(max) − VOL(max), VNH = VOH(min) − VIH(min), 팬아웃은 두 전류비 중 작은 값.

외우는 법: XOR = 홀수 탐지기 · Low는 입력 − 출력, High는 출력 − 입력 · 팬아웃은 작은 쪽

직접 풀기 — 게이트 출력과 게이트 계산 (12문제 · 회색 칸을 누르면 답)

계산 문제의 숫자는 연습용이에요. 공식은 9/22 페이지 기준.

  1. 2입력 XOR에 A = 1, B = 1을 넣으면? 0 (같으면 0)
  2. 3입력 XOR에 1, 1, 1을 넣으면? 1 (1의 개수 3개 = 홀수)
  3. 3입력 XOR에 1, 0, 1을 넣으면? 0 (1의 개수 2개 = 짝수)
  4. NAND에 A = 1, B = 1을 넣으면? 0 (모두 1일 때만 0)
  5. NOR에 A = 0, B = 0을 넣으면? 1 (모두 0일 때만 1)
  6. XNOR에 A = 1, B = 0을 넣으면? 0 (다르면 0)
  7. 예제 4-8: XOR의 한 입력에 구형파 A, 다른 입력 B = 1이면 출력은? A′ (반전되어 나온다), B = 0이면 A 그대로
  8. VIL(max) = 0.8 V, VOL(max) = 0.5 V일 때 Low 잡음 여유도 VNL은? 0.8 − 0.5 = 0.3 V
  9. VOH(min) = 2.7 V, VIH(min) = 2.0 V일 때 High 잡음 여유도 VNH는? 2.7 − 2.0 = 0.7 V
  10. IOH = 0.4 mA, IIH = 0.02 mA, IOL = 8 mA, IIL = 0.4 mA일 때 팬아웃은? IOH/IIH = 20, IOL/IIL = 20 → 작은 쪽 20
  11. IOH/IIH = 25, IOL/IIL = 10일 때 팬아웃은? 작은 쪽 10
  12. VCC = 5 V, ICC = 3 mA인 게이트의 소비 전력은? P = 5 × 3 mA = 15 mW
바로 확인
2입력 OR의 한 입력을 1로 고정하면 출력은?
OR는 하나라도 1이면 1이라 항상 1. 0으로 고정하면 다른 입력이 그대로 통과해요(AND는 반대로 1이 문 열기).

제3장 — BCD는 왜 1010을 안 쓸까, 패리티는 1을 센다

BCD 변환 · BCD 덧셈 +6 보정 · 짝수/홀수 패리티 · 해밍 위치
시험엔 이렇게

BCD는 10진수 각 자리를 4비트 2진수(8421)로 나타낸 코드로 0000~1001만 쓴다. BCD 덧셈에서 자리 합이 9를 넘거나 자리올림이 생기면 0110(6)을 더해 보정한다. 패리티 비트는 1의 개수를 짝수(또는 홀수)로 맞추는 비트로, 받은 쪽에서 개수가 맞지 않으면 에러로 판단한다.

외우는 법: 9 넘으면 6 더해 · 패리티는 1 세기

직접 풀기 — BCD · 패리티 (15문제 · 회색 칸을 누르면 답)

"BCD 코드가 뭐예요?"에 답할 수 있어야 한다고 했어요. 서술은 위 시험엔 이렇게 문장 그대로.

  1. 59 → BCD 0101 1001
  2. 307 → BCD 0011 0000 0111
  3. 86 → BCD 1000 0110
  4. BCD 1001 0110 → 10진수 96
  5. BCD 덧셈 38 + 45 (일의 자리 합이 9를 넘으면 +0110) 0011 1000 + 0100 0101 → 자리별 보정 → 1000 0011 = 83
  6. BCD 덧셈 27 + 15 (일의 자리 합이 9를 넘으면 +0110) 0010 0111 + 0001 0101 → 자리별 보정 → 0100 0010 = 42
  7. BCD 덧셈 69 + 85 (일의 자리 합이 9를 넘으면 +0110) 0110 1001 + 1000 0101 → 자리별 보정 → 0001 0101 0100 = 154
  8. 0110 1010은 올바른 BCD일까? 아니다. 1010(10)은 BCD에 없다(0000~1001만 사용)
  9. 데이터 1011001에 짝수 패리티 비트를 붙이면 패리티 비트는? 1의 개수 4개 → 0

제5장 — 드모르간, 모자 자르기 12번 (시험에 반드시)

(A + B)′ = A′B′ · (AB)′ = A′ + B′ · 여러 겹 모자 · NAND/NOR
시험엔 이렇게

드모르간의 정리: (A + B)′ = A′B′, (AB)′ = A′ + B′. 전체를 부정한 것은 각 변수를 부정하고 + 와 · 를 바꾼 것과 같으며 n항으로도 확장된다. 증명은 진리표에서 좌변과 우변의 열이 모든 행에서 같음을 보인다.

외우는 법: 큰 모자를 잘라 작은 모자로, 자르면 + ↔ · 바뀜 · NAND = 반전 입력 OR, NOR = 반전 입력 AND

직접 풀기 — 모자 자르기 (시험에 반드시) (12문제 · 회색 칸을 누르면 답)

모자를 한 번에 다 자르지 말고, 바깥 큰 모자부터 한 겹씩 자르세요. 답은 모두 진리표로 검산한 식이에요.

  1. (AB)′ = A′ + B′
  2. (A + B + C)′ = A′B′C′
  3. (A′B)′ = A + B′
  4. (AB′C)′ = A′ + B + C′
  5. (A + BC)′ = A′(B′ + C′) = A′B′ + A′C′
  6. (AB + C)′ = (A′ + B′)C′ = A′C′ + B′C′
  7. ((A + B)C)′ = A′B′ + C′
  8. (A′ + B′)′ = AB
  9. (A′B′)′ = A + B
  10. ((A + B′)(C′ + D))′ = A′B + CD′
  11. (A′B + C)′ = (A + B′)C′ = AC′ + B′C′
  12. (AB + CD)′ = (A′ + B′)(C′ + D′)
바로 확인
(A + B′ + C)′를 드모르간으로 바꾸면?
각각 뒤집고 + 를 · 로: A′ · B · C′ = A′BC′.
바로 확인
2입력 NOR 게이트와 같은 것은?
(A + B)′ = A′B′이니까 NOR = 입력을 반전한 AND. NAND = 입력을 반전한 OR.
바로 확인
(AB)′ = A′ + B′를 진리표로 증명할 때 확인해야 하는 것은?
모든 입력 조합(00, 01, 10, 11)에서 좌변 = 우변이어야 같은 식이에요.

제5장 — 줄이고, 줄일 때 쓴 법칙 이름 대기 (시험 메모 두 줄)

흡수 · 분배 14 · 15 · 합의 · 같은 항 추가 · 법칙 이름 맞히기
시험엔 이렇게

불 대수 간소화는 공통 인수를 분배법칙으로 묶고, X + X′ = 1과 X · 1 = X로 변수를 지운다. 짝이 남으면 X + X = X로 같은 항을 추가해 묶을 수 있다. 각 단계에 쓴 법칙(분배 · 흡수 · 합의 · 드모르간 · 교환 · 결합)과 공리를 함께 적는다.

외우는 법: 묶고(분배) → 1 만들고(X + X′) → 지우기(X · 1)

직접 풀기 — 간소화 (시험 메모 "불대수식 반드시") (12문제 · 회색 칸을 누르면 답)

답 옆에 과정 힌트가 있어요. 모든 답은 진리표로 원래 식과 같은지 검산했어요.

  1. A + AB 를 간소화 A ← A(1 + B) = A · 1 = A (흡수법칙)
  2. A(A + B) 를 간소화 A ← AA + AB = A + AB = A (흡수법칙)
  3. A + A′B 를 간소화 A + B ← (A + A′)(A + B) = 1 · (A + B) (분배법칙 → X + X′ = 1)
  4. AB + AB′ 를 간소화 A ← A(B + B′) = A · 1 (분배 → X + X′ = 1 → X · 1 = X)
  5. (A + B)(A + B′) 를 간소화 A ← A + BB′ = A + 0 (분배 X + YZ = (X + Y)(X + Z)를 거꾸로 → X · X′ = 0)
  6. AB + A′C + BC 를 간소화 AB + A′C ← 가운데 BC가 사라짐 (합의의 정리)
  7. A′B′C + A′BC + AB′C + ABC 를 간소화 C ← A′C(B′ + B) + AC(B′ + B) = A′C + AC = C(A′ + A) = C
  8. ABC + ABC′ + AB′C 를 간소화 AB + AC = A(B + C) ← ABC를 한 번 더 써서(X + X = X) AB(C + C′) + AC(B + B′)
  9. A′B′ + A′B + AB 를 간소화 A′ + B ← A′(B′ + B) + AB = A′ + AB = A′ + B (분배 15: (A′ + A)(A′ + B))
  10. (A + B)(A + C) 를 간소화 A + BC ← 분배법칙 X + YZ = (X + Y)(X + Z) (일반 수학엔 없음)
  11. A′B′C′ + A′BC′ + A′BC + AB′C′ (예제 5-8 · 과제 5) 를 간소화 B′C′ + A′B ← B′C′(A′ + A) + A′B(C′ + C)
  12. AB′ + A′B + AB 를 간소화 A + B ← AB를 한 번 더 써서 A(B′ + B) + B(A′ + A) = A + B

직접 풀기 — 이 식에 적용된 법칙은? (시험 메모) (14문제 · 회색 칸을 누르면 답)

시험 메모: "이 식에 적용된 법칙이 무엇이냐 문제 나옴". 이름을 정확히 쓰는 연습.

  1. A + 0 = A 기본법칙(항등) X + 0 = X
  2. A · A′ = 0 보수 법칙 X · X′ = 0
  3. A + A′ = 1 보수 법칙 X + X′ = 1
  4. A + A = A 기본법칙 X + X = X (같은 항 추가에 사용)
  5. (A′)′ = A 이중 부정
  6. A + B = B + A 교환법칙
  7. (AB)C = A(BC) 결합법칙
  8. A(B + C) = AB + AC 분배법칙 14
  9. A + BC = (A + B)(A + C) 분배법칙 15 (일반 수학엔 없음)
  10. A + AB = A 흡수법칙
  11. (A + B)′ = A′B′ 드모르간의 정리
  12. AB + A′C + BC = AB + A′C 합의의 정리
  13. 1 + 1 = 1 공리 P5 (불 대수에는 2가 없다)
  14. A + B′C + DD′ = (A + B′C + D)(A + B′C + D′) 분배법칙 X + YZ = (X + Y)(X + Z) (최대항 변환)
바로 확인
A + A′B = (A + A′)(A + B)로 바꾼 단계에 쓰인 법칙은?
X = A, Y = A′, Z = B로 보면 X + YZ = (X + Y)(X + Z), 분배법칙이에요. 다음 줄의 A + A′ = 1은 보수 법칙(공리).
바로 확인
AB + AB′ = A의 마지막 단계 A · 1 = A의 근거는?
1을 곱해도 그대로: X · 1 = X.

제5장 — 최소항 · 최대항 표를 가리고 채우기 (시험 메모)

시험엔 이렇게

최소항은 모든 변수를 포함하는 AND항(0은 보수, 1은 그대로, 소문자 m), 최대항은 모든 변수를 포함하는 OR항(0은 그대로, 1은 보수, 대문자 M)이다. 출력이 1인 행은 Σm으로, 0인 행은 ΠM으로 모으며, 같은 함수의 Σm과 ΠM 번호는 서로 나머지이고 Mᵢ = mᵢ′이다.

외우는 법: 최소 = 1 모아 Σm, 0에 바 / 최대 = 0 모아 ΠM, 1에 바
