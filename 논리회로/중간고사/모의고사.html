세트 A : 9문제를 40분 안에 끝낼 수 있을까?

개념 서술 · 단위 · 진법 · 보수 · BCD · 그레이 · 게이트 · Σm ΠM · 간소화

시간을 40분으로 맞추고 1번부터 끝까지 풀어 보세요. 계산 문제는 과정을 쓰면 부분 점수가 있으니 줄마다 쓰는 연습까지 같이 해요.

  1. [개념 서술] 보수를 쓰는 이유를 쓰고, 1의 보수와 2의 보수를 비교해 컴퓨터가 무엇을 쓰는지 설명하시오. 덧셈기만으로 뺄셈을 하려고 빼는 수를 음수(보수)로 바꿔 더한다. 1의 보수는 비트 반전이라 쉽지만 0이 +0 · −0 두 개, 2의 보수는 1의 보수 + 1로 0이 하나라 정확 → 컴퓨터는 2의 보수
  2. [단위] 1 KiB와 1 kB는 각각 몇 바이트인가? 1 KiB = 1024(210), 1 kB = 1000(103)
  3. [진법] ① 10진 100 → 8진 ② 2진 110101.11 → 8진, 16진 ① 144(8) ② 65.6(8), 35.C(16)
  4. [보수 계산] 8비트 2의 보수로 23 − 41을 계산하고 결과를 10진수로 쓰시오. 00010111 + 11010111 = 11101110 → 음수, 2의 보수 00010010 = 18 → −18
  5. [코드] 10진 59를 BCD와 3초과 코드로 쓰시오. BCD 0101 1001, 3초과 1000 1100
  6. [그레이] ① 2진 1101 → 그레이 ② 그레이 0111 → 2진 ① 1011 ② 0101
  7. [게이트 빈칸] 입력 AB = 00, 01, 10, 11일 때 NAND · NOR · XOR 출력을 순서대로 쓰시오. NAND 1 1 1 0 · NOR 1 0 0 0 · XOR 0 1 1 0
  8. [최소항 · 최대항] 3변수 F = Σm(0, 2, 5, 7)을 ΠM으로 쓰고, m5와 M3을 식으로 쓰시오. ΠM(1, 3, 4, 6) · m5 = AB′C · M3 = A + B′ + C′
  9. [간소화 2문제] ① F = AB + AB′C ② F = (A + B)(A + C)를 간소화하고 ②에 적용된 법칙을 쓰시오. ① AB + AC (= A(B + C)) ② A + BC, 분배법칙

  9. [간소화 · 드모르간] ① F = A′B′ + A′B + AB를 간소화 ② ((A + B′)C)′를 드모르간으로 푸시오. ① A′ + B ② A′B + C′
