CH01 — 데이터와 정보, 그리고 "공 · 통 · 저 · 운"

교재 p.35~37 · 객관식 8 · ○× 5 · 빈칸 5 · 서술 6
시험엔 이렇게

데이터는 현실 세계에서 관찰 · 수집한 객관적 사실(값 그대로), 정보는 데이터를 처리해 의사 결정에 쓸 수 있게 만든 결과다. DB는 공용 · 통합 · 저장 · 운영 데이터이며, 파일 처리 방식의 근본 문제는 데이터 종속성과 중복성이다.

외우는 법: 공 · 통 · 저 · 운 (참조 · 분석 · 독점 · 종속 데이터는 함정) · DB가 허용하는 중복은 통제된 중복

교재 CH01 연습문제 (p.35~37) (회색 칸을 누르면 답)

객관식은 답 번호와 이유를 같이 말해 보고, 서술형은 공책에 먼저 써 본 다음 열어 보세요.

  • 01 데이터와 정보에 대한 설명으로 가장 적합한 것은?
    ① 정보는 데이터를 처리해서 얻을 수 있는 결과이다 · ② 정보는 현실 세계에 존재하는 가공하지 않은 그대로의 모습이다 · ③ 데이터는 의사 결정에 직접 쓸 수 있는 수단이다 · ④ 데이터와 정보는 같은 의미이다
    ① — ②③은 데이터와 정보를 뒤바꿔 쓴 설명
  • 02 파일 처리 방식과 비교해 DBMS를 쓸 때의 장단점으로 옳지 않은 것은?
    ① 중복 최소화 · ② 일관성 유지가 쉬움 · ③ 무결성 유지가 쉬움 · ④ 데이터 간 복잡한 관계로 표준화가 어렵다
    ④ — DB는 한곳에서 관리하니 오히려 표준화가 쉬워진다
  • 03 테이블끼리 연결하려고 공통 속성을 두거나 성능을 위해 일부러 허용하는 중복을 뭐라 할까?
    ① 외래키 · ② 중복 투명성 · ③ 데이터 종속성 최소화 · ④ 제어(통제)된 중복
    ④ — DB는 중복을 없애는 게 아니라 필요한 만큼만 통제해서 허용한다
  • 04 DBMS를 통해 향상될 수 있는 장점이 아닌 것은?
    ① 데이터의 종속성 · ② 일관성 · ③ 표준화 · ④ 무결성
    ① — 종속성은 파일 시스템의 문제. DB는 독립성을 높인다
  • 05 데이터베이스의 정의로 가장 적합한 것은?
    ① 공용 · 통합 · 참조 · 운영 · ② 공용 · 분석 · 참조 · 운영 · ③ 공용 · 분석 · 저장 · 운영 · ④ 공용 · 통합 · 저장 · 운영
    ④ — 공 · 통 · 저 · 운
  • 06 DB에 저장된 데이터의 특성으로 옳지 않은 것은?
    ① 실시간 데이터 · ② 운영 데이터 · ③ 통합 데이터 · ④ 종속 데이터
    ④ — 종속은 파일 시스템의 문제
  • 07 DB 또는 DBMS 사용에 관해 가장 옳은 설명은?
    ① 혼자 쓰는 경우에도 DBMS는 필수다 · ② DB를 쓰면 기능 추가 · 확장이 쉬워 융통성이 향상된다 · ③ 오버헤드가 크니 가급적 보수적으로 결정해야 한다 · ④ 큰 기업은 정보의 표준화를 기대하기 어렵다
    ② — ①은 혼자 쓰면 파일로도 충분, ④는 오히려 표준화가 쉬워진다
  • 08 데이터베이스에 관한 설명 중 관련성이 가장 적은 것은?
    ① 통합된 데이터 · ② 실시간 처리가 가능해야 한다 · ③ DB 안의 데이터는 독점 데이터 · ④ DB 안의 데이터는 운영 데이터
    ③ — 여럿이 함께 쓰는 공용 데이터라 독점이 아니다
  • 09 참이면 ○, 거짓이면 ×
    • ① 정보는 수집된 그대로의 정량적 · 정성적 실제 값이다 × — 그건 데이터의 정의
    • ② 사용자 관점에 따라 특정 정보는 다른 누군가에게는 데이터가 될 수 있다 ○ — I = P(P(D)), 정보가 다시 입력 데이터가 된다
    • ③ 기업 전반의 운영 · 관리 정보를 통합 지원하는 정보 시스템은 ERP다 ○ — 전사적 자원 관리 시스템
    • ④ 파일 처리의 근본적 문제는 데이터 종속성과 중복성이다 ○ — 교재 "전통적 파일 시스템의 문제점"
    • ⑤ DB의 통합은 논리적 통합보다 한 곳으로 모으는 물리적 통합을 뜻한다 × — 흩어져 있어도 연결돼 접근할 수 있으면 통합, 논리적 통합
  • 10 ( ) 안에 알맞은 용어
    • ①( )는 현실 세계에서 관찰 또는 수집의 결과로 나타난 사실(fact)이다 데이터
    • ②데이터를 저장했다가 필요할 때 제공하는 역할은 정보 시스템의 핵심인 ( )가 담당한다 데이터베이스
    • ③조직의 전체 데이터를 관리하고 ( )라는 최고 경영자를 임명해 정보를 관장하게 한다 CIO (최고 정보 관리 책임자)
    • ④( )은 중복되거나 연관된 데이터 간의 의미적 불일치성 혹은 모순성이 없는 상태다 일관성
    • ⑤( )은 저장된 값이 현실 세계의 실제 값과 얼마나 정확히 일치하는지, 의미적 정확성이다 무결성
  • 11 데이터와 정보의 차이를 설명하시오.
    데이터는 현실 세계에서 관찰 · 수집한 객관적 사실로 가공하지 않은 값 그대로(예: 출석, 중간 80, 기말 90)이다. 정보는 데이터를 처리해 의사 결정에 유용하게 만든 결과(예: 학점 A+)이다. 정보 시스템은 I = P(D)로 데이터를 정보로 만든다.
  • 12 정보 시스템의 구조와 종류를 설명하시오.
    구조: 현실 세계의 데이터(D)를 수집해 가공 처리(P)하고 정보(I)를 만들어 의사 결정에 쓰며, 데이터의 저장 · 제공은 DB가 맡는다. 종류(교재 표): 업무별 = 생산 · 마케팅 · 인사 · 재무회계 정보 시스템, 기능별 = 거래 처리(TPS) · 경영 정보(MIS) · 전문가(ES) · 의사 결정 지원(DSS) · 전사적 자원 관리(ERP) 시스템.
  • 13 파일 정보 시스템과 비교한 DB 시스템의 장점은?
    데이터 중복 최소화(통합 저장소), 데이터 독립성(종속성 해결), 데이터 공유(동시 공용), 일관성 · 무결성 유지, 보안 강화, 표준화, 장애 시 회복 기능. 모든 접근을 DBMS를 통해서만 하기 때문이다.
  • 14 시대별 DB 시스템의 성장 과정을 개략적으로 설명하시오.
    전통 파일 시스템(프로그램이 파일 구조에 묶임 → 종속성) → 개선 1: 프로그램별 파일(같은 데이터가 여러 곳 → 중복성) → 개선 2: 파일 하나로 통합(동시 사용 · 회복 불가 → 공유 한계) → DB 시스템(DBMS가 감싸 모든 접근을 DBMS로, 동시성 · 권한 · 회복 해결).
  • 15 좁은 의미의 데이터베이스를 정의하시오.
    여러 사용자가 공유하도록 통합 · 저장된 운영 데이터의 집합. 즉 공용 · 통합 · 저장 · 운영 데이터이며, 형식이 엄격하게 관리된다(뱅킹, 예매).
  • 16 DB의 주요 특성 4가지를 설명하시오.
    실시간 접근(요청에 바로 응답), 끊임없는 변화(삽입 · 삭제 · 수정으로 늘 최신), 동시 공용(여러 사용자가 동시에 같은 데이터 사용, 가장 중요), 내용 기반 참조(위치가 아니라 값으로 찾음).

CH02 — 사용자 · 언어 · 3단계 구조를 문제로 확인

교재 p.61~64 · 객관식 13 · ○× 5 · 빈칸 10 · 서술 5
시험엔 이렇게

DBMS 필수 기능은 정의 · 조작 · 제어이고 각각 DDL · DML · DCL로 수행한다. 3단계 구조는 외부(여러 개) · 개념(1개) · 내부(1개) 스키마이며, 외부/개념 사상이 논리적 독립성, 개념/내부 사상이 물리적 독립성을 준다. 데이터 사전은 메타 데이터 저장소로 사용자는 검색만, 갱신은 DBMS만 한다.

외우는 법: 정 · 조 · 제 = DDL · DML · DCL · 외개내 = 여럿 · 하나 · 하나 · E-R은 모델링 도구지 DBMS 분류 모델이 아님

교재 CH02 연습문제 (p.61~64) (회색 칸을 누르면 답)

  • 01 DB 시스템의 장점이 아닌 것은?
    ① 통합성 · ② 독립성 · ③ 종속성 · ④ 일관성
    ③ — 종속성은 파일 시스템의 문제
  • 02 DBA의 역할로 거리가 먼 것은?
    ① 보안 및 권한 부여 · ② DBMS 개발 · ③ 스키마 정의 · ④ 백업 및 회복
    ② — DBMS는 만들어진 소프트웨어를 쓰는 것, 개발은 DBMS 회사의 일
  • 03 DBA의 주요 역할로 거리가 먼 것은?
    ① 접근 권한과 회복 절차 수립 · ② 구성 요소 결정과 내부 저장 구조 정의 · ③ 조작어를 호스트 언어에 포함하여 DB에 접근 · ④ 시스템 감시 · 성능 분석과 개선
    ③ — 프로그램 코드 안에 SQL을 넣는 건 응용 프로그래머
  • 04 DBMS 필수 기능 · 데이터 언어 · 사용자가 바르게 연결된 것은?
    ① 저장 기능 - DSL - 일반 사용자 · ② 조작 기능 - DML - DBA · ③ 정의 기능 - DDL - 일반 사용자 · ④ 제어 기능 - DCL - 응용 프로그래머
    ② — ①은 필수 기능에 저장이 없고, ③ DDL과 ④ DCL은 DBA 몫. DBA는 DML도 쓰니 ②만 틀린 데가 없다 (교재 해답이 없어 추론한 답)
  • 05 DDL과 가장 관련이 적은 것은?
    ① 데이터 사전 · ② 데이터 조작어 · ③ 메타 데이터 · ④ 스키마
    ② — DDL은 구조 정의 → 스키마 · 데이터 사전 · 메타 데이터와 연결. 조작어는 DML
  • 06 DBMS의 제어 기능으로 옳지 않은 것은?
    ① 무결성이 손상되지 않도록 제어 · ② 모든 사용자가 제한 없이 자유롭게 접근하도록 관리 · ③ 정확성 · 안전성 유지 · ④ 동시 접근을 위한 병행 제어
    ② — 제어 기능은 권한 있는 사용자만 접근하게 하는 보안을 포함
  • 07 DBMS의 주요 구성 요소가 아닌 것은?
    ① 질의어 처리기 · ② 트랜잭션 관리기 · ③ 저장 데이터 관리기 · ④ 스케줄러
    ④ — 구성: 컴파일러 · 질의 처리기 · 런타임 처리기 · 트랜잭션 관리자 · 저장 데이터 관리자
  • 08 DB와 DBMS 유형을 분류하는 데이터 모델이 아닌 것은?
    ① 계층형 · ② 관계형 · ③ 개체-관계형(E-R) · ④ 객체-관계형(O-R)
    ③ — E-R은 개념적 설계(모델링)용. 분류 모델은 계층 · 네트워크 · 관계 · 객체 지향 · 객체 관계
  • 09 시스템 DB(시스템 카탈로그)에 대한 설명으로 옳지 않은 것은?
    ① 일반 질의어로 내용을 검색할 수 있다 · ② 스키마 정보를 제공한다 · ③ 사용자가 직접 갱신할 수 있다 · ④ DBMS가 스스로 생성 · 유지한다
    ③ — 검색은 가능, 갱신은 DBMS만

DDL = CREATE · ALTER · DROP, DCL = GRANT · REVOKE. WITH GRANT OPTION이면 받은 권한을 남에게 줄 수 있고, REVOKE ... CASCADE는 연쇄로 회수한다. 뷰는 데이터를 저장하지 않는 가상 테이블이고, 인덱스는 검색을 빠르게 하지만 많다고 무조건 좋지는 않다.
