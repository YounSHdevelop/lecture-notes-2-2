장면 1

휴대폰번호를 안 적은 학생을 찾고 싶다 — = NULL은 왜 안 될까?

IS NULL · IS NOT NULL · 예제 5-15 · NULL ≠ 0 ≠ 공백

SELECT 이름 FROM 학생 WHERE 휴대폰번호 = NULL;

univDB에는 휴대폰번호가 비어 있는 학생이 두 명 있는데, 이 문장을 실행하면 한 명도 안 나와요. 오류도 안 나고 그냥 빈 결과예요.

NULL은 "아직 정해지지 않은 값", 즉 모르는 값이에요. 입력을 생략하면 대신 들어가요. 중요한 건 NULL이 0도 아니고, 공백 문자 ' '도 아니고, 빈 문자 ''도 아닌 특별한 값이라는 거예요. 모르는 값과 비교하면 결과도 "모른다"가 되니까, = · > · <= 같은 비교 연산자로는 NULL을 찾을 수 없어요.

그래서 NULL을 찾을 때는 전용 연산자를 써요. NULL인 것은 IS NULL, NULL이 아닌 것은 IS NOT NULL.

예제 5-15 · 휴대폰번호가 등록되지 않은 학생의 이름과 휴대폰번호SELECT 이름, 휴대폰번호
FROM 학생
WHERE 휴대폰번호 IS NULL ;
이름휴대폰번호
홍길동 (s002)NULL
이승엽 (s003)NULL
헷갈리기 쉬운 데이터 — 홍길동(s002)의 주소는 DEFAULT로 입력돼서 '미정'이라는 값이 들어 있어요. 그래서 WHERE 주소 IS NULL을 하면 홍길동은 안 나오고 이승엽 한 명만 나와요. 이승엽은 주소에 NULL을 직접 넣었거든요. (10/8의 COUNT(주소) = 6도 같은 이유)
시험엔 이렇게

NULL은 아직 지정되지 않은 값으로 0, 공백 문자, 빈 문자와 다른 특별한 값이라 =, >, <= 같은 비교 연산자로는 비교할 수 없다. 널 값을 찾을 때는 '=' 대신 IS NULL을, 널이 아닌 값을 찾을 때는 '<>' 대신 IS NOT NULL을 사용한다.

외우는 법: NULL은 같다(=)가 아니라 이다(IS)
바로 확인
SELECT 이름 FROM 학생 WHERE 주소 IS NULL;의 결과는? (univDB)
홍길동(s002)의 주소는 DEFAULT '미정'이라는 값이에요. 주소가 진짜 NULL인 건 이승엽 한 명뿐이에요.

장면 2

나이를 모르는 학생의 나이에 1을 더하면?

NULL 연산 세 가지 · 산술식 = NULL · 집계에서 제외 · 비교는 거짓

교재 Note에 NULL을 쓸 때 조심할 세 가지가 있어요. 교수님은 지난 시간 COUNT 얘기와 이어서 설명했어요. "카운트할 때만 다르고, 그 외 집계 함수에서는…"

규칙univDB로 확인
① NULL이 포함된 산술식의 결과는 항상 NULL이영애(s004)는 나이가 NULL → 나이 + 1도 NULL
② NULL이 포함된 행은 대부분의 집계 함수에서 제외COUNT(*) = 7이지만 COUNT(나이) = 6, SUM(나이) = 151, AVG(나이) = 151 ÷ 6 ≈ 25.17 (7로 안 나눔)
③ NULL을 일반 비교 연산자로 비교하면 결과는 거짓WHERE 나이 <> 23 하면 26 · 30 · 26은 나오지만 나이가 NULL인 이영애는 안 나옴

③이 은근히 함정이에요. "나이가 23이 아닌 학생"이라고 하면 사람 생각엔 나이를 모르는 이영애도 들어갈 것 같지만, SQL은 "모르는 값이 23이 아닌지도 모른다"고 보고 빼 버려요. 꼭 넣고 싶으면 OR 나이 IS NULL을 따로 붙여야 해요.

시험엔 이렇게

NULL이 포함된 산술식 연산의 결과는 항상 NULL이고, NULL이 포함된 행은 대부분의 집계 함수 결과에서 제외되며(COUNT(*)는 모든 행을 셈), '100 <> NULL'처럼 널 값을 일반 비교 연산자로 비교하면 결과는 항상 거짓이다.

외우는 법: 더하면 NULL, 모으면 빠지고, 비교하면 거짓
바로 확인
SELECT COUNT(*), COUNT(나이) FROM 학생;의 결과는? (나이가 NULL인 학생 1명)
COUNT(*)는 행을 전부 세서 7, COUNT(나이)는 NULL인 이영애를 빼고 6.

장면 3

'여'학생이거나 'A'학점을 받은 학생 — 테이블 두 개의 결과를 어떻게 합칠까?

집합 연산자 · UNION(합집합) · 예제 5-16 · 중복 자동 제거 · 합병 가능 조건

성별은 학생 테이블에 있고, 학점은 수강 테이블에 있어요. 두 테이블에서 각각 학번을 뽑은 다음 결과를 합치면 되겠죠. 이렇게 서로 다른 SELECT 결과가 의미적으로도 형식적으로도 일치할 때(여기선 둘 다 "학번" 한 열) 관계 대수의 집합 연산을 쓸 수 있어요. CH04에서 배운 "합병 가능" 조건이에요.

예제 5-16 · '여'학생이거나 'A'학점을 받은 학생의 학번SELECT 학번 FROM 학생 WHERE 성별 = '여'      // s001, s004, s005, s007
UNION
SELECT 학번 FROM 수강 WHERE 평가학점 = 'A' ;  // s001, s004, s004 (s004가 A를 두 과목)
결과 (학번)왜
s001여학생이면서 A (양쪽에 있지만 한 번만)
s004여학생이면서 A를 두 번 (그래도 한 번만)
s005여학생
s007여학생

합치면 s001이 두 번, s004가 세 번 나오지만 UNION은 결과에서 중복 행을 자동으로 제거해요. 그래서 4행. 여기서는 A학점 받은 학생이 전부 여학생이라 결과가 여학생 목록과 같아요.

시험엔 이렇게

서로 다른 SQL 검색문의 결과 집합이 의미적 · 형식적으로 일치할 경우 관계 대수의 집합 연산자를 적용할 수 있다. UNION(합집합)은 여러 SELECT 문의 검색 결과를 결합하고, 결과 테이블에서 중복 행을 자동으로 제거한 나머지 행들을 반환한다.

외우는 법: UNION = 합치고 중복은 한 번만
바로 확인
SELECT 학번 FROM 학생 WHERE 성별 = '남' UNION SELECT 학번 FROM 수강 WHERE 평가학점 = 'B';의 결과는? (B학점: s003 두 과목, s001 한 과목)
남학생 s002 · s003 · s006에 B학점 s003 · s001 · s003을 합치고 중복 제거 → 4행. s003 하나만 나오는 건 교집합이에요.

장면 4

교재는 "MySQL은 교집합 · 차집합이 안 된다"는데, 교수님은 된다고?

INTERSECT(교집합) · EXCEPT(차집합) · MySQL 8.0.31 이상 · MINUS는 없음 · 교재 정정

교재 p.23 아래에 이런 줄이 있어요. "MySQL: INTERSECT(교집합), EXCEPT 또는 MINUS(차집합) 연산자 등 지원하지 않음". 교수님이 이 줄을 정정했어요. 여러분이 깐 MySQL은 8.0대 최신 버전(아마 8.3쯤)이라 INTERSECT를 쓸 수 있다고요. 8.0.31보다 낮은 버전에서는 안 먹고요. MINUS는 오라클 쪽 이름이라 MySQL에는 없어요. MySQL에서 차집합은 EXCEPT라는 이름으로 써요.

교수
8.0 이상 쓰는 경우는 책에 있는 내용과 다르게 인터섹트는 씁니다. 마이너스는 쓰지 않아요. 책에 있는 이 내용은 교정합니다. 예시를 준비해 뒀으니까 한번 해 보세요. 중요합니다.10/13 강의 중 (녹음 인식이 많이 깨져서 뜻만 다듬어 옮김)
교집합 · '여'학생이면서 'A'학점을 받은 학생SELECT 학번 FROM 학생 WHERE 성별 = '여'
INTERSECT
SELECT 학번 FROM 수강 WHERE 평가학점 = 'A' ;   // 결과: s001, s004

차집합 · '여'학생 중에서 'A'학점을 받은 학생을 뺀 학번SELECT 학번 FROM 학생 WHERE 성별 = '여'
EXCEPT
SELECT 학번 FROM 수강 WHERE 평가학점 = 'A' ;   // 결과: s005, s007

차집합 결과가 수업 때 나온 "5번, 7번"이에요. 여학생 {s001, s004, s005, s007}에서 A학점 {s001, s004}를 빼면 s005, s007이 남죠. 순서도 중요해요. A EXCEPT B와 B EXCEPT A는 달라요. 거꾸로 하면 "A학점 중 여학생이 아닌 학생"이라 결과가 없어요.

연산자뜻여학생 ○ A학점 결과MySQL
UNION합집합 (중복 제거)s001, s004, s005, s007됨
INTERSECT교집합s001, s0048.0.31부터 됨 (교재와 다름)
EXCEPT차집합s005, s0078.0.31부터 됨
MINUS차집합 (오라클식 이름)—안 됨
시험엔 이렇게

INTERSECT는 두 검색 결과에 공통으로 있는 행(교집합)을, EXCEPT(MINUS)는 첫 번째 결과에서 두 번째 결과에 있는 행을 뺀 행(차집합)을 반환한다. 교재는 MySQL이 지원하지 않는다고 했으나 MySQL 8.0.31 이상에서는 INTERSECT와 EXCEPT를 사용할 수 있고, MINUS는 지원하지 않는다.

외우는 법: 합 UNION · 교 INTERSECT · 차 EXCEPT(MINUS는 오라클)
바로 확인
SELECT 학번 FROM 학생 WHERE 성별 = '남' INTERSECT SELECT 학번 FROM 수강 WHERE 평가학점 = 'B';의 결과는?
남학생 {s002, s003, s006}과 B학점 {s001, s003}에 둘 다 있는 건 s003뿐이에요. s002, s006은 남학생 EXCEPT B학점의 결과예요.

★ 시험 관련

① NULL 찾기

  • NULL : 아직 지정되지 않은 값. 0, 공백 문자, 빈 문자와 다른 특별한 값
  • IS NULL / IS NOT NULL : NULL을 찾는 연산자. = 나 <> 로는 못 찾음 (예제 5-15 → 홍길동, 이승엽)

② NULL 연산 더하면 NULL, 모으면 빠짐, 비교하면 거짓

  • 산술식 : NULL이 들어가면 결과도 NULL (이영애 나이 + 1 = NULL)
  • 집계 : NULL 행은 빠짐. COUNT(*) = 7, COUNT(나이) = 6, AVG(나이) = 151 ÷ 6
  • 비교 : 나이 <> 23에 이영애는 안 나옴

③ 집합 연산자 ★ 결과 말하기

  • UNION : 합집합, 중복 자동 제거 (예제 5-16 → s001, s004, s005, s007)
  • INTERSECT : 교집합 (여 ∩ A → s001, s004)
  • EXCEPT : 차집합 (여 − A → s005, s007), 순서가 바뀌면 결과도 바뀜
  • 조건 : 두 결과가 의미적 · 형식적으로 일치(합병 가능)

④ 교재 정정 ★

  • 교재 "MySQL은 INTERSECT · EXCEPT 지원 안 함" → 8.0.31 이상은 지원, MINUS는 안 됨

빈칸 채우기 눌러서 정답 확인

널 값을 찾을 때는 '=' 대신 IS NULL을, 널이 아닌 값을 찾을 때는 IS NOT NULL을 쓴다. NULL이 포함된 산술식의 결과는 항상 NULL이고, NULL이 포함된 행은 대부분의 집계 함수에서 제외된다. 두 검색 결과를 합치고 중복을 제거하는 연산자는 UNION, 공통 행만 남기는 것은 INTERSECT, 첫 결과에서 둘째 결과를 빼는 것은 EXCEPT다. MySQL에서 교집합은 8.0.31 이상 버전부터 쓸 수 있다.

    Q4SELECT 이름 FROM 학생 WHERE 나이 <> 23;에 나오는 학생 수는?

    Q5예제 5-16(여학생 UNION A학점)의 결과 행 수는?

    4 + 3 = 7행이 합쳐지지만 UNION은 중복을 제거해서 s001, s004, s005, s007 네 행.

    Q6"A학점 받은 학생 EXCEPT 여학생"의 결과는?

    A학점 {s001, s004}가 전부 여학생이라 빼고 나면 아무도 안 남아요. 순서를 바꾸면 결과가 달라지는 예.

    Q7MySQL 8.3에서 차집합을 구할 때 쓰는 연산자는?

    MySQL은 EXCEPT(8.0.31부터). MINUS는 오라클식 이름이라 MySQL에서는 안 돼요.

    Q8집합 연산자를 쓰려면 두 SELECT 결과가 어때야 할까?

    학생과 수강처럼 다른 테이블이어도 돼요. 결과 열의 개수와 의미 · 형식이 맞으면 돼요(CH04 합병 가능).

    내 말로 설명하기 친구한테 말하듯이

    "WHERE 휴대폰번호 = NULL로 하면 왜 아무것도 안 나와?"라고 묻는 친구에게 설명하고, 맞는 문장도 알려 주세요.

    NULL은 0이나 빈칸이 아니라 "아직 정해지지 않은, 모르는 값"이에요. 모르는 값을 = 로 비교하면 같은지 다른지도 모르니까 참이 안 돼서 아무 행도 안 나와요. 그래서 NULL을 찾을 땐 비교 연산자 대신 전용 연산자 IS NULL을 써야 해요. SELECT 이름, 휴대폰번호 FROM 학생 WHERE 휴대폰번호 IS NULL; 이렇게 하면 홍길동이랑 이승엽이 나와요. 반대로 번호가 있는 학생은 IS NOT NULL.
    더 알아두면 좋은 것 다음 진도 · 참고

    UNION ALL

    중복을 지우지 않고 다 보여 주는 버전이에요. 예제 5-16을 UNION ALL로 하면 s001, s004, s005, s007, s001, s004, s004 일곱 행이 나와요. 교재 p.23에는 없는 내용이라 참고만.

    SELECT 안에 또 SELECT를 넣는 부 질의문, IN · NOT IN · EXISTS, 그다음 조인(크로스 · 동등 · 셀프 · 외부)이 이어져요.
