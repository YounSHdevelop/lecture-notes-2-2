장면 1

뭘, 어디서, 어떤 조건으로 — SELECT문의 뼈대

SELECT 형식 6개 절 · 실행 순서 · [ ] 생략 · { } 반복 · 예제 5-1 · 5-2

DB 작업은 대부분 SELECT로 시작해요. INSERT로 넣는 건 실무에선 파일로 통째로 넣는 경우가 많고, 쌓인 데이터 중 원하는 것만 조회해서 가져오는 게 SELECT예요. 교수님 말로 "뭐를, 어디서, 어떤 조건으로" 이 세 가지가 기본이에요.

SELECT 명령문의 형식 (자료 p.12) — 오른쪽 숫자 = 실행 순서SELECT [DISTINCT|ALL] 열_리스트              ⑤ 뭘 보여 줄까
FROM   테이블_리스트                          ① 어디서
[WHERE 검색_조건식]                           ② 행 고르기
[GROUP BY 그룹_기준열_리스트]                  ③ 묶기
[HAVING 그룹_조건식]                          ④ 묶음 고르기
[ORDER BY {정렬_기준열 [ASC|DESC][,]}*];      ⑥ 정렬 (맨 마지막!)
  • [ ]는 생략 가능, { }는 반복 가능. |는 선택, +는 1번 이상, *는 0번 이상 반복.
  • 그래서 SELECT + FROM 두 줄만으로도 완성된 문장이에요. 조건이 없으면 WHERE를 생략하고 다 가져와요.
  • 결과는 항상 테이블(2차원 표) 모양으로 돌아와요. 맨 위가 속성(열) 이름, 그 밑이 실제 값.

시험엔 이렇게

SELECT문은 SELECT(열 리스트) · FROM(테이블) · WHERE(검색 조건) · GROUP BY(그룹 기준) · HAVING(그룹 조건) · ORDER BY(정렬)로 구성되며, 실행 순서는 FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY다. SELECT와 FROM은 필수, 나머지는 생략 가능하다. *는 모든 열을 뜻한다.

교수님 말대로 "학과가 몇 개로 구분돼 있는지 쉽게 알 수 있어요". DISTINCT의 반대는 ALL인데, 안 쓰면 기본이 ALL(전부)이에요. 그리고 DISTINCT는 SELECT 바로 뒤에 한 번만 써요 — "중복 없이 가져와"를 두 번 말해도 결과는 같으니까요.

AS는 결과 열에 새 이름(별칭)을 붙여요. SELECT COUNT(*) AS 학생수 FROM 학생; → 열 제목이 "학생수". 원래 테이블에 없는 열(계산 결과)을 새로 만들 때 써요.

시험엔 이렇게

DISTINCT는 검색 결과에서 중복 행을 제거하고, ALL(기본값)은 중복을 포함해 모두 검색한다. AS는 결과 열에 별칭을 붙인다.

2학년 이상이면서 컴퓨터학과인 학생만 — 조건 걸기

WHERE · 비교 연산자 · AND · OR · NOT · BETWEEN AND · 예제 5-4 · 5-5

WHERE는 FROM에서 가져온 행 중 조건에 맞는 행만 남겨요. 교수님 예처럼 "24학번 이상만", "남학생만", "졸업자만" 같은 거요. 비교는 = <> > >= < <=, 여러 조건은 AND · OR · NOT으로 이어요. 문자 · 날짜 값은 작은따옴표로 감싸요('컴퓨터').

예제 5-4 · 2학년 이상인 '컴퓨터'학과 학생의 이름, 학년, 소속학과, 휴대폰번호SELECT 이름, 학년, 소속학과, 휴대폰번호
FROM 학생
WHERE 학년 >= 2 AND 소속학과 = '컴퓨터';

성적 높은 학생부터 줄 세우기 — 정렬은 맨 마지막에

ORDER BY · ASC · DESC · 정렬 기준 여러 개 · NULL 위치 · 예제 5-6 · 5-7

ORDER BY는 위의 절들이 다 끝나서 나온 최종 결과를 정렬해요. 실행 순서도 맨 마지막(⑥). ASC는 오름차순(작은 것 → 큰 것, 기본값), DESC는 내림차순(큰 것 → 작은 것). 교수님 예로 "가장 성적이 좋은 학생부터"는 내림차순(91점부터 내려가며).

시험엔 이렇게

COUNT(*)는 7인데 COUNT(주소)는 왜 6일까?

집계 함수 · NULL과 집계 · GROUP BY · HAVING · 예제 5-8 ~ 5-12

저장된 값이 아니라 "몇 명인지", "평균은 얼마인지" 같은 통계가 필요할 때 쓰는 게 집계 함수예요: COUNT · MAX · MIN · SUM · AVG.

예제 5-8 (실습 파일 ch5_univDB_table_gen.sql에도 있음)SELECT COUNT(*) AS 학생수1, COUNT(주소) AS 학생수2, COUNT(DISTINCT 주소) AS 학생수3
FROM 학생;
학생수1학생수2학생수3
765
  • COUNT(*) — 행 개수 전부: 7
  • COUNT(주소) — 주소가 NULL인 행은 빼고: 이승엽 빠져서 6 ('미정'은 값이라 셈)
  • COUNT(DISTINCT 주소) — 중복까지 빼고: 서울 서초 · 미정 · 경기 분당 · 서울 종로 · 경기 과천 = 5

예제 5-9 SELECT AVG(나이) '여학생 평균나이' FROM 학생 WHERE 성별 = '여'; → 여학생 나이 23, NULL, 23, 23 중 NULL은 빼고 평균 23. NULL이 포함된 행은 대부분의 집계에서 제외돼요.

묶어서 세기 — GROUP BY와 HAVING

GROUP BY는 같은 값끼리 그룹으로 묶어요(교수님 예: 남녀로 묶기). HAVING은 그 그룹에 조건을 걸어요. WHERE가 행을 거른다면 HAVING은 그룹을 걸러요.

예제 5-10 · 성별 최고 나이와 최저 나이SELECT 성별, MAX(나이) AS '최고 나이', MIN(나이) AS '최저 나이'
FROM 학생 GROUP BY 성별;
-- 결과: 여 23 23  |  남 30 26

예제 5-11 · 20대 학생만 나이별 학생수SELECT 나이, COUNT(*) AS '나이별 학생수'
FROM 학생 WHERE 나이 >= 20 AND 나이 < 30 GROUP BY 나이;
-- 결과: 23 → 3명 (김연아, 송윤아, 이은진)  |  26 → 2명 (홍길동 ×2)

예제 5-12 · 학생이 2명 이상인 학년만 학년별 학생수SELECT 학년, COUNT(*) AS '학년별 학생수'
FROM 학생 GROUP BY 학년 HAVING COUNT(*) >= 2;
-- 결과: 1학년 2 · 2학년 2 · 4학년 2   (3학년은 1명이라 빠짐)
시험엔 이렇게

집계 함수 COUNT · MAX · MIN · SUM · AVG는 열 값의 통계를 반환하며, NULL이 포함된 행은 대부분의 집계에서 제외된다(COUNT(*)는 전체 행). GROUP BY는 기준열이 같은 행끼리 그룹을 만들고, HAVING은 그룹에 대한 조건을 지정한다. WHERE는 행, HAVING은 그룹에 대한 조건이다.

외우는 법: *은 다 세고, 열 이름은 NULL 빼고 센다 / WHERE는 사람을, HAVING은 반을 거른다
바로 확인
SELECT COUNT(휴대폰번호) FROM 학생;의 결과는?
휴대폰번호가 NULL인 홍길동(s002) · 이승엽 2명을 빼고 5.

예제 5-13 · '이'씨 성을 가진 학생의 학번과 이름SELECT 학번, 이름
FROM 학생

예제 5-14 · 주소에 '서울'이 들어간 학생의 이름, 주소, 학년을 학년 내림차순SELECT 이름, 주소, 학년
FROM 학생
WHERE 주소 LIKE '%서울%'
ORDER BY 학년 DESC;
-- 결과: 김연아 서울 서초 4 · 홍길동 서울 종로 2
헷갈림'이__'와 '이%'는 같다
정답'이__'는 정확히 3글자만, '이%'는 '이'로 시작하는 모든 길이(이, 이몽룡, 이수일과심순애…)
시험엔 이렇게

LIKE는 부분 문자열 포함 여부를 검색하기 위해 WHERE절에 쓰는 비교 연산자로, _는 특정 위치의 1개 문자, %는 임의 위치의 0개 이상 문자를 허용한다.

외우는 법: _ = 빈칸 한 칸 · % = 아무거나 얼마든지
바로 확인

한 장 정리 공책에 옮겨 적기

"키워드 가리기"를 누르면 형광펜 부분이 가려져요.

= 정의 · → 흐름 · / 대비 · ★ 시험(결과 말하기)

① SELECT 뼈대 ★프 · 웨 · 그 · 해 · 셀 · 오

  • SELECT 열 · FROM 테이블 (필수) · WHERE · GROUP BY · HAVING · ORDER BY (생략 가능)
  • 실행: FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY · * = 모든 열

② DISTINCT · AS 도장 한 번씩

  • DISTINCT 중복 제거 / ALL 기본 · 소속학과 → 4개 · AS = 별칭

③ WHERE AND 둘 다 · OR 하나만

  • 비교 · AND · OR · NOT · BETWEEN a AND b(양 끝 포함) · 문자는 '따옴표'

④ ORDER BY 앞 기준 먼저

  • ASC(기본, 오름) / DESC(내림) · 맨 마지막 수행 · NULL은 오름차순 맨 앞

⑤ 집계 · 그룹 ★*은 다, 열은 NULL 빼고

  • COUNT(*) 7 · COUNT(주소) 6 · COUNT(DISTINCT 주소) 5
  • GROUP BY 묶기 · HAVING = 그룹 조건 (WHERE = 행 조건)

⑥ LIKE _ 한 칸 · % 얼마든지

  • '이__' → 이승엽 · 이영애 · 이은진 · '%서울%' → 김연아 · 홍길동

빈칸 채우기 눌러서 정답 확인

SELECT문에서 필수인 절은 SELECT와 FROM이다. 중복 행을 제거하려면 DISTINCT를 쓴다. 범위 조건 "1 이상 3 이하"는 BETWEEN 1 AND 3으로 쓸 수 있다. 내림차순 정렬은 DESC다. 그룹에 조건을 걸 때는 WHERE가 아니라 HAVING을 쓴다. COUNT(열)은 NULL인 행을 세지 않는다. LIKE에서 1글자는 _, 0글자 이상은 %로 나타낸다.

키보드: Space 뒤집기 · → 알아요 · ← 모르겠어요
SELECT문 6개 절과 실행 순서는?
FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY.
SELECT 형식에서 [ ], { }, |, *의 뜻은?
[ ] 생략 가능, { } 반복 가능, | 선택, * 0번 이상 반복(+는 1번 이상).
SELECT 이름, 주소 FROM 학생; 의 결과는?
학생 7명 전부의 이름과 주소 2열. 홍길동(s002)은 '미정', 이승엽은 NULL.
DISTINCT의 역할은?
결과에서 중복 행 제거. 기본은 ALL. 소속학과 DISTINCT → 컴퓨터 · 통계 · 정보통신 · 경영 4개.
BETWEEN a AND b의 뜻은?
a 이상 b 이하(양 끝 포함). (열 >= a AND 열 <= b)와 같음.
ASC와 DESC는?
ASC 오름차순(기본값), DESC 내림차순. 기준이 여러 개면 앞 기준부터.
MySQL에서 NULL의 정렬 위치는?
오름차순 시 가장 앞.
집계 함수 5가지는?
COUNT(개수), MAX(최댓값), MIN(최솟값), SUM(합계), AVG(평균).
COUNT(*)와 COUNT(열)의 차이는?
COUNT(*)는 전체 행, COUNT(열)은 그 열이 NULL인 행을 제외. 학생: 7 vs COUNT(주소) 6.
WHERE와 HAVING의 차이는?
WHERE는 행에 대한 검색 조건, HAVING은 GROUP BY로 만든 그룹에 대한 조건.
LIKE의 _와 %는?
_ = 특정 위치 1개 문자, % = 임의 위치 0개 이상 문자.
'이__'와 '%서울%'로 찾은 결과는?
이승엽 · 이영애 · 이은진 / 김연아(서울 서초) · 홍길동(서울 종로).

    퀴즈 "결과를 말하시오" 형태 그대로

    Q1SELECT 이름, 주소 FROM 학생;의 결과 행 수와, 이승엽의 주소 칸은?

    조건 없음 → 7행. 이승엽은 INSERT 때 NULL을 넣었어요('미정'은 DEFAULT를 쓴 홍길동).

    Q2SELECT DISTINCT 주소 FROM 학생;의 결과 행 수는? (MySQL은 NULL도 하나의 값으로 한 행 표시)

    서울 서초 · 미정 · NULL · 경기 분당 · 서울 종로 · 경기 과천 = 6. (COUNT(DISTINCT 주소)는 NULL을 빼서 5)

    Q3SELECT 이름 FROM 학생 WHERE 학년 BETWEEN 2 AND 3;의 결과는?

    2학년(이영애, 홍길동 s006) + 3학년(이승엽). 양 끝 포함.

    Q4SELECT 이름 FROM 학생 WHERE 소속학과 = '정보통신' ORDER BY 학년 DESC;의 결과 순서는?

    정보통신 = 이승엽(3), 이영애(2) → 내림차순.

    Q5SELECT COUNT(나이) FROM 학생;의 결과는?

    이영애 나이가 NULL → 6.

    Q6SELECT 소속학과, COUNT(*) FROM 학생 GROUP BY 소속학과 HAVING COUNT(*) >= 2;의 결과는?

    학과별로 묶은 뒤 2명 이상인 그룹만.

    Q7SELECT 이름 FROM 학생 WHERE 이름 LIKE '%연%';의 결과는?

    이름에 '연'이 들어간 사람은 김연아뿐.

    Q8"남학생의 이름과 나이를 나이가 많은 순으로"를 SQL로 바르게 쓴 것은?

    절 순서 SELECT · FROM · WHERE · ORDER BY, 문자는 따옴표, 많은 순 = DESC.

    내 말로 설명하기 "결과를 말하시오" 서술 연습

    "SELECT 학년, COUNT(*) FROM 학생 WHERE 성별 = '여' GROUP BY 학년;이 어떤 순서로 실행되어 어떤 결과를 내는지 설명해 보세요."

    먼저 FROM으로 학생 테이블 7행을 가져오고, WHERE 성별 = '여'로 여학생 4명(김연아 4학년, 이영애 2학년, 송윤아 4학년, 이은진 1학년)만 남겨요. 그다음 GROUP BY 학년으로 학년이 같은 행끼리 묶어 1학년 그룹(이은진), 2학년 그룹(이영애), 4학년 그룹(김연아, 송윤아)을 만들고, SELECT에서 각 그룹의 학년과 COUNT(*)를 보여 줘요. 그래서 결과는 1학년 1명, 2학년 1명, 4학년 2명의 3행이에요. 3학년 여학생은 없어서 나오지 않아요.
